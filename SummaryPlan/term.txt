================================================================================
 用語：Present / presentBlock / cpuWork
================================================================================

 Present は DXGI の関数。presentBlock と cpuWork はこの計画で付けた計測用の名前で、
 コードや API には存在しない。

--------------------------------------------------------------------------------
 Present
--------------------------------------------------------------------------------
 描き終わった絵を画面に出してもらうよう GPU に依頼する関数（ManagerImpl.h の endDraw）。
 CPU の Draw 呼び出しは「命令をキューに積むだけ」で、GPU は後から順に実行する。
 Present も命令を積むだけだが、次の場合は Present の中で CPU が止まる。
  (1) GPU が遅い：キューの上限（既定は3フレーム）が埋まり、空きが出るまで待つ
  (2) VSync が有効：画面の更新（60Hzなら16.67msごと）より速くは絵を出せない

--------------------------------------------------------------------------------
 cpuWork（CPU が実際に仕事をしていた時間）
--------------------------------------------------------------------------------
 フレームの開始から Present を呼ぶ直前まで。
 含む：メッセージ処理、入力、ティックの更新、描画命令の発行、ImGui
 含まない：Present の中での待ち、フレーム制限の sleep
 → 60fps 目標なら「16.67 − cpuWork」が CPU 側の余裕

--------------------------------------------------------------------------------
 presentBlock（Present の中で止まっていた時間）
--------------------------------------------------------------------------------
 Present を呼んでから戻るまで。長いほど「GPU 待ち」か「VSync 待ち」をしている。


Sync（垂直同期、Vertical Synchronization）
パソコンのGPU（グラフィックボード）が描画するフレームレートを、モニターのリフレッシュレート（画面の書き換え回数）に一致させる機能
