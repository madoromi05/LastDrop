■ 案（★がおすすめ）
命中を 4 つの重さに分ける。重いほどまれで、出る物が大きい。
  ふつう      ：胴・腕・脚に当たっただけ           … 今より少し控えめ（差を作るため）
  部位が飛んだ：腕・脚が千切れた                   … 専用の音・血を多く・画面が少し揺れる
  倒した      ：止めを刺した（部位は飛んでいない）   … 倒れる体の音（地面にドサッ。ゾンビから 3D）
  頭が弾けた  ：頭のクリティカル、または頭の体力 0 … 一番大きい音・血・揺れ

■ 作り（★の案のとき。後の「■ 差分を書くときの直し」「■ ユーザーの変更」で変わった所がある）
・CombatResolver::ZombieHit に「重さ」（enum class HitWeight { Normal, Severed, Killed, HeadBurst }）を足す。
  決めるのは CombatResolver::hitZombie だけ（部位が切れたか・倒したか・頭か、はもうここで分かる）。
  重さの決まりを変えるときは、ここの 1 つの関数（chooseHitWeight）だけを直す。
・頭のクリティカルを外から読めるように、ZombieHealth::takeDamage が「この 1 発で何が起きたか」を返す
  （戻り値 struct DamageOutcome { bool critical; }。今の void を変える）。ZombieHealthComponent が持ち上げる。
・音：ZombieHitSounds が重さで音を選ぶ（SOUND_HIT_SEVER・SOUND_HIT_HEADBURST・SOUND_ZOMBIE_BODYFALL を足す）。
  倒れる音は撃った瞬間ではなく、倒れるアニメで体が地面に着く頃に鳴らしたいが、
  ★最初は「倒した 0.6 秒後」に固定で鳴らす（アニメの印を読む仕組みが無いため。遊んでずれたら直す）。
・揺れ：GameScene が zombieHitsThisTick を読み、重さで CameraShake に足す（噛まれた揺れと同じ入口）。強さは調整値（F6）。
・血：EffectManager::spawnBloodHit に重さを渡す（ふつうを小さく・頭が弾けたを大きく）。
・調整値は HitFeelParams（F6 の Tuning「HitFeel」）にまとめる：重さごとの揺れの強さ・音量・血の大きさ。

■ 影響範囲

■ 差分を書くときの直し（2026-11-06。コードを読んで変えた所）
・「頭が弾けた」は「頭に当たった 1 発で倒した」で決める（クリティカルでも 3 発目でも、頭で倒せば頭は飛ぶ＝ZombieHealthComponent の severIfBroken）。
  → ZombieHealth::takeDamage の戻り値は変えない（ZombieHealth は触らない）。
・ZombieHit は weight（重さ）と killed（倒した）を持つ。倒れる音は重さに関係なく「倒した」なら鳴らす（脚を飛ばして倒したときも）。
・HitFeelParams（F6）はやめ、値は使う所の定数に置く（揺れは FirstPersonControl・音量は ZombieHitSounds・血は EffectManager。今の揺れ・血の値と同じ置き方）。
・H-a の「F6 で重さを文字で見る」はやめた（音と血で分かるため）。

■ ユーザーの変更（2026-11-06）
・弾が当たった音は SOUND_HIT_FLESH 1 つだけにする（頭の音 SOUND_HIT_HEAD もやめる。千切れる・弾ける音は作らない。音量も重さで変えない）。

・その代わり、頭に当たったら血の量を増やす。
  頭に当たった（倒れていない）＝ 1.5 → 2.0（1 回の血しぶきの上限。BloodSpray::kMaxDropNumber 24 ＝ 12 粒 × 2）。
  頭が弾けた ＝ 上限の 2.0 を 3 回（弾の向き・真上・撃った側）。
・前の差分の直し：頭が弾けたを scale 3 にしていたが、BloodSpray は scale 2 を超えると ASSERT で止まる → 上の 3 回に変えた。

■ 実装（2026-11-07。H-a〜H-c。ユーザーが途中まで入れた差分を整えて仕上げた）
・CombatResolver：ZombieHit に weight・killed。chooseHitWeight（重さ）・bloodHitSize（重さ→血の大きさ）。血しぶきは重さが決まってから出す。
・音：弾が当たった音は SOUND_HIT_FLESH だけ。SOUND_HIT_HEAD の位置に SOUND_ZOMBIE_BODYFALL（後ろの番号は変わらない）。
  ZombieHitSounds が倒した 0.6 秒後に鳴らす（PendingFall）。合成は tools/SoundGen/BodyFallSynth.cpp。
  WAV は zombie_bodyfall_0/1 だけを書き出して入れた（SoundGen は scratchpad へ書き出し、ほかの WAV は触っていない）。hit_head_0.wav は残してある（使わない）。
・血：BloodSpray に kBaseDropNumber・kMaxScale（2）と範囲の ASSERT。ふつう 0.8・頭 2.0・部位/倒した 1.2・頭が弾けた 2.0 × 3 方向。
・揺れ：FirstPersonControl::shakeOnHeavyHit（部位 0.15・頭 0.25・上限 0.6）。GameScene::shakeOnHeavyHits が命中を読んで呼ぶ。
・Debug・Release・Profile・SoundGen ビルド済み。画面と音で確認済み。
