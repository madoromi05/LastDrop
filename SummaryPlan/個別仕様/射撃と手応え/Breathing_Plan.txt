 ☆ ユーザーに決めてもらうこと（おすすめを先に書く）
--------------------------------------------------------------------------------
 ☆1 疲れ（スタミナ）で走れなくするか
     （おすすめ）息のためだけに使う。走るのは今までどおりいつまでも走れる
       ・表題が「爽快さを追求したタルコフ」。ゾンビから逃げている最中に走れなくなるのは、爽快さより我慢が勝つ
       ・それでも「走り続けると息が上がる・止まっても息がしばらく荒い」ので、走った重さは耳で伝わる
       ・疲れの値は自キャラの側（Player/PlayerExertion）に置く。後でスタミナにするときは、
         PlayerCharacter が「疲れ切ったら run を落とす」を 1 か所足すだけ（脚が壊れたときの allowed.run と同じ所）
     （別案）タルコフどおり、疲れ切ったら走れなくなる（息が戻るまで歩き）

 ☆2 音の素材
     （おすすめ）SoundGen で合成して始め、後で録音素材に差し替える
       ・手元の素材集（Downloads/ゾンビゲーム/ など）に息・うめきの音は無い（2026-10-23 に探した）
       ・息は「声の高さの帯を通したノイズ」で近い物が作れる（吸う＝高め・短い、吐く＝低め・長い）
       ・差し替えは目録（SoundCatalog）で recorded にして WAV を置くだけ。コードは変わらない（着弾音と同じ）
     （別案）始めから録音素材を探す（freesound の CC0 など）。人の息は合成だと「風の音」に寄りやすいので、
       合成で聞いて安っぽければこちらへ移る

 ☆3 走った後の息のほかに、どの場面で息を鳴らすか
     （おすすめ）つかまれている間は荒い息／噛まれた瞬間に詰まった息を 1 回
       ・つかまれている間は疲れていなくても荒い息にする（あせり）。疲れの値は変えない（音だけ）
       ・噛まれた瞬間は「ぐっ」と息が詰まる音を 1 回。画面の赤み・怯み（PlayerDamageView・AimPunch）と同じ瞬間
       ・タルコフは被弾の声（言葉・うめき）があるが、調べた範囲では「息」としての仕様は分からなかった（1 章）
     （別案）走った後の息だけ（つかまれた・噛まれたは今のまま無音）

 ☆4 ゾンビが息を聞いて寄ってくるか
     （おすすめ）今回は作らない（9 章）
       ・タルコフでは荒い息は「相手に聞こえやすくなる」作り（1 章）。ただ、このゲームで息が荒いのは
         走った後・つかまれた時で、どちらもゾンビはもう近くにいるか、足音の方が大きい
       ・銃声で寄ってくる（40m）が今の「音で寄る」仕組みの全部。息まで足すと寄ってくる理由が読みにくくなる

--------------------------------------------------------------------------------
 決まりごと（Claude の判断。確かめてもらう）
--------------------------------------------------------------------------------
 ・普段の息（疲れていない時）は鳴らさない。タルコフも息の音は「スタミナが切れた時の荒い息」として足した物（1 章）。
   ずっと鳴っていると、銃声・足音・ゾンビの音を聞き分ける邪魔になる
 ・息は 2 段階で鳴らす
       弾んだ息：走った後。小さく、ゆっくり
       荒い息　：疲れ切りそう／つかまれている。大きく、速い（タルコフの「息切れ」に当たる所）
   段階の間は、疲れの値に合わせて速さと大きさを滑らかに変える（段がガクッと変わると機械的に聞こえるため）
 ・荒い息になったら、疲れが少し下がるまで荒い息のまま（しきい値を上りと下りで分ける）。
   しきい値の 1 本だけだと、その上下を行ったり来たりして、息の種類が 1 回ずつ入れ替わってしまうため
 ・1 回の息は「吸う → 吐く」の 2 つの音。1 回の長さ（周期）を位相で進め、吸う・吐くの所をまたいだティックで鳴らす。
   足音がアニメの位相で鳴るのと同じ考え方（周期が途中で変わっても位相は続くので、間が飛ばない）
 ・自分の口の音なので 3D にせず 2D で鳴らす（play2D。BUS_EFFECT）。耳の位置とずれない
 ・死んだら鳴らさない（その瞬間に次の息を止める。鳴っている途中の 1 回は最後まで鳴らす）
 ・一時停止の間は鳴らない（AudioEngine::setPaused で止まる。疲れと位相はティックで進むので、止まっている間は進まない）
 ・疲れ（PlayerExertion）は音を知らない。息を鳴らす係（BreathEmitter）は自キャラのクラスを知らない。
   2 つをつなぐのは今の PlayerBodySounds（足音・装備の音をつないでいる所）。足音の FootstepEmitter と同じ形

 1. タルコフでは
================================================================================
 調べて分かったこと
 ・スタミナが切れると息が上がる。荒い息の音と手の震えが出る（0.12.4.6440・2020 年 3 月のパッチで追加）。
   「そのぶん相手に少し聞こえやすくなる」とされている
 ・スタミナは腕と脚の 2 本（0.12.4）
     脚：走る・跳ぶ・姿勢を変えると減る　　腕：覗く・投げる・近接攻撃で減る（腕が 0 になると脚も減り始める）
 ・スタミナが低いまま長くいると「疲労」がつき、減りが速くなる（0.12.4）
 ・覗いている間に息を止められる。息を止められる長さと、息が戻るまでの時間は持久力（Endurance）の技能で伸び・縮む
   （1 レベルごとに息止め +2%・最大 +100%、息の戻り −1%・最大 −50%。最上位で「息が体力に左右されなくなる」）
 ・一部の声（BEAR・USEC）の息の音が大きすぎたのを直した（0.12.10。息の音量は声ごとに持っている）

 調べても分からなかったこと
 ・息の音が何 m まで相手に聞こえるか（数値は出ていない）
 ・疲れの度合いで息の速さ・大きさがどう変わるか（段階の数・値）
 ・被弾したときのうめき・息の仕様（声としてあることは分かるが、息の仕様として書かれた物は見つからなかった）
 ・普段（疲れていない時）の息が鳴っているか

 このゲームで合わせる所・変える所
 ・合わせる：息の音は「疲れたら鳴る」もの。疲れは走ると増え、休むと戻る。荒い息は脚の疲れから
 ・変える　：疲れ切っても走れる（☆1 おすすめ。爽快さのため）
 ・変える　：息止めは作らない。このゲームの銃は覗いても照準が揺れない（揺れを抑える物が無い）ので、止める意味が無い
 ・後回し　：手の震え（9 章）／相手（ゾンビ）に息が聞こえる（☆4）／腕の疲れ（覗くと減る）／疲労

 2. 前提：今のコードで関係するところ
================================================================================
 ・自キャラの走りは PlayerCommand::run（押している間）。PlayerCharacter::update で、覗いている・リロード中・
   脚が壊れている・つかまれている時は走れない（PlayerCharacter.cpp 490〜505 行あたり）。スタミナは無い
 ・今の歩き方は PlayerCharacter::gait()（GAIT_STILL / GAIT_WALK / GAIT_RUN）
 ・自キャラの体から鳴る音は PlayerBodySounds::update( player ) が 1 ティックに 1 回、
   足音（FootstepEmitter）と装備の音（PlayerFoley）へ状態を渡して鳴らしている
 ・噛まれた瞬間は GameScene が分かっている（PlayerDamageView::update( bitten, dead ) へ渡している）。
   つかまれているかは PlayerCharacter::isHeld()、死んだかは isDead()
 ・音は AudioEngine::play2D( SoundId, Bus, volume, pitch ) で自分の耳に直接鳴らせる。
   1 回だけ鳴らす音は同時に 32 個まで（AudioEngine.cpp kMaxOneShots）

 3. 作り方の全体像
================================================================================

  PlayerCharacter::update
        └─ mExertion.update( gait )               ← 4 章。走ると増え、歩く・止まると戻る
  （GameScene が噛まれた瞬間を PlayerBodySounds へ伝える。☆3）
        ▼
  PlayerBodySounds::update( player, bitten )
        └─ BreathEmitter::update( BreathState{ 疲れ, つかまれているか, 噛まれたか, 死んだか } )  ← 5 章
               ・息の強さ（0〜1）を決める：疲れ／つかまれていれば荒い息の強さ
               ・強さ → 周期・音量・弾んだ息か荒い息か
               ・位相を進め、吸う・吐くの所をまたいだら play2D
               ・噛まれたら詰まった息を 1 回（次の吸う息を少し遅らせる）

 4. 疲れ（息の元になる値）
================================================================================

 4-1 PlayerExertion（新規。Player/）
     ・疲れ 0〜1 を持つだけの係。歩き方（Gait）を 1 ティックに 1 回受け取って増減する
     ・音も画面も知らない。PlayerCharacter が持ち、exertion() で読ませる
     ・☆1 で別案（走れなくなる）にするときも、この係はそのまま。PlayerCharacter が値を読んで run を落とすだけ

 4-2 増え方・戻り方（定数は PlayerExertion.cpp。数値は初期値で、走って聞いて直す）
     歩き方       変わり方                   0 → 1 / 1 → 0 にかかる時間
     -----------  -------------------------  ---------------------------------
     GAIT_RUN     増える                     10 秒走ると 1（疲れ切る）
     GAIT_WALK    戻る（ゆっくり）           1 から 0 まで 30 秒
     GAIT_STILL   戻る                       1 から 0 まで 15 秒
     ・走る速さは 3.1〜3.2m/秒なので、10 秒で 30m ほど。町の 1 ブロックを走り抜けると息が上がる
     ・戻る方を増える方より遅くする（止まってもしばらく息が荒い、が「走った重さ」になるため）
     ・つかまれている間は歩き方が止まり（GAIT_STILL）になるので、勝手に戻る。荒い息は 5 章で別に出す

================================================================================
 5. 息の鳴らし方
================================================================================

 5-1 BreathEmitter（新規。Audio/）
     ・FootstepEmitter と同じ立場：AudioEngine を借りて、渡された状態から「いつ・どの音を・どの大きさで」を決める
     ・キャラのクラスは知らない（BreathState で受け取る）ので、ほかのキャラにも使える
         struct BreathState{
             float exertion; // 疲れ（0〜1）
             bool held;      // つかまれているか（☆3）
             bool bitten;    // このティックに噛まれたか（☆3）
             bool dead;      // 死んだか
         };

 5-2 息の強さ
     強さ = max( 疲れ, つかまれていれば kHeldIntensity（0.85） )
     強さ                     鳴らし方
     -----------------------  --------------------------------------------------
     0.30 未満                鳴らさない（普段の息）
     0.30 〜                  弾んだ息
     0.75 以上で荒い息になる   荒い息。0.60 を下回るまで荒い息のまま（上りと下りでしきい値を分ける）
     ・鳴らさない所から鳴る所へ入るときは、その時の位相の続きから鳴らす（急に吸う音から始まらないように、
       位相は鳴らさない間も進めておく）

 5-3 速さと大きさ（強さ 0.30 → 1.00 の間を直線でつなぐ）
                       強さ 0.30    強さ 1.00
     ----------------  ----------  ----------
     1 回の長さ（周期）  3.2 秒      1.1 秒
     音量              0.20        0.60
     ・吸う：周期の頭（位相 0）で鳴らす。吐く：位相 0.4 で鳴らす（吸う方が短い）
     ・音程は鳴らすたびに ±5% 揺らす（目録の pitchJitter）。同じ間で同じ音が続くと機械的に聞こえるため
     ・音量は足音（走り）より小さく、銃声には埋もれる大きさにする。撃ち合いの最中は聞こえなくてよい
       （止まって息を整えている時に聞こえるのが目的）

 5-4 噛まれた瞬間（☆3）
     ・SOUND_BREATH_PAIN を 1 回（音量 0.7）。その後 0.6 秒は吸う・吐くを鳴らさない（詰まった後に息を吸い直す間）
     ・噛まれた後はつかまれたまま（または離された直後）なので、続きは荒い息になる

 5-5 死んだとき
     ・dead になったティックから何も鳴らさない（膝から崩れて暗転するのを、音でも止まった感じにする）

 6. 音の素材
================================================================================

 6-1 目録（SoundCatalog）に足す音
     SoundId                  揺らぎ  音程の揺れ  素材
     -----------------------  ------  ----------  ---------------
     SOUND_BREATH_LIGHT_IN    4       ±5%         合成（☆2）     弾んだ息・吸う
     SOUND_BREATH_LIGHT_OUT   4       ±5%         合成（☆2）     弾んだ息・吐く
     SOUND_BREATH_HEAVY_IN    4       ±5%         合成（☆2）     荒い息・吸う
     SOUND_BREATH_HEAVY_OUT   4       ±5%         合成（☆2）     荒い息・吐く
     SOUND_BREATH_PAIN        3       ±5%         合成（☆2）     噛まれた瞬間の詰まった息（☆3）
     ・2D でしか鳴らさないので聞こえる距離は使わない（目録の値は足音と同じにしておく）
     ・揺らぎは足音と同じ 4（1 秒に 2 回近く鳴るので、同じ音が続かないように）

 6-2 合成のレシピ（tools/SoundGen/BreathSynth.cpp。新規）
     音            長さ    作り
     ------------  ------  ----------------------------------------------------------------
     弾んだ・吸う  0.50秒  ノイズを高めの帯（中心 2.5kHz）に通す。ゆっくり立ち上がり、ゆっくり消える
     弾んだ・吐く  0.70秒  ノイズを低めの帯（中心 1.2kHz と 600Hz の 2 本を重ねる。口の響き）に通す
     荒い・吸う    0.30秒  弾んだ吸うより短く強い。立ち上がりを速く
     荒い・吐く    0.45秒  弾んだ吐くより短く強い。頭を強く（「ハッ」）
     詰まった息    0.25秒  短く強い吐く息を途中で切る（立ち上がり 10ms・0.15 秒で急に消す）＋喉の低い音（addThump を弱く）
     ・どの音も荒い息の周期（1.1 秒）の吸う・吐くの間（0.44 秒・0.66 秒）より短くする（次の息と重ならないように）
     ・最後に normalize と fadeEdges（足音・着弾音と同じ）。帯の中心や長さは作ってから耳で直す
     ・main.cpp の switch に 5 つを足す

  ・修正の入口：
      息が上がるまでの時間・戻る時間 → PlayerExertion.cpp の定数

      走れなくする（☆1 別案） → PlayerCharacter の走れるかの判定に 1 行

 8. 懸念点
================================================================================
 ・合成の息は「風の音」に聞こえやすい。帯を 2 本にして口の響きを出すが、だめなら ☆2 の別案（録音）へ移る
 ・走って止まり、また走る、を繰り返すと疲れの値が中ほどを行き来する。弾んだ息のままなら問題は無いが、
   荒い息のしきい値の近くなら上りと下りを分けたので入れ替わらない。周期が変わり続けるのは滑らかなので気にならない想定
 ・噛まれた瞬間は、噛む音・ヒットの画面効果・詰まった息が同時に鳴る。うるさければ詰まった息の音量を下げる
 ・同時に鳴らせる音は 32 個。息は多くても 1 秒に 2 個・長さ 1 秒未満なので、枠はほとんど使わない
 ・息の値は初期値。走って聞いて直す（画面と音の確認が必要）

 9. 後回しにする物
================================================================================
 ・疲れで走れなくなる（☆1 別案。値は PlayerExertion にあるので、足すのは PlayerCharacter の 1 か所）
 ・荒い息の間の手の震え（タルコフにはある。照準が揺れると撃ちにくくなるので、入れるなら見える絵だけを揺らす
   CameraShake の形で、別に決める）
 ・ゾンビが息を聞いて寄ってくる（☆4）
 ・腕の疲れ（覗くと減る）・息止め（覗いて揺れる銃を作ったら考える）
 ・体力が減っている時・脚が壊れている時の苦しい息（痛みの息）。タルコフで分からなかったので、要るかは遊んで決める
 ・死ぬ瞬間の最後の息
