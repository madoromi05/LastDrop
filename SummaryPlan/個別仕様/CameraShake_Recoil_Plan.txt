 1. 前提：今のコードで関係するところ
================================================================================
  ・弾は目から FirstPersonCamera::viewDirection の向きへ飛ぶ（GameWorld::update）。
    viewDirection は setPitchOffset（今は ViewRecoil）を足した向きなので、足したずれはそのまま弾道になる
  ・撃ったティックの弾は反動を足す前の向きへ飛ぶ（FirstPersonControl::updateRecoil は撃った後に呼ぶ）。1 発目は狙った所へ
  ・FirstPersonCamera はピッチのずれ（setPitchOffset）しか持たない。左右のずれ・揺れ（ロール）は無い
  ・連射は 600 発/分＝6 ティックに 1 発（FireControl、60 ティック/秒）
  ・噛まれた瞬間は GameScene が知っている（bitten）。PlayerDamageView が赤み（setDamageFlash）と死後の暗転（setFade）を決める
  ・Present.hlsl にビネット・赤み・暗転がある。ぼかしは無い

 2. 弾道の反動（Weapon/AimRecoil・新規）
================================================================================
  決めるのは「狙いへ足す角度（上下・左右）」だけ。足すのは持ち主（FirstPersonControl）。
  マウスで決めた向きそのものは変えないので、撃ちやめればずれは 0 へ戻る（★）。

  1 発ごと（撃ったティック）
    上：n 発目（連射の何発目か。1 から）に足す角度 ＝ kRiseFirst × (1 − (n − 1) / kClimbShots)   n ≦ kClimbShots
        → 1 発目 1.0°、だんだん小さく、6 発目まででおよそ 3.5° 上がって頭打ち（★）
        頭打ちの後は ±kRiseBounce（0.3°）の範囲で上下にランダムに足し、合計は頭打ちの高さ ±0.6° に収める
    左右：毎発 −kSidePerShot〜+kSidePerShot（±0.45°）を一様乱数で足す。合計は ±kSideLimit（2.5°）で止める
        → マウスを動かさなければ、上に上がりながら左右にふらつく
  撃ちやめた後
    最後の 1 発から連射の間隔＋1 ティック（7 ティック）撃たなければ「撃ちやめた」とし、
    上下・左右とも毎ティック kReturnPerTick（0.9）倍して 0 へ戻す（約 0.4 秒でほぼ戻る ★）。連射の何発目かも 1 に戻す
  覗いている間（ADS）
    今回は腰だめと同じ量にする（タルコフも覗いて大きくは減らない）。必要なら倍率を 1 か所に足す

  乱数は std::mt19937 を AimRecoil が持つ（種は起動時間。SpawnPicker と同じ）

 3. 射撃時のカメラシェイク（Player/CameraShake・新規）
================================================================================
  決めるのは「見える絵の揺れ（上下・左右・ロールの角度）」だけ。弾の向き・照準・体の向きには入れない。
  トラウマ値 t（0〜1）
    ・撃ったティックに +kFireTrauma（0.12）。ただし射撃だけでは kFireTraumaLimit（0.45）より上げない
      （連射しても揺れすぎない。タルコフでも射撃時の揺れは弱められてきた）
    ・噛まれた瞬間に +kBiteTrauma（0.8）、つかまれた瞬間に +kGrabTrauma（0.35）（4 章）
    ・毎ティック kTraumaDecayPerSecond（1.6/秒）ずつ減らす
  揺れの量 ＝ t² × 最大角度 × なめらかなノイズ（−1〜1）
    最大角度：上下 kMaxPitch 1.2°・左右 kMaxYaw 1.2°・ロール kMaxRoll 2.5°
    ノイズは 3 本（上下・左右・ロール）を別々の位置から読む 1 次元のバリューノイズ（決まった間隔の乱数を smoothstep でつなぐ）。
    速さは 1 秒に 18 回ほど向きが変わる程度（細かく震える）
  なぜ「見える絵だけ」か
    弾まで揺らすと、マウスで押さえても当たらない運になってしまう。弾道のずれは AimRecoil だけで決め、
    「押さえれば当たる」をはっきりさせる（原因が見える因果。ゲーム案_確定条件.md）

 4. 被弾の怯み（Player/AimPunch・新規）と痛みの画面効果
================================================================================
  怯み（エイムパンチ）
    ・噛まれた瞬間に、狙いへ上 kPunchPitch（2.5°）＋左右ランダム ±kPunchYaw（2.0°）を足し、
      毎ティック kPunchReturnPerTick（0.85）倍で戻す（約 0.3 秒）。弾の向きも一緒に動く
    ・つかまれた瞬間は今の「顔を見る」（lookToward）があるので、怯みは足さない（揺れだけ 0.35）
  痛みの画面効果（PlayerDamageView に量を足す。PostProcess・Present.hlsl で描く）
    ・赤み：今のまま（setDamageFlash）
    ・ぼかし（painBlur 0〜1）：噛まれた瞬間に 1、約 0.6 秒で 0 へ。画面の真ん中はぼかさず、周りほど強く
      作り：Present.hlsl で、画面の中心から外へ向けた線の上を 8 回読んで平均する（放射状のぼかし）。
      量が 0 の間は読まない（分岐）。ぼかしはブルームを足す前のシーンの色に掛ける
    ・暗く（painDarken 0〜1）：噛まれた瞬間に 1、約 0.6 秒で 0 へ。今のビネットの暗さに足す（最大 +0.5）
    ・死んだ後の暗転（setFade）はそのまま

 5. 部品と処理の流れ
================================================================================
  新しく作る
    Weapon/AimRecoil     弾道のずれ（上下・左右の角度）。update( fired ) / pitchOffset / yawOffset
    Player/CameraShake   見える絵の揺れ。addTrauma( amount, limit ) / update / pitch / yaw / roll
    Player/AimPunch      噛まれた瞬間の狙いのずれ。punch / update / pitchOffset / yawOffset
  直す
    FirstPersonCamera    setPitchOffset → setAimOffset( yaw, pitch )（狙いへ足すずれ。yaw()・pitch()・viewDirection に入る）
                         setShake( yaw, pitch, roll )（apply・projectionViewMatrix だけに入る。viewDirection には入れない）
    FirstPersonControl   AimRecoil・CameraShake・AimPunch を持つ。updateViewEffects（updateRecoil を改名）で 4 つを進め、
                         ViewRecoil＋AimRecoil＋AimPunch を足して setAimOffset、CameraShake を setShake。
                         flinch()（噛まれた）と shakeOnGrab()（つかまれた）を足す
    PlayerDamageView     pain() を足す（噛まれた瞬間に 1、時間で 0。ぼかしと暗さは同じ量で動かし、強さは PostProcess の定数で分ける）
    PostProcess          setPain( amount )。定数バッファに 4 つ足す（痛み・ぼかしの長さ・ぼかし始める距離・暗さ）
    Present.hlsl         放射状のぼかし・暗さの上乗せ
    GameScene            つかまれた／噛まれたときに mControl へ伝え、痛みの量を mPostProcess へ渡す

  1 ティックの流れ（今の順のまま）
    1. GameWorld::update（撃つ。弾は今の向きへ飛ぶ）
    2. FirstPersonControl::updateViewEffects( fired )：ViewRecoil・AimRecoil・AimPunch・CameraShake を進め、カメラへ渡す
    （その前の updatePlayerDamage で、噛まれた → flinch・つかまれた → shakeOnGrab と mDamageView へ）
  描く前：placeCamera（揺れを入れた行列で描く）

 6. 懸念点・後回し
================================================================================
  ・撃ちながらマウスで押し下げると、撃ちやめた後にずれが 0 へ戻るので、狙いは押し下げた分だけ下へ行く
    （タルコフでも起きる。気になるなら「戻るのは押し下げで打ち消されなかった分だけ」に変える）
  ・揺れはビュー行列にだけ入るので、照準（画面中央の点）と弾の着く所が揺れの分（最大 1.2°×t²）だけ一瞬ずれる。
    射撃だけなら t ≦ 0.45 で約 0.24° なので目立たない見込み
  ・体の向き（背骨の曲げ・キャラの向き）は狙いのずれに付いてくる（今のピッチの反動と同じ）
  ・揺れ・ぼかしで酔う人向けの「揺れの強さ」設定はメニュー画面を作るときに足す
  ・後回し：爆発・大口径のスクリーンシェイク（武器が増えたら CameraShake::addTrauma を呼ぶだけ）、
    武器ごとの反動の値（プロトタイプβ。今は AimRecoil.cpp の定数）
