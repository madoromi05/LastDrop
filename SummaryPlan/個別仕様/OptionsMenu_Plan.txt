 0. タルコフでは
================================================================================
 ・設定画面はタブで分かれている：Game / Graphics / PostFX / Sound / Controls。
 ・Sound タブ：一番上が Overall volume（全体）。ほかに Interface・Chat・Music・Hideout の音量、
   Binaural audio、Music on raid end。どれも 0〜100 のスライダー。
 ・Controls タブ：キーの割り当ての一覧（変更もできる）と、マウスの感度。感度は
   「Mouse sensitivity（ふだん）」と「Aiming sensitivity（覗いている間）」の 2 つに分かれている。
 ・操作説明だけの画面は無い。Controls タブのキーの一覧がその役をしている。
 ・分からなかったこと：
   ・感度の値の範囲と既定値（公式の資料が見つからなかった。攻略サイトの「0.05〜0.1 がおすすめ」くらい）。
   ・レイドの中で ESC から設定を開けるか、開いている間ゲームが止まるか（出典が見つからなかった）。

 出典：
  ・GGRecon「Escape from Tarkov best settings」（Sound の項目）
    https://www.ggrecon.com/guides/escape-from-tarkov-best-settings-improve-fps-visibility/
  ・esports.net「Best Escape From Tarkov Settings Guide」（タブの並び・Overall volume が一番上）
    https://www.esports.net/wiki/guides/best-escape-from-tarkov-settings/
  ・mouse-sensitivity.com（Mouse sensitivity と Aiming sensitivity が別）
    https://www.mouse-sensitivity.com/n/escape-from-tarkov/

 ■ 合わせる所
  ・音量は 0〜100 のスライダー。全体の音量を一番上に置く。
  ・操作説明は「設定の中の操作の一覧」にする（独立した遊び方の画面は作らない）。
 ■ あえて変える所
  ・タブにはしない。項目が 4〜5 個しか無いので 1 枚に並べる（タブを作る手間に見合わない）。
  ・音量の項目は、このゲームにある音の系統（効果音・環境音）だけ。Music・Chat・Interface の音は無いので出さない。
  ・キーの割り当ての変更は今回作らない（一覧を見せるだけ）。変えられる作り（InputConfig）はあるので、後で足せる。
  ・一人で遊ぶゲームなので、設定を開いている間は止める（今の一時停止の上に出す）。

 1. 決めてほしいこと（★）
================================================================================
 ★1 入口
   おすすめ：タイトルと一時停止の両方に「Options」ボタンを足す。Options の画面の中に「Controls」ボタンを置き、
             操作の一覧はそこから開く（タルコフと同じく設定の中）。
             一時停止は Resume / Options / Retry / Title / Quit の 5 つになる。
   別の案：「Options」と「Controls」を別々のボタンにする（操作の一覧は見つけやすいが、ボタンが 6 つになる）。

 ★2 音量の項目
   決定（2026-10-25 ユーザー回答）：Master（全体）・Effects（足音・銃・ゾンビなど）の 2 つ。
             Ambience は今サイレンしか流れていない（2 分に 1 回）ので、動かしても違いが分かりにくく、
             0 にすると脱出の方向の手がかりまで消える。環境音が増えたら足す（バスは分かれているので行を足すだけ）。
   （元のおすすめ：Master・Effects・Ambience の 3 つ）

 ★3 感度
   おすすめ：1 つ（Mouse Sensitivity）。覗いたときは今も視野角の比で自動で遅くしている
             （FirstPersonControl：0.15 度/画素 × 今の視野角 ÷ 腰だめの視野角）ので、覗いた時の手触りは揃っている。
             値は倍率で見せる：1.00 が今の感度、0.20〜3.00、1 回に 0.05 ずつ。
   別の案：タルコフと同じく 2 つ（Mouse Sensitivity と Aim Sensitivity）。覗いた時だけ別の倍率を掛ける。

 ★4 保存
   おすすめ：Options の画面を閉じたとき（Back）に settings.xml へ書き、起動時に読む。
             形式はキーコンフィグ（input_p0.xml）と同じ PseudoXml＋fstream。ファイルが無い・読めない値は既定値。
   別の案：保存しない（起動するたびに既定値）。

 ★5 操作の一覧の中身
   おすすめ：今のキーの割り当て（Pad の InputConfig）から作る。後でキーの割り当ての変更を足しても、一覧が勝手に合う。
             キーの名前（"Shift"・"Left" など）はもう GameLib が持っているので、それを表示に使う。
   別の案：決まった文字の表（作るのは簡単だが、割り当てを変えると一覧とずれる）。

 2. 画面
================================================================================
 ■ Options（見出し「OPTIONS」白）
     Master Volume      [■■■■■■■■□□]  80
     Effects Volume     [■■■■■■■■■■] 100
     Mouse Sensitivity  [■■■■□□□□□□] 1.00
                  [ Controls ]
                  [  Back    ]
   ・音量は 0〜100、1 回に 5 ずつ。既定値はどれも 100。
   ・変えたらすぐ効く（音量は AudioEngine へ、感度は自キャラへ）。ただし一時停止の間は音を止めているので、
     音量の違いは Resume した後に聞こえる。
   ・操作：
       キー   ：上下で行を選び、左右で値を変える（←→ と A/D）。ボタンの行は決定キーで押す。
       マウス ：バーをクリックした所の値にする。押したまま横へ動かすと値が付いてくる。
   ・ESC は Back と同じ（一時停止の中では一時停止のメニューへ戻る。ゲームへは戻らない）。

 ■ Controls（見出し「CONTROLS」白）
     Move            W A S D
     Run             Shift
     Look            Mouse
     Fire            Mouse Left
     Aim             Mouse Right
     Draw / Holster  1
     Reload          R
     Interact        E
     Pause           Esc
                  [  Back  ]
   ・遊ぶ操作だけを出す。開発用の F キーと、今は何も起こらない Jump / Dodge（Space）は出さない。
   ・ESC は Back と同じ。

 3. 作り
================================================================================
  クラス・ファイル                          変更
  ----------------------------------------  ----------------------------------------------------------------
  Core/GameSettings（新規）                 音量 2 つと感度の倍率を持つ struct と load / save（PseudoXml＋fstream）。
                                            範囲に収めるのもここ。ファイル名の文字列もここ（Pad.cpp には書かない）
  GameResources                             GameSettings を持つ（全シーンで 1 つ）。起動時に読み、AudioEngine へ流す
  AudioEngine                               setMasterVolume（ma_engine_set_volume）・setBusVolume（バスの ma_sound_group_set_volume）
  FirstPersonControl                        0.15 度/画素に設定の倍率を掛ける（GameSettings を借りる）
  UI/IUiAdjustable（新規）                  左右で変えられる部品の約束：adjust( 向き )・dragTo( カーソル )
  UI/UiSlider（新規）                       名前・バー・数字の 1 行。値は getter / setter の関数で受け取り、
                                            どの設定を変えるかは知らない（UiButton の onActivate と同じ考え方）
  UI/UiInput・UiCanvas                      左右の入力とクリックを押し続けているかを足す。選んでいる部品が IUiAdjustable なら渡す
  UI/UiScreen                               設定の行・操作の一覧の行の並べる位置
  Scene/Menu/MenuPages（新規）              メニューの「今のページ」（メイン／Options／Controls）を持ち、ページを切り替える。
                                            タイトル（MenuScene）と一時停止（PauseMenu）が同じ物を使う
  Scene/Menu/OptionsPage・ControlsPage（新規）各ページに何を並べるか（MenuCatalog と同じく文言はここだけ）
  MenuCatalog                               title・pause に Options ボタン
  MenuScene・PauseMenu                      UiScreen を直接持たず MenuPages を持つ。ESC で 1 ページ戻る
  GameLib Input（InputEnums・InputBuilder） WorkId::UiLeft / UiRight（←→ と A/D）。割り当てからキーの名前を返す関数（★5）
  Pad                                       InputUiLeft / InputUiRight。今の割り当てを読む関数（★5）
  vcxproj・filters                          新しいファイルの登録

 決まりごと（Claude の判断。確かめてもらう）
  ・ページを切り替えるとき、押したボタンを持っている画面をその場で消すと落ちるので、切り替えは予約にして、
    次の handleInput の頭で行う（SceneManager::requestChange と同じ考え方）。
  ・音量の数字はそのまま掛けず、2 乗して掛ける（50 で 0.25 倍）。耳の感じ方に近く、真ん中あたりで動かしたときに変わったのが分かりやすい。
  ・UiRenderer::draw は 1 回の描画に 1 回だけ、の決まりは今のまま守る（ページは 1 枚ずつしか描かない）。

 4. 懸念点
================================================================================
 ・input_p0.xml が既にあると、新しい UiLeft / UiRight はファイルの割り当てで上書きされて効かない
   （今は保存する所が無いのでファイルは無い。キーの割り当ての変更を作るときに、足りない操作を既定値で補う必要がある）。
 ・見つけたこと（2026-10-25）：InputConfig::load は読んだルートの名前が "InputConfig" かを見ているが、PseudoXml のテキストの
   ルートは名前を書かない入れ物なので、保存したキー設定は読めずに既定値になる。キーの割り当ての変更を作るときに直す。
   GameSettings はこれを避けて、ルートの子から "Settings" の要素を探す。
 ・A/D は移動の Left/Right と同じキー。メニューの間はキャラを動かさないので重ならない（W/S と UiUp/UiDown と同じ）。

================================================================================
 5. 確かめ方
================================================================================
 ・Debug・Profile・Release のビルドが警告なしで通る。
 ・タイトル → Options で値を変えて Back → 終了 → 起動し直して、値が残っている。
 ・本編で ESC → Options → 感度を変えて Resume → 視点の速さが変わる。音量 0 で音が消える。
 ・Controls の一覧が今のキーと合っている。ESC で 1 ページずつ戻る。
