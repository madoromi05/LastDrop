 ★1 ZombieChase（どこへ行くか）と ZombiePath（通り道）を誰が持つか
     （おすすめ）案A：ZombieLocomotion が持つ
       ・「どこへ行くか」「どう回り込むか」「どちらを向いて進むか」が 1 か所にまとまる。ゾンビが変な所へ歩くときの入口が 1 つになる

         ZombieLocomotion の短い関数（alert・hearNoise・mode・path）を通す
     （別案）案B：Zombie が持ったまま、ZombieLocomotion は借りる
       ・Zombie の変更は少ないが、Zombie に「行き先の AI」が残り、ZombieLocomotion は借り物を操るだけの薄い物になる

 ★2 仲間を避けるとき、ZombieCrowd に「自分」をどう名乗るか（ZombieCrowd::separation は const Zombie* で自分を除く）
     （おすすめ）案A：ZombieLocomotion が作るときに持ち主の Zombie のポインタを覚える（比べるだけで中身は読まない）
       ・ZombieCrowd は変えない。CharacterMover が this を覚えているのと同じ形
     （別案）案B：ZombieCrowd を「番号」で自分を除くように変える。ZombieCrowd と GameWorld も変わるので、今回は勧めない

 ★3 死体が残る時間と沈む時間を、何本の時計で数えるか
     （おすすめ）案A：倒れ終わってからの 1 本の時計にする（沈み始めは「10 秒たった所」、消えるのは「11.5 秒たった所」）
       ・今の「Corpse で数えて 0 に戻し、Sinking でまた数える」と、すべてのティックで同じ値になる（6 章に確かめた式）
       ・消えるまでの残り秒が 1 つの式（11.5 秒 − 経った時間）で済む
     （別案）案B：今と同じく、Corpse と Sinking で数え直す 2 本の時計のまま移す

 決まっていること（1 回目と同じ方針）
--------------------------------------------------------------------------------
 ・動きは 1 つも変えない（式・呼ぶ順・定数をそのまま移す）
 ・Zombie の public の関数は変えない（GameWorld・確認用の表示・ZombieCrowd はそのまま）
 ・部品は Zombie のメンバとして値で持つ。足元（mPosition）と向き（mAngleY）は Zombie が持ったまま、関数ごとに渡す
   （どちらも追う・攻撃・這う・根の動き・死体のどこでも使うので、1 つの部品の物にしない。1 回目の ZombieRootMotionSpan と同じ）
 ・「今どの状態か（State）」「攻撃を始めてよいか」「どのアニメを流すか」は Zombie に残す。部品はそれを知らない

   攻撃は Zombie の仕事（アニメ・根の動き）なので、追う処理を丸ごと外へ出すと、攻撃まで借りることになる

================================================================================
 3. 分け方の方針（1 回目に分けなかった理由をどう越えるか）
================================================================================
 追う処理を「考える（見て・行き先を決め・向きを変える）」と「動く（歩く・横へよける）」の 2 つに分け、
 その間で Zombie が攻撃を始めるかを見る。今の chase の中の順番そのままなので、動きは変わらない。

   今の chase                         分けた後の Zombie::chase
   ─────────────                      ──────────────────────────────
   見る・行き先・回り込む・向きを変える   intent = mLocomotion.thinkStanding( ... )   ← ZombieLocomotion
   攻撃を始めてよいか → 攻撃へ          if ( canStartAttack ) { 攻撃へ; return; }    ← Zombie のまま
   歩く・立つのアニメ                   setWalking( intent.walking )                ← Zombie のまま（アニメ）
   歩く／横へよける                     mLocomotion.walkStep / standAside           ← ZombieLocomotion

 這う追い方も同じ形にする（考える → 攻撃を始めるか → 腕の速さを決める）。

 4. 段階D：追う・歩く（ZombieLocomotion）
================================================================================
 置き場所：GameSrc/include/GameSrc/Zombie/ZombieLocomotion.h・src/Zombie/ZombieLocomotion.cpp

   // ゾンビ1体の「どこへ行き、どちらを向いて、どう進むか」（SummaryPlan/個別仕様/ZombieChase_Plan.txt・ZombiePath_Plan.txt・
   // ZombieCrowd_Plan.txt）。行き先を決めるのは ZombieChase、建物を回り込む通り道は ZombiePath（どちらもここが持つ）。
   // 向く点には、近くの仲間から離れる向きと、フラつきで倒れている側への流れを混ぜる。
   // 足元と向きは持ち主（Zombie）が持ち、関数ごとに渡す。攻撃を始めてよいか・どのアニメを流すかは知らない
   // （考える thinkXxx と、動く walkStep・standAside の間で、持ち主が攻撃を始めるかを見る）。
   class ZombieLocomotion{
   public:
       enum class Posture{ Standing, Crawling }; // 向きを変える速さが違う（這っている体はゆっくり）

       // 考えた結果。
       struct Intent{
           bool walking;   // 歩きたいか（ZombieChase::wantsToWalk）
           bool facing;    // 行き先の方を向き終わったか（向きの差が大きいうちは false。進まない）
           bool wandering; // うろついているか（Wander。這っている体はその場でもがくだけ）
       };

       // self: ZombieCrowd に自分を名乗るための持ち主（比べるだけ。★2）。streets・mover: 借りるだけ。どれも nullptr 不可で、
       // この部品より長く生きていること。sightPhase・randomSeed: ZombieChase・ZombiePath へそのまま渡す。
       ZombieLocomotion( const Zombie* self, const StreetGraph* streets, const CharacterMover* mover, int sightPhase, int randomSeed );

       // ── 考える ──
       // 立っている体：見て・行き先を決め・回り込む点を選び・向く点へ 1 ティックぶん向きを変える（今の chase の前半）。
       // center: 体の中心。eye: 目の位置。weaveDegree: フラつきで流す角度（今の mSway.lean() × weaveDegree）。
       Intent thinkStanding( const Vector3& center, const Vector3& eye, const ChaseTarget* target, const HitWorld& hitWorld,
           const ZombieCrowd* crowd, float weaveDegree, float* angleY );
       // 這っている体：同じことを、避けず・揺れずに行う（今の crawlChase の前半。5 章）。
       Intent thinkCrawling( const Vector3& center, const Vector3& eye, const ChaseTarget* target, const HitWorld& hitWorld, float* angleY );
       // destination の方へ 1 ティックぶん向きを変える（攻撃中に相手の方を向くのにも使う）。向き終わっていなければ false。
       bool turnToward( const Vector3& center, const Vector3& destination, Posture posture, float* angleY ) const;

       // ── 動く ──
       // angleY の向きへ distance だけ進もうとして、壁・車・ほかの体に沿って滑った後の移動量を返す（足すのは持ち主）。
       Vector3 walkStep( float distance, float angleY ) const;
       // 追いついて立ち止まっている間に、重なりそうな仲間から横へ半歩よける（向きは変えない）。footing を動かす。
       void standAside( const Vector3& center, const ZombieCrowd* crowd, Vector3* footing );

       // ── 持ち主が使う ──
       void beginTick();                                  // このティックの「仲間から離れる向き」を 0 に戻す（今の update の頭）
       void alert();                                      // 撃たれた。見えていなくても気付く（ZombieChase::alert）
       void hearNoise( const Vector3& position );         // 銃声（ZombieChase::hearNoise）
       void clearPath();                                  // 攻撃を始めた・這い始めた
       ZombieChase::Mode mode() const;
       const ZombiePath& path() const;                    // 確認用の表示
       const Vector3& separation() const;                 // 確認用の表示
   private:
       Vector3 avoidCrowd( const Vector3& center, const Vector3& point, const ZombieCrowd* crowd ); // 今の avoidCrowd
       Vector3 weave( const Vector3& center, const Vector3& point, float degree ) const;            // 今の weave
       const Zombie* mSelf;
       const StreetGraph* mStreets;
       const CharacterMover* mMover;
       ZombieChase mChase;
       ZombiePath mPath;
       Vector3 mSeparation;
   };

 （Vector3 は GameLib::Math::Vector3。仕様書では略した）

 移る定数：kTurnPerTick・kCrawlTurnPerTick・kTurnInPlaceDegree・kMinTurnDistance。
 Zombie に残る定数：kEyeHeight・kCrawlEyeHeight（目の位置は Zombie が求めて渡す。headPosition の頭が無いときにも使うので）。

 分けた後の Zombie::chase（今の順番のまま）：
   Intent intent = mLocomotion.thinkStanding( mPosition, 目, target, hitWorld, crowd, mSway.lean() * weaveDegree, &mAngleY );
   if ( canStartAttack( target ) ) { mLocomotion.clearPath(); startAttack(); mMesh.setAngleY( mAngleY ); return; }
   setWalking( intent.walking );
   if ( intent.walking && intent.facing ) { mPosition += mLocomotion.walkStep( walkDistanceThisTick(), mAngleY ); }
   else if ( !intent.walking && mLocomotion.mode() == Chase ) { mLocomotion.standAside( bodyCenter(), crowd, &mPosition ); }
   メッシュへ置き場所・向きを渡す
 approachDuringAttack は mLocomotion.turnToward と walkStep を使う（寄る距離・速さは攻撃の決まりなので Zombie に残す）。

 Zombie に残る（追う・歩くのうち）：walkDistanceThisTick（歩きアニメの足の表を読む）、setWalking・locomotionAnimation（アニメ）、
 swayStrength（State・よろけ・攻撃を見る）、canStartAttack・reachDistanceTo・headingDifferenceTo・flatDistanceTo（攻撃の間合い）。

 注意：今の avoidCrowd・weave・standAside は bodyCenter() を中心にしている。追っている間は根の動きの区間の外で這ってもいないので、
 中心は足元と同じ。分けた後は Zombie が bodyCenter() を渡す（同じ値）。

 5. 段階E：這う追い方（ZombieLocomotion に足す）
================================================================================
 今の crawlChase のうち「見る・行き先・回り込む・向きを変える・あきらめる」を thinkCrawling へ移す。
 腕の往復の速さ（pace）を決めるのは ZombieCrawl への指示なので Zombie に残す。

 分けた後の Zombie::crawlChase（今の順番のまま）：
   if ( !canCrawl() ) return kStillPace;                                   // 両腕が無い（部位欠損は Zombie が知っている）
   Intent intent = mLocomotion.thinkCrawling( 胸, 胸の上の目, target, hitWorld, &mAngleY );
   if ( intent.wandering ) return kStrugglePace;                            // 気付いていない間はもがくだけ
   if ( canStartAttack( target ) ) { mLocomotion.clearPath(); startAttack(); return kStillPace; }
   if ( !intent.walking ) return kStrugglePace;                             // 追いついて待っている
   *moving = intent.facing; return kCrawlPace;
 updateDowned で胸を進める所は mCrawlBody.moveCenter( mLocomotion.walkStep( 腕で引いた長さ, mAngleY ) ) にする。

 「胸の位置で追う」ための形（ZombieCrawlBody）とは混ぜない。ZombieCrawlBody は置き場所の計算、こちらは行き先と向き。

 6. 段階F：倒れてから消えるまで（ZombieCorpse）
================================================================================
 置き場所：GameSrc/include/GameSrc/Zombie/ZombieCorpse.h・src/Zombie/ZombieCorpse.cpp

   // 倒れ終わったゾンビが、死体として残り、地面へ沈んで消えるまでの時間（ゾンビ1体ぶん）。
   // 倒れ終わってから 10 秒残し、1.5 秒かけて 0.5m 沈め、沈み終わったら消えてよい（SummaryPlan/個別仕様/ZombieDamage_Plan.txt）。
   // 状態（Corpse → Sinking）を切り替える・見た目を下げるのは持ち主（Zombie）。ここは時間と、どれだけ沈めるかだけ。
   class ZombieCorpse{
   public:
       ZombieCorpse();
       void start();                   // 倒れ終わった。ここから数える
       void tick();                    // 1 ティック進める
       bool isSinking() const;         // 残す時間が過ぎて、沈む時間に入ったか
       float sinkDepth() const;        // 今どれだけ沈めるか（m。0〜0.5）
       bool isGone() const;            // 沈み終わったか
       float secondsUntilGone() const; // 消えるまでの残り秒（確認用の表示）
   private:
       int mTicks;                     // 倒れ終わってからのティック数（★3 案A）
   };

 ★3 案A で同じ値になることの確かめ（残す 600 ティック・沈む 90 ティック）：
   今：Corpse に入ると t = 0。毎ティック t+1 してから見て、t が 600 になったティックに Sinking へ移って t = 0（このティックは沈めない）。
       Sinking では t+1 してから、t / 90 だけ沈める。消えてよいのは t >= 90。残り秒は Corpse で (600 − t + 90)、Sinking で (90 − t)。
   案A：倒れ終わってからの時計 c。今の Corpse の t は c と同じ、Sinking の t は c − 600 と同じ。
       沈み始め c >= 600、沈む量 (c − 600) / 90、消えてよい c >= 690、残り秒 (690 − c)（Corpse でも Sinking でも今の式と同じ値）。
   Zombie 側は「Corpse の間に tick して isSinking になったら Sinking へ（そのティックは沈めない）」「Sinking の間は tick してから沈める」
   と、今と同じ順に呼ぶ。

 移る定数：kCorpseSeconds・kSinkSeconds・kSinkDepth。mStateTicks は消える（使っているのは死体の時間だけ）。
 Zombie に残る：Falling → Corpse の切り替え（死亡アニメが終わったか、根の動きの区間の固定）、State、見た目の位置を下げる所。

 7. この後も Zombie に残る物
================================================================================
 見込み：Zombie.cpp 862 → 約 700 行（2 回目で約 160 行減る）。
 前に「約 600 行」と書いたが、詰めてみると、攻撃のつなぎ（約 100 行）と、定数のコメント（約 70 行）・値を返す小さな関数（約 100 行）は

 残る仕事：今どの状態かを決める（update・applyDamage・startFalling・startDowned）、攻撃のつなぎ（アニメ・根の動き・のけぞり）、

 攻撃のつなぎを分けるか（ZombieAttack を「段階だけ」から「アニメと寄る所まで」に広げる）は、今回の後に別に考える。
 行数だけを減らすために定数を別ファイルへ移すことはしない（使う所の近くに理由を書く方が、修正の入口が分かりやすいため）。

 11. 懸念点
================================================================================
 ・ZombieLocomotion が持ち主の Zombie のポインタを持つ（★2 案A）。中身は読まず ZombieCrowd に渡すだけ、とコメントに書く
 ・thinkStanding の引数が 7 つになる。まとめた構造体にするほどではないので、引数の説明をヘッダに書く
 ・ZombieChase・ZombiePath を ZombieLocomotion の中へ移すので、コンストラクタの初期化の順（sightPhase・乱数の種）を今と同じにする
   （今は mRandom.getInt() で ZombieChase の種を引いている。引く順が変わると、うろつく先が変わる）
