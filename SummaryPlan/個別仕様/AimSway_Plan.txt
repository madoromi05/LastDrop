 ★ ユーザーに決めてもらうこと（おすすめを先に書く）
--------------------------------------------------------------------------------
 ★1 弾はぶれた銃の向きへ飛ぶか
     （おすすめ）飛ぶ。カメラ（画面の中央）は動かさず、銃とその向きだけがぶれる
       ・覗いているとサイトが画面の中で少しずつ動いて見え、撃った弾はサイトの先へ行く（タルコフと同じ。1 章）
       ・今の弾は「目から、画面の中央へ」出している。出す所（目）は変えず、向きにだけぶれを足す
         （銃口が壁にめり込んでいても壁の向こうへ撃てない、という今の決まりは残る）
     （別案）画面ごとぶれる（反動 AimRecoil と同じく、カメラの向きに足す）
       ・作りは小さいが、銃は画面の真ん中に止まったまま景色が揺れるので、「照準がぶれる」より「酔う」に近い

 ★2 揺れの種類
     （おすすめ）次の 3 つ。3 章
       a. 息：止まって構えているだけでも、ゆっくり小さく 8 の字を描く
       b. 歩き：歩くと大きくぶれ、止まってもすぐには収まらない（0.6 秒かけて収まる）
       c. 振り向きの遅れ（慣性）：マウスで向きを変えると、銃が少し遅れて付いてくる
     息止め（覗きながらキーを押すと揺れが止まる）と腕のスタミナは作らない（8 章）

 ★3 腰だめ（覗いていない）でもぶれるか
     （おすすめ）ぶれる。覗いているときの 2 倍。走っている間（銃を胸元へ抱えている間）はぶれない（撃てないため）
     （別案）覗いている間だけ

 ★4 画面の中央の「+」（GameHud の照準）
     ぶれで弾が「+」から外れるので、「+」の扱いを決める必要がある。タルコフには「+」が無い（1 章）
     （おすすめ）覗いている間は消し（サイトで狙う）、腰だめでは銃が向いている所へ「+」を動かす
       ・「+」がうそをつかない（弾は「+」へ飛ぶ）。動く「+」を見れば、ぶれていることも分かる
     （別案1）今のまま画面の中央に固定（ぶれた分だけ「+」と弾がずれる）
     （別案2）いつも消す（タルコフと同じ。腰だめで当てにくくなり、爽快さが下がる）

 ★5 腕が壊れていると大きくぶれるか
     （おすすめ）ぶれる。片腕が 0 で 1.8 倍、両腕が 0 で 2.5 倍（タルコフの腕の骨折と同じ扱い。1 章）
       今の自キャラの体力は腕の部位も持っているが、腕が壊れても何も変わらない。ここで初めて意味が付く
     （別案）作らない

 ★6 作る順番
     （おすすめ）先に調整値の仕組み（DebugTools_Profiling_Plan.txt 5-5。F6 で値を動かす）を作り、
       その後でぶれを作る。ぶれは「大きさ・速さ・収まるまでの時間」の値が 15 個ほどあり、画面で見ながら決めるしかないので、
       先に F6 で動かせるようにしておくと、ビルドし直す回数が大きく減る
     （別案）ぶれを先に作り、値は定数のまま直す

--------------------------------------------------------------------------------
 決まりごと（Claude の判断。確かめてもらう）
--------------------------------------------------------------------------------
 ・ぶれは「角度（度）」で持つ。左右（ヨー）と上下（ピッチ）の 2 つだけ。銃の傾き（ロール）は入れない
     サイトが傾くと覗いた絵が崩れて見え、狙いにも関係しないため
 ・ぶれを計算するのは新しい係（AimSway）。反動（AimRecoil）・怯み（AimPunch）と同じく FirstPersonControl が持つ
 ・ぶれは反動・怯みとは別に渡す。反動・怯みはカメラごと動かす（今のまま）、ぶれは銃と弾の向きだけ（★1）
 ・マウスの動きはフレームごと、ぶれはティックごとに進む。フレームで読んだマウスの量はためておき、
   次のティックで使い切る（1 フレームにティックが 0 回のときは次のフレームへ持ち越す）
 ・1 ティック前のぶれで銃を描く（自キャラの update の後でぶれを進めるため）。反動の見た目と同じ遅れで、目では分からない
 ・一時停止の間はぶれも止まる（ティックが進まないため）
 ・乱数は使わない（息も歩きも決まった形の波）。毎回同じ形でも、マウスと歩きで毎回違う形に見える

 1. タルコフでは
================================================================================
 調べて分かったこと
 ・覗いている間は手が揺れる。腕のスタミナ（息止め・近接攻撃に使う上の段のゲージ）が減るほど揺れが大きくなる。
   Aim Drills スキルの最上位は「覗いてから 2 秒は、スタミナがいくつでも手が揺れない」
   → 揺れは「覗いている時間・スタミナ」で大きくなる作り
 ・息止めがあり、Endurance スキルで息を止められる時間が延びる（1 段ごとに +2%、最上位で +100%）
 ・腕を骨折すると狙いが大きく揺れ（「酔っ払いのよう」）、リロード・覗く・持ち替えも遅くなる。
   腕が真っ黒（0）だと、息止めでスタミナが早く減り、揺れがとても大きくなる
 ・痛みを治していないと手の震え（Tremor）が出る。水分が 0 でも出る
 ・しゃがむ・伏せると揺れが小さくなり、腕のスタミナも減りにくい
 ・パッチ 12.12 で慣性（Inertia）が入った。歩き・横歩き・走り・走りながらの急な振り向き・着地・リーンで、
   動き出しと止まりが遅れる。装備が重いほど・Strength スキルが低いほど強い（0kg から効き始め、70kg で最大）
 ・パッチ 0.14.6.0 で慣性の強さが下げられた（強すぎるという声があった。同じパッチで撃ったときの視点の跳ね・揺れも減らした）
 ・腰だめの照準（「+」）は画面に無い

 調べても分からなかったこと（推測で埋めない）
 ・揺れの大きさ・速さ・形の数字（公式の資料・パッチノートに無い）
 ・弾が「画面の中央」でなく「銃の向き」へ飛ぶことを、公式の資料では確かめられなかった
   （遊んだ人の間では「弾は銃身の先から出る」と広く言われている）
 ・歩いている間の揺れが、止まった後にどれだけ残るか

 合わせる所
 ・止まっていても少し揺れる・歩くと大きく揺れる・止まってもすぐには収まらない・振り向くと銃が遅れて付いてくる
 ・腕が壊れていると大きく揺れる（★5）
 ・揺れた銃の向きへ弾が飛ぶ（★1）

 あえて変える所（爽快さのため）
 ・息止めと腕のスタミナは作らない。スタミナのゲージを見ながら撃つ遊びは、ゾンビを撃ちまくる爽快さとぶつかるため（8 章）
 ・揺れは時間で大きくならない（スタミナが無いので）。いつ覗いても同じ揺れ
 ・慣性は銃の向きの遅れだけにする。歩き出し・止まりの遅れ（体の動き）は今のまま（自キャラの加速・減速）
 ・腰だめでは「+」を出す（★4）

 3. ぶれの中身（3 種類）
================================================================================
 3 つを足した角度が「ぶれ」。最後に 覗き具合（腰だめは 2 倍 ★3）× 腕の倍率（★5）を掛ける。
 走って銃を胸元へ抱えている間（mCarryWeight）は、その割合で 0 へ寄せる。

 a. 息
   ・左右と上下を、周期の違う正弦波で動かす（左右 4.0 秒・上下 2.7 秒。比が 3:2 に近いので 8 の字に近い形になる）
   ・いつも出す（止まっていても、歩いていても）

 b. 歩き
   ・「歩きの強さ」（0〜1）を持つ。歩くと 0.3 秒で 1 へ上がり、止まると 0.6 秒かけて 0 へ下がる（止まってもすぐ収まらない）
     強さは「今の速さ ÷ 銃を持った歩きの速さ（1.0m/秒）」で決める（脚が壊れて遅く歩くと、少し小さくなる）
   ・形は歩きのアニメの位相（gaitPhase）に合わせる。上下は 1 歩ごと（1 周に 2 回）、左右は 2 歩で 1 往復
     （足を着くたびに銃が沈み、体重が左右へ移るのに合わせて振れる）
   ・止まった後は位相が進まないので、形は止まった所で固まったまま強さだけ下がる → ゆっくり真ん中へ戻って見える

 c. 振り向きの遅れ（慣性）
   ・マウスで回した量の一部だけ、銃を逆へずらす（右へ振り向くと、銃は少し左に残る）
   ・ずれはばねで 0 へ戻す（はね返らない強さ。行きすぎて逆へ振れると、照準が勝手に動いたように見えるため）
   ・ずれは上限で止める（大きく振り向いても、銃が画面の外へ行かないように）

================================================================================
 4. ぶれをどこへ入れるか（★1 がおすすめのとき）
================================================================================
 ・弾の向き：FirstPersonCamera に「銃のぶれ」（setWeaponSway）を足し、新しい weaponDirection() を
   「今の向き（反動・怯みを足した向き）＋ぶれ」で返す。GameWorld が弾を出すときだけこれを使う
   （画面に平行な板の向き・音の向きなど、ほかの viewDirection の使い方は今のまま）
 ・銃の見た目：FirstPersonBody に setSway を足し、alignSightToEye の後・kickWeapon の前に swayWeapon を入れる。
   目の 15cm 後ろ（肩の付け根あたり。銃床を当てている所）を中心に、両腕（kArmBones）をぶれの角度だけ回す
     ・目の位置を中心にすると、サイトの手前が止まって先だけが動く。少し後ろを中心にすると、サイト全体が少しずれながら
       向きも変わり、構えた銃が肩ごと揺れて見える
     ・回す向きは目の向き（体の前方をピッチぶん傾けた軸。alignSightToEye と同じ）で決める
   腰だめでも同じ所・同じ中心で回す（★3）
 ・マズルフラッシュは銃口の位置から出しているので、何もしなくてもぶれた銃に付いていく
 ・腰だめの「+」（★4 がおすすめのとき）：weaponDirection の少し先の点を射影×ビューで画面へ写した所に置く。
   覗き具合が 0.5 を超えたら消す

 5. 作るクラスと変えるクラス
================================================================================
 新：GameSrc/Player/AimSway.h / .cpp
       ぶれの計算だけを持つ（入力は 覗き具合・歩きの強さ・歩きの位相・このティックに回した角度・腕の倍率・抱えている割合。
       出力は左右・上下の角度）。描画も入力デバイスも知らない
 直：FirstPersonControl     ── AimSway を持つ。readInput で回した角度をためる。updateViewEffects でぶれを進め、カメラへ渡す
     FirstPersonCamera      ── setWeaponSway・weaponDirection・weaponSwayYaw / Pitch
     PlayerCharacter        ── 歩きの強さ（速さの割合）を読む口・腕の倍率を読む口・setWeaponSway（FirstPersonBody へ渡すだけ）
     FirstPersonBody        ── setSway・swayWeapon（apply の順番に 1 つ足す）
     GameScene / GameWorld  ── 弾を出す向きを weaponDirection にする。ぶれを自キャラへ渡す
     GameHud                ── 「+」の位置と表示（★4）
     vcxproj と filters     ── AimSway を足す
   GameLib は触らない。
 ★6 がおすすめのとき：値は AimSwayParams（調整値の構造体）に入れ、F6 の欄に出す。

 6. 初期値（見た目を確かめる前の値。画面で見ながら直す）
================================================================================
 覗いているとき（腰だめは ×2）
   息      ：左右 0.15° / 上下 0.10°、周期 左右 4.0 秒 / 上下 2.7 秒
   歩き    ：左右 0.6° / 上下 0.8°、強さは 0.3 秒で上がり 0.6 秒で下がる
   遅れ    ：回した角度の 0.25 倍だけ逆へ。上限 2.0°。戻る速さ 0.12 秒で半分
 腕        ：片腕 0 で ×1.8、両腕 0 で ×2.5
 「+」     ：覗き具合 0.5 を超えたら消す
 比べると：反動の弾道のずれは上へ最大 3.5°・左右 2.5°。ぶれはその 1/4〜1/2 ほどで、「狙い続けるには押さえる必要があるが、
           撃ちまくれば当たる」くらいを狙う

 7. 懸念点
================================================================================
 ・弾がサイトの先へ行くかは、サイトの目の点（mSightEye）と銃口の向きが揃っている前提。今は覗くとサイトを視線に合わせているので、
   ぶれ 0 なら画面の中央へ飛ぶ。ぶれがあると、サイトのずれと弾のずれが同じ角度になるか画面で確かめる
 ・目の後ろを中心に回すので、覗いたときにサイトが目からずれる（0.6° で約 1.5mm）。近くを描かない距離（5cm）より十分小さいので、
   サイトが欠けることは無い見込み
 ・ぶれが小さすぎると気づかれず、大きすぎると「当たらない」になる。初期値は小さめにして、画面で上げていく
 ・慣性（遅れ）は感度の設定と重なる。感度を上げた人ほど遅れが大きく出る（回す量の割合なので）。上限で止めるので暴れはしない

 8. 後回しにする物
================================================================================
 ・息止め（覗きながら Shift。今は Shift が「走り出す＝覗くのをやめる」なので、使うならキーの意味を変える必要がある）
 ・腕のスタミナ（覗いている時間で揺れが大きくなる）
 ・しゃがみ・伏せ（このゲームにまだ無い）
 ・銃の重さ・エルゴノミクス（銃が 1 種類なので。プロトタイプβで武器が増えたら、ぶれの大きさを銃ごとの値にする）
 ・痛みの震え（Tremor）。今の痛みは画面の効果（PostProcess::setPain）だけ。足すなら ★5 の倍率と同じ所
