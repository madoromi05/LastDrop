1. 何が問題か
 ・Brain の中に「直す理由」が 6 つ混ざっている（攻撃・撃たれた反応・這う・死体・歩いて追う・状態）
 ・ZombieAttackComponent・ZombieCorpseComponent は getter 1 つだけで、名前と中身が合っていない
 ・外（GameWorld・確認用の表示）も、ゾンビのことは何でも Brain に聞いている

2. 新しい分け方
 部品                       持つ判断（前の Brain の関数）
 ZombieStateComponent（新） 状態（Alive/Downed/Falling/Corpse/Sinking）・足元・体の中心・頭・目の位置・這っているか・
                            追ってくる体か・移動の当たり判定の形（ICollisionBody）
 ZombieChaseComponent       立って追う：考える（thinkStanding）・歩く・横へよける・フラつきの強さ
 ZombieAttackComponent      攻撃を始めるか・始める・寄る・段階を進める・間合い・腕が当たったか
 ZombieHealthComponent      撃たれた反応（IDamageable）・部位を切る・倒れる・よろける
 ZombieCrawlComponent（新） 脚を失って倒れた後、腕で体を引きずって追う（updateDowned）
 ZombieCorpseComponent      倒れ終わり → 死体 → 沈む・消えてよいか
 ZombieBrainComponent       部品を呼ぶ順番だけ（update）・姿勢の書き換えの順・銃声を聞くか（全部の状態を見て決める）

 依存は一方通行にする（上が下を使う。下は上を知らない）
   Brain → Crawl・Health → Attack → Chase → State → Dismember・RootMotion・Hitbox・Transform
   ・Chase は Attack を知らない。「考える → 攻撃を始めるか → 歩く」の順は Brain が呼ぶ
   ・状態を変えるのは Health（Alive → Downed / Falling）と Corpse（Falling → Corpse → Sinking）だけ

3. 付ける順（ZombieFactory）
   start で、前に付いた部品が start の中で作る物（ZombieChase の ZombieLocomotion・ZombieRootMotion の区間とアニメ）を
   借りる部品があるので、RootMotion → Chase を先に、判断の部品をその後に付ける。
   新しい部品は、隣の部品をポインタ（部品そのもの）で覚え、中の物は使うときに読む（付ける順に依りにくくする）。

4. 外から読む所
 ・GameWorld・ZombieHealthBars・ZombiePathDrawer は、状態・位置を ZombieStateComponent、
   攻撃を ZombieAttackComponent、消えてよいかを ZombieCorpseComponent、ダメージを ZombieHealthComponent から読む
 ・ゾンビを数える・描くのは今のまま ZombieBrainComponent（1 体に 1 つ）

5. 変えないこと
 ・遊び（動き・順番・数値）は変えない。関数の中身は移すだけ
 ・自キャラ（PlayerComponent）は今回触らない
