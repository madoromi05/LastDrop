0. 何が問題か
 LightComponent は「付いている・消えている」しか持っていない。光そのもの（位置・色・強さ）は SceneLights が、
 光の種類ごとに違う道で集めている。
   ・懐中電灯 … 自キャラ → HoldComponent → 銃の LightComponent（付いているか）＋ HoldComponent::muzzle（銃口）
   ・銃口の光 … WorldRenderer::muzzleLight（中で自キャラ → HoldComponent → 銃の MuzzleFlashComponent）
   ・街灯     … TownMap::streetLights の座標の一覧（街灯の物は読まない。柱の物と光が別々に置かれている）
 このため
   ・光る物を足すたびに SceneLights に道を 1 本足すことになる（物に部品を 1 行足すだけでは光らない）
   ・SceneLights が HoldComponent・TownMap・WorldRenderer の中身を知っている
   ・街灯の物を消しても光は残る（物と光がつながっていない）

1. 今それぞれが持っている仕事
 1-1 LightComponent（ヘッダだけ・28 行）
   ① 付いている・消えている（押した瞬間に切り替える）
   ② このティックに切り替えたか（スイッチの音を鳴らす PlayerBodySounds が読む）
 1-2 SceneLights（実装 210 行）
   ① 月・補助光・空・環境光・霧を調整値から作る
   ② 懐中電灯の光を作る（自キャラの HoldComponent をたどる・調整値を読む・銃口から前へずらす・内側の角度を抑える）
   ③ 懐中電灯の影のマップを付ける
   ④ 銃口の光を WorldRenderer から受け取る
   ⑤ 街灯の光を TownMap の座標から作る（高さを足す・今日の条件の倍率を掛ける）
   ⑥ 影のマップを描く
   ②④⑤ の「物の光を作る」を、物の部品の側へ移す。①③⑥ は SceneLights に残す（世界に 1 つの物・描く手順のため）

2. 分けた後の形
 2-1 LightComponent（GameSrc/Component/。.cpp を足す）
   「この物の光を 1 つ答える」部品。持つのは 3 つだけ
     ・光の種類（LightPreset。付けるときに渡す）
     ・付いている・消えている（今と同じ。update・isOn・toggledThisTick は変えない）
     ・光の出る所を答える相手（ILightSocket。持つ側が渡す。無ければ自分の物の TransformComponent の位置）
   公開の関数（足す物）
     explicit LightComponent( LightPreset preset )
     void setSocket( const ILightSocket* socket )   … 持つ側が渡す。nullptr で外す。所有権は受け取らない
     bool castsShadow() const                       … 影を落とす種類か（LightPreset の表）
     LightPreset preset() const
     bool lightSource( LightSource* out ) const     … 今の光。消えている・出る所が無ければ false
   lightSource の中
     消えていれば false
     → socket があれば socket に位置と向きを聞く（false なら false）
     → 無ければ同じ物の TransformComponent（任意。使う所で getComponent）の位置。それも無ければ false
     → LightPresets::make( preset, 位置, 向き ) で LightSource を作る

 2-2 LightPreset（新。GameSrc/Component/LightPreset.h / .cpp）（★1）
   光の種類と、種類ごとの決まりの表。色・強さ・届く距離は部品に写さず、調整値（LightingParams）を毎回読む
   （F6 で動かした値がすぐ効くのを保つため）
     enum class LightPreset{ StreetLamp, Flashlight }
     LightPresets::startsOn( preset )     … 始めから付いているか（街灯：付いている・懐中電灯：消えている）
     LightPresets::castsShadow( preset )  … 影を落とすか（懐中電灯だけ）
     LightPresets::make( preset, position, direction ) → LightSource
        StreetLamp：位置に streetLightHeight を足した点光源（今の SceneLights 87〜89 行目と同じ式）
        Flashlight：銃口から flashlightOffset だけ前のスポット。内側の角度は外側までに抑える。近さの下限を入れる
                    （今の SceneLights::addFlashlight 164〜170 行目と同じ式）

 2-3 ILightSocket（新。GameSrc/Component/ILightSocket.h）（★4）
   「光の出る所の今の位置と向き」を答えるインターフェース。関数は 1 つ
     virtual bool lightSocket( Vector3* position, Vector3* direction ) const = 0;   … 今は無ければ false
   実装するのは HoldComponent（中身は今の muzzle をそのまま返す）
   銃の物は TransformComponent を持たず、手の骨に付いて動くので、位置は持つ側にしか分からない。
   LightComponent が HoldComponent を直接知ると「銃 → 持つ側」の逆向きの依存ができるので、インターフェースを挟む

 2-4 HoldComponent
   ・ILightSocket を実装する（lightSocket は muzzle を呼ぶだけ）
   ・bindWeapon：持っていた銃の LightComponent・MuzzleFlashComponent から socket を外し（nullptr）、
     新しく持った銃の 2 つへ自分を渡す。どちらも任意の部品（無ければ飛ばす）
   ・onDestroy：持っている銃の 2 つから socket を外す（消えた部品を指したままにしない）
   ・light()・muzzle() は残す（PlayerComponent・PlayerBodySounds・WorldRenderer::drawMuzzleFlash が読む）

 2-5 MuzzleFlashComponent（★2）
   ・setSocket( const ILightSocket* ) を足す
   ・bool lightSource( LightSource* out ) const を足す（socket が無ければ false。あれば MuzzleFlash::light へ位置と向きを渡す）
   ・光り方（MuzzleFlash）と、描く所（WorldRenderer::drawMuzzleFlash）は変えない

 2-6 SceneLights
   ・addFlashlight・街灯のループ・mRenderer->muzzleLight を消し、addObjectLights（新・private）にまとめる
       1. 影を落とす LightComponent を全部たどる（forEach）。lightSource が true なら、影のマップが空いていれば付けて足す
       2. MuzzleFlashComponent を全部たどり、lightSource が true なら足す
       3. 残りの LightComponent を全部たどり、lightSource が true なら足す。
          街灯（LightPreset::StreetLamp）には今日の条件の倍率を掛け、0 なら足さない（★3）
     1 → 2 → 3 の順は、今の「懐中電灯 → 銃口の光 → 街灯」と同じ（6 章の 1 つ目）
   ・懐中電灯の影の行列は、受け取った LightSource の位置・向き・外側の角度・届く距離から作る（今と同じ値）
   ・#include から HoldComponent・（TownMap の座標の読み取り）が消える。WorldRenderer は影を落とす物を描くのに残る

 2-7 組み立て（Factory）
   PlayerFactory::spawnWeapon   obj->addComponent< LightComponent >( LightPreset::Flashlight );
   PropFactory::spawnStreetLamp obj->addComponent< LightComponent >( LightPreset::StreetLamp );   … 1 行足す
   街灯は「Transform・StaticModel・BoxCollider・Light」の 4 つになる

 2-8 消える物
   ・WorldRenderer::muzzleLight（呼ぶのは SceneLights だけ）
   ・SceneLights::addFlashlight
   ・WorldBuilder.cpp 69 行目のコメント「照らす光はシーンが同じ置き場所の一覧から作るので、柱が置けなくても光は出る」は、
     今の形の説明に書き直す

3. 依存の向き（一方通行のまま）
   SceneLights ─→ LightComponent・MuzzleFlashComponent（GameObjectWorld::forEach でたどる）・LightingParams・今日の条件
   LightComponent ─→ LightPreset・ILightSocket（インターフェースだけ）・TransformComponent（任意）
   MuzzleFlashComponent ─→ GunComponent（今と同じ）・ILightSocket（インターフェースだけ）
   HoldComponent ─→ LightComponent・MuzzleFlashComponent（借りる。今と同じ向き）・ILightSocket を実装
   ・LightComponent・MuzzleFlashComponent は HoldComponent を知らない
   ・SceneLights は HoldComponent・TownMap の街灯の座標・WorldRenderer::muzzleLight を知らなくなる

4. 光る物を足すときの手順（分けた後）
   今：SceneLights に「その物をどうたどって、どの調整値から作るか」を書き足す
   後：物を組み立てる所に obj->addComponent< LightComponent >( 種類 ) を 1 行足す。
       新しい種類の光なら LightPreset に 1 つ足し、LightPresets::make に式を足す

5. 外から読む所
   ・PlayerComponent::updateHands：hold->light()->update( … ) は変えない
   ・PlayerBodySounds：hold->light()->toggledThisTick() は変えない
   ・GameWorld::changeDayCondition → PropFactory::relightStreetLamps（ガラスの形を替える）は変えない
   ・F6 の Zombie info のライトの表示（LightDebugDrawer）は LightList を読むだけなので変えない

6. 変わってしまう所
   ・ライトを一覧へ足す順は変えない（月 → 補助光 → 懐中電灯 → 銃口の光 → 街灯）。
     LightList は 20 個を選ぶとき、届く範囲の内にいる光どうしは足した順で残す（LightList::select の stable_sort）ので、
     順が変わると選ばれる光が変わる。そのため 2-6 の 1 → 2 → 3 の順でたどる
   ・街灯の柱の形の構築に失敗したとき：今は柱が無くても光だけ出る。後は柱の物が無いので光も出ない
     （失敗は MeshCache がデバッグ出力する。ふだんは起きない）
   ・街灯の物の部品が 1 つ増える（F6 の Objects の欄の部品の数が、街灯 38 本で 1 ずつ増える）
   ・1 回の描画ごとに LightComponent を 40 個ほどたどる（街灯 38 ＋ 銃 2）。今も 38 個の座標をたどっているので、差は出ない見込み
   ・数値・計測の印・ログの文字・保存ファイルは変えない

7. 決めてほしい所（★）
 ★1 光の色・強さ・届く距離をどこに置くか
     A（おすすめ）部品は種類（LightPreset）だけを持ち、値は調整値（LightingParams）を毎回読む。F6 で動かすとすぐ効く（今と同じ）
     B 部品が色・強さ・届く距離を自分で持つ（画像の形に近い）。F6 の調整値が効かなくなるので、F6 の欄を部品ごとに作り直す
 ★2 銃口の光（MuzzleFlashComponent）も今回そろえるか
     A（おすすめ）そろえる（2-5）。SceneLights から WorldRenderer::muzzleLight の道が消え、物の光の道が 1 つになる
     B 今回は触らない（SceneLights に銃口の光の道が 1 本残る）
 ★3 街灯に今日の条件（停電）の倍率を掛ける所
     A（おすすめ）SceneLights（今と同じ所）。LightComponent は今日の条件を知らない
     B LightComponent が共有の棚から今日の条件（DayConditionEffect）を引いて掛ける。
       SceneLights は種類を見なくてよくなるが、共通の部品が出撃の決まりを知る
     C 停電の日は街灯の LightComponent を消す（PropFactory::relightStreetLamps で切り替える）。
       倍率が 0 か 1 のときだけ今と同じになる（途中の値を使いたくなったら合わない）
 ★4 懐中電灯の「どこから照らすか」の渡し方
     A（おすすめ）ILightSocket（2-3）。HoldComponent が実装し、持った銃の部品へ渡す
     B SceneLights が今のまま HoldComponent に銃口を聞く（懐中電灯だけ特別な道が残る。街灯だけ部品の形になる）
