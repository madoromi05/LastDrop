0. 何が問題か
 千切れた部位（腕・脚・頭）は、1 つずつ「飛ぶ → 地面で止まる → 沈んで消える」自分の寿命を持つ物なのに、
 EffectManager の中の並び（SeveredLimbList）が持ち、外から進めて、外から「消えたか」を毎ティック探して消している。
   ・設計思想.md「物の寿命は物が決める。外の係が『消えたか』を毎回探して消すのではなく、部品が自分で消す印を付ける」と逆の形
     （ゾンビの死体は ZombieCorpseComponent が自分で消す印を付けている）
   ・EffectManager は「数が多いので GameObject にしない物」（弾痕・砂ぼこり・血）の置き場所だが、
     千切れた部位は上限 24 個で、数の心配が無い。1 つにゾンビ 1 体ぶんのメッシュを持つ、重くて少ない物
   ・EffectManager::update が、千切れた部位のためだけに地面（ground）を引数で受け取っている

1. 今の形
   SeveredLimb（Zombie/Damage/。190 行）      1 つの部位。飛ぶ・止まる・沈む・描く・消えてよいか（isGone）
   SeveredLimbList（Zombie/Damage/。37 行）   持ち主。上限 24（超えたら一番古い物を消す）・乱数（回る軸と速さ）・全部進める・全部描く
   EffectManager::spawnSeveredLimb            切れた瞬間の姿勢を写し、切り口に血しぶきを出し、SeveredLimbList へ足す
   EffectManager::update( ground )            ほかのエフェクトと一緒に進める（GameWorld::update の World.effects。ゾンビが考える前）
   EffectManager::drawSeveredLimbs            WorldRenderer::drawCharacters・drawShadowCasters から（ゾンビの後）
   呼ぶのは CombatResolver::hitZombie（部位が 0 になった弾の 1 発ごと）

2. 分けた後の形
 2-1 千切れた部位の物（タグ SeveredLimb を足す。名前 "SeveredLimb"）
   部品は 1 つ：SeveredLimbComponent（新。GameSrc/Zombie/Component/SeveredLimbComponent.h / .cpp）
     作るときの引数は SeveredLimb と同じ（形・切り口の決まり・切れた瞬間の姿勢・弾の向き・乱数）
     updatePhase … Late（★2）
     start       … 落ちる先の地面を共有の棚から引く（★3）
     update      … 中の SeveredLimb を 1 ティック進め、沈み終えたら自分の物に消す印を付ける（ZombieCorpseComponent と同じ形）
     draw( culling ) … 中の SeveredLimb を描く（描く側が全部の SeveredLimbComponent をたどって呼ぶ）
   置き場所・見た目・動きを別々の部品に分けない。飛び方と描く箱が同じ中心を使う 1 つの仕事なので、分けると互いの中をのぞく口が増える
   （設計思想.md「同じデータの並べ方を知らないと書けない仕事は、クラスを分けない」）

 2-2 SeveredLimb（★1）
   今のクラスを残し、SeveredLimbComponent が中に 1 つ持つ（MuzzleFlashComponent が MuzzleFlash を持つのと同じ形）
   飛び方・止まり方・沈み方・姿勢の書き換え（BonePoseModifier）のコードには触らない

 2-3 SeveredLimbFactory（新。GameSrc/Zombie/Damage/SeveredLimbFactory.h / .cpp）
   千切れた部位の物を組み立てる。今の SeveredLimbList から「上限」と「乱数」を引き継ぐ
     spawn( world, data, cut, worldPose, direction ) → GameObject*
        ・上限 24：今ある数が上限以上なら、古い方から（数 − 上限 + 1）個に消す印を付ける
          （同じティックに 2 つ出ても、flush の後に 24 個へ戻る。古い順は、SeveredLimbComponent を全部たどる順＝spawn した順）
        ・物を作り、SeveredLimbComponent を付けて spawn する
     乱数は今と同じ種（4517）で、ここが 1 つ持つ（出る順に同じ値が出る＝回る軸と速さは今と同じ）
   持ち主は CombatResolver（部位が 0 になったら出す、と決めている所）
   SeveredLimbList は消す

 2-4 CombatResolver
   今の EffectManager::spawnSeveredLimb の中身（4 行）を、private の severLimb( mesh, model, part, direction ) として持つ
      切れた瞬間の姿勢を写す（作業領域 mSeverPose を EffectManager から移す）
      → 切り口の決まりを設計図から引く
      → 切り口に血しぶきを出す（EffectManager::spawnSeverBlood）
      → 千切れた部位の物を出す（SeveredLimbFactory::spawn）
   順番（血しぶき → 部位）は今と同じ

 2-5 EffectManager
   ・spawnSeveredLimb を spawnSeverBlood( 切り口の位置, 弾の向き ) に替える（血しぶきだけを出す。量は今と同じ kSeverBloodScale）
   ・update の引数 ground を消す。drawSeveredLimbs・mSeveredLimbs・mSeverPose を消す
   ・説明のコメントから千切れた部位を外す（弾痕・砂ぼこり・血しぶき・血の跡の持ち主になる）

 2-6 描く・進める
   WorldRenderer::drawCharacters・drawShadowCasters：mEffects->drawSeveredLimbs( culling ) の行を、
      全部の SeveredLimbComponent をたどって draw( culling ) を呼ぶ行に替える（ゾンビの後、という位置は同じ）
   GameWorld::update：mEffects.update() から ground が消える。千切れた部位は Late の段（mObjects.update( UpdatePhase::Late )）で動く

 2-7 地面（★3）
   TownEnvironment::build の中で、町の地面（TownGround）を共有の棚へ置く（objects->provide）
   SeveredLimbComponent が start で引く。落ちる先は今と同じく地面だけ（建物・車の上には乗らず、抜ける）

3. 依存の向き（一方通行のまま）
   CombatResolver ─→ SeveredLimbFactory ─→ SeveredLimbComponent ─→ SeveredLimb・TownGround（共有の棚。IRayBlocker として使う）
   CombatResolver ─→ EffectManager（血しぶき）
   WorldRenderer ─→ SeveredLimbComponent（draw）
   ・EffectManager は千切れた部位を知らなくなる（GameObject を知らないまま）
   ・SeveredLimb は部品も物も知らない（今のまま）

4. 手を付けない所
   ・SeveredLimb の中身（飛び方の数値・回り方・沈み方・描く箱）
   ・ゾンビの体の側の欠損（ZombieDismemberment）・切り口の決まり（ZombieSeverLayout）
   ・弾痕・砂ぼこり・血しぶき・血の跡（EffectManager のまま。GameObject にしない）

5. 外から読む所
   ・F6 のエディタの物の一覧（EditorWindow.cpp）：タグ SeveredLimb の名前の行を足す
   ・GameWorld.h のコメント「建物・地面・飛ぶ弾・エフェクトは GameObject にしない」に、千切れた部位は物、と書き足す

6. 変わってしまう所
   ・F6 の Objects の欄に、千切れた部位が 1 つずつ出る（最大 24）
   ・進める時：今はゾンビが考える前（World.effects）。後はゾンビが考えた後（Late の段）。千切れた部位は地面しか読まず、
     ゾンビも千切れた部位を読まないので、動きは同じ。出たティックに 1 回進むのも同じ（出るのは弾の解決で、Late より前）
   ・計測：千切れた部位を進める時間が、World.effects から World.late へ移る（印の名前は変えない。前の記録と比べるとき、
     部位を千切った場面では effects が少し減り late が少し増える）
   ・消える時：今は沈み終えたティックの update の中ですぐ。後はそのティックの終わりの flush。描画からは同じ
   ・上限を超えたとき：今は一番古い物をすぐ消す。後は消す印を付け、そのティックの終わりに消える。描画からは同じ
   ・回る軸・速さの乱数は、同じ種・同じ並びのまま（Factory が 1 つ持つ）
   ・処理の順番（上のほか）・数値・ログの文字・保存ファイルは変えない

7. 決めてほしい所（★）
 ★1 SeveredLimb クラスの扱い
     A（おすすめ）残して、SeveredLimbComponent が中に 1 つ持つ。飛び方のコードに触らないので、見た目が変わる心配が無い
       （4 番目の Interactor は作り替えたが、あちらは 50 行で、作るときの引数ごと形が変わった。こちらは 190 行の動きがそのまま使える）
     B SeveredLimbComponent に作り替える（SeveredLimb は消す。ファイルは 2 つ減るが、動きのコードを全部移し替える）
 ★2 どの段で動かすか
     A（おすすめ）Late（今ある段。銃口の光と同じ）。段を増やさない。進める時がゾンビの前から後へ移る（6 章。動きは同じ）
     B 新しい段 Effect を足し、今と同じ所（弾の解決の後・ゾンビの前）で呼ぶ。時も計測も今と同じになるが、段が 4 つになる
 ★3 落ちる先の地面の渡し方
     A（おすすめ）町（TownEnvironment）が地面を共有の棚へ置き、部品が引く。落ちる先は今と同じ地面だけ
     B 部品が共有の棚の HitWorld（弾を止める物の全部）に聞く。棚へ置く物は増えないが、車・建物の上にも乗るようになる（遊びが変わる）

8. 手順
   1. TownEnvironment::build で地面を共有の棚へ置く
   2. SeveredLimbComponent・SeveredLimbFactory を作る。タグ SeveredLimb を足す
   3. CombatResolver：severLimb を作り、SeveredLimbFactory を持つ。EffectManager::spawnSeverBlood に替える
   4. WorldRenderer の描く 2 か所を替える。GameWorld::update の mEffects.update から ground を消す
   5. EffectManager から千切れた部位を消す。SeveredLimbList.h / .cpp を消す
   6. vcxproj と filters：SeveredLimbList の 2 つを外し、新しい 4 つを登録する
   7. Debug・Profile・Release の 3 構成でビルド
   8. この仕様書の状態欄、GameChats/ComponentSystem.md、設計思想.md、メモリを更新

9. 画面で確かめる所
   ・ゾンビの腕・脚・頭を撃って千切ると、部位が弾の向きへ回りながら飛び、地面で止まり、10 秒ほどで沈んで消える
   ・切り口から血しぶきが出る
   ・千切れた部位に影が落ちる（懐中電灯・月）
   ・たくさん千切っても落ちない（24 個を超えたら古い物から消える）
   ・F6 の Objects の欄に SeveredLimb が出て、消えると一覧からも消える
   ・F6 でゾンビを止めている間も、千切れた部位は動く
