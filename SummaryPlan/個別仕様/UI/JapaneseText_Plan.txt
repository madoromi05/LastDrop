 0. 決めること（★はおすすめ）
================================================================================
 Q1. 英語を残すか
     ★A：日本語だけにする（英語の文字は日本語に書き換えて消す）。依頼の「置き換えたい」どおり。
      B：設定画面に「言語」を足し、英語と日本語を切り替えられるようにする（タルコフと同じ）。
         文字を 1 か所の表に集める作業と、settings.xml の項目が増える。

 Q2. 文字の置き場所
     ★A：今のまま、各画面の .cpp の先頭の定数（kHeading など）を日本語に書き換える。
         置き場所が変わらないので「この画面の文字を直したい」の入口は今と同じ。
      B：UiText.cpp などの 1 か所の表に全部集める（Q1 で B を選ぶならこちらが要る）。

 Q3. 途中から初めて出る文字をどう作るか
     （今は「最初の描画より前に、使う文字を全部作っておく」作り。DX11 版の画像は GPU へ送った後に描き足せないため。2 章）
     ★A：文字の画像だけ CPU 側の画素を残し、新しい文字を描いたら GPU へ送り直す。
         GameLib の Texture に「後から書き足せる画像」の作り方を 1 つ足す。どの文字でも出せるので、書き忘れで止まることが無い。
         CPU 側に残る量は 512×512×4 = 1MB × 文字の画像の枚数（数枚）。
      B：起動時に、使う日本語の文字の一覧から全部作っておく。一覧に無い文字を出すと止まる（ASSERT）。
      C：JIS 第 1 水準（約 3000 字）を起動時に全部作る。108px の大きさだと数百 MB になるので不可。

 Q4. フォント
     ★A：Yu Gothic UI（太字）。Windows 10 以降に必ずある。ゴシック体で小さくても読みやすい。英数字もきれい。
      B：Meiryo UI（太字）。少し丸く、横に広い（説明の行がはみ出しやすい）。
      C：BIZ UDPGothic。読みやすさ重視のフォント。Windows 10 の途中から入った物で、古い Windows に無い。
     ※ 今の Arial には日本語の字が無いので、変えないと日本語は出ない。英数字も同じフォントで描く（混ぜると高さと線の太さが揃わない）。

 Q5. 大きい見出し（タイトル名・PAUSED・DAY 3 SURVIVED・KILLED IN ACTION など）
     ★A：見出しも日本語にする。タイトル名「ZOMBIE ESCAPE」だけは仮の名前なので英語のまま。
      B：大きい見出しは英語のまま（雰囲気を残す）、ボタン・説明・項目名だけ日本語。

 Q6. 確認用の表示（F3 のゾンビの体力・F6 の ImGui エディタ）
     ★：英語のまま（遊ぶ人が見る物ではない）。
         ただし F6 の物の一覧は物の名前（ItemSpec::name）を出しているので、日本語にすると ImGui の初めの字（英数字だけ）で「?」になる。
         → F6 では内部の名前（"fuel" などの saveName）を出すように変える。

 Q7. キーの名前（[Enter] [Tab] [Esc] [F] [E]）
     ★：英語のまま（キーボードに書いてある字と同じ）。説明の言葉だけ日本語にする。例：「[Enter] 拾う」

 1. タルコフでは
================================================================================
 ・設定（SETTINGS）の「Interface Language」で言語を選ぶ作り。日本語は 2020 年 7 月にテストで入った。
   出典：https://www.gamespark.jp/article/2020/07/28/100862.html
 ・最初の日本語フォントは読みにくいと言われ、2020 年 11 月にゴシック系の読みやすいフォントへ変わった。
   変え方は「SETTINGS」から「Interface Language」を「jp」。
   出典：https://automaton-media.com/articles/newsjp/20201121-143974/
 ・翻訳は公認のボランティアチームがしていた。
   出典：https://www.gamebusiness.jp/article/2020/01/14/16622.html
 ・正式版（2025-11-15）の後の今の日本語の状態は、調べて分からなかった。

 合わせる所：ゴシック体の読みやすいフォント（Q4 ★）。
 あえて変える所：言語の切り替えは作らない（Q1 ★A）。このゲームは日本語だけで遊ぶ人に見せる物で、
                 切り替えの作り（表・設定の項目）を足しても今は使う人がいない。要るようになったら Q2 を B にして足す。

 2. 今のコードで関係するところ（日本語が出ない理由）
================================================================================
 ① 文字のコード：プロジェクトは /utf-8 なので、"拾う" のような文字列は UTF-8 のバイトで入る。
    ところが GameLib::Scene::StringRenderer は Shift_JIS として 2 バイトの字を切り出している（StringRenderer.cpp 89〜95 行）。
    → UTF-8 の日本語はバラバラのバイトとして読まれ、化ける。
 ② フォント：UiRenderer.cpp の kFontName が "Arial"。日本語の字が無い。
    FontImplOS は GetGlyphOutlineA（Shift_JIS のコードを受ける）で字を描いている。
 ③ 途中から出る文字：DX11 版の Texture は GPU へ送った後に CPU 側の画素を捨てる（TextureImpl.h の ensureGpuUploaded の最後）。
    だから UiRenderer::prepareGlyphs で ASCII の 95 字を最初に全部作っている。日本語は数が多いので同じやり方ができない（Q3）。
 ④ 文字の幅：UiRenderer::textWidth は 1 バイトずつ数えている。中央揃えの位置がずれる。
 ⑤ 大文字にする所：RaidHud::exitNames が toupper で脱出点の名前を大文字にしている（日本語には要らない）。

 3. やること・やらないこと
================================================================================
 やること
  ・GameLib の文字の読み方を UTF-8 にする（StringRenderer と UiRenderer::textWidth で同じ読み方を使う。1 か所にまとめる）
  ・OS のフォントを Unicode で描く（GetGlyphOutlineW）
  ・文字の画像を後から書き足せるようにする（Q3 ★A）
  ・フォントを Yu Gothic UI に（Q4 ★A）
  ・遊ぶ人が見る UI の文字を全部日本語にする（4 章の表）
 やらないこと
  ・言語の切り替え（Q1 ★A）
  ・F3・F6 の確認用の表示の日本語化（Q6）
  ・Framework::drawDebugString（別物。ASCII だけなので UTF-8 にしても変わらない）
  ・ゲームのタイトル名（Q5。仮の名前のまま）

 5. 変える所（ファイルごと）
================================================================================
 GameLib
  ・Base/Utf8.h（新規）：UTF-8 の 1 字を読む関数 decodeUtf8( const char* text, int* byteCount ) → コードポイント。
      StringRenderer と UiRenderer::textWidth が同じ物を使う（読み方を 2 か所に書かない）。
  ・Scene/StringRenderer.cpp：Shift_JIS の切り出し（89〜95 行）を decodeUtf8 に置き換える。
  ・Scene/FontImplOS.h：GetGlyphOutlineA → GetGlyphOutlineW。文字の画像を「後から書き足せる画像」で作る。
  ・Graphics/Texture.h・TextureImpl.h：後から書き足せる画像の作り方を足す（Q3 ★A）。
      その画像だけ ensureGpuUploaded で CPU 側の画素を捨てず、unlock の後の次の描画で送り直す。他の画像は今と同じ。
  ・ビットマップのフォント（BitmapChar の mCode は Shift_JIS）は使っている所が無いので触らない（コメントで「UTF-8 のコードポイント」に直すかは実装で確認）。
 GameSrc
  ・UI/UiRenderer.cpp：kFontName を "Yu Gothic UI" に。textWidth を decodeUtf8 で 1 字ずつに。
      prepareGlyphs（ASCII の先作り）は Q3 ★A なら要らなくなるので消す（理由のコメントも一緒に）。
  ・4 章の各 .cpp の定数を日本語に書き換える。
  ・Scene/Game/RaidHud.cpp：exitNames の upper を外す。
  ・DebugMode/EditorWindow.cpp：物の一覧を saveName で出す（Q6）。

 修正の入口（できあがった後）
  ・言い回しを直す → 各画面の .cpp の先頭の定数（Q2 ★A）
  ・フォントを変える → UiRenderer.cpp の kFontName だけ

================================================================================
 ・タイトル → 設定 → 操作の一覧 → 拠点 → 町（カバン・拾う）→ 脱出 → 結果 → 5 日間の終わり、を全部開いて日本語が出るか見る。

 7. 懸念点
================================================================================
 ・はみ出し：ボタンの幅・説明の行の幅が英語に合わせてある。はみ出したら UiScreen.cpp 等の幅の定数を広げる（画面で見てから）。
 ・文字の画像の枚数：日本語は字の種類が多いので、大きい見出し（4K で 1 字 216px）だと 512×512 が数枚になる。
   いまの描き方は画像が変わるたびに描くまとまりを分けるので、描く回数が数回増える（UI だけなので小さい）。
 ・FontImplOS の Char::mWidth は unsigned char（255px まで）。8K のような大きい画面で見出しを作ると溢れる。今の範囲（4K まで）では大丈夫。
 ・Yu Gothic UI が無い Windows（7・8）では、Windows が別のフォントに置き換える。対象外とする。
