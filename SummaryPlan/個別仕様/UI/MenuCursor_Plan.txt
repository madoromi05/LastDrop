 1. 今の作り
================================================================================
  ・窓のクラスの登録（GameLib/src/WindowCreator/WindowCreator.cpp の MyRegisterClass）で、
    カーソルを Windows の標準の矢印（IDC_ARROW）にしている
  ・遊んでいる間は Input の ManagerImpl が ShowCursor( FALSE ) で隠し、メニュー・カバン・結果の画面を開くと出す
  ・F6 のエディタを Alt で触っている間だけ、ImGui が自分でカーソルの形を変える（DebugUi::applyMouseFlags）

 2. タルコフでは
================================================================================
  ・Web では、タルコフのメニューのカーソルの形を説明した資料は見つからなかった
    （探した所：https://forge.sp-tarkov.com/mod/1365/ui-fixes など。カーソルの話は無かった）
  ・カーソルは遊びの手応えに関わらないので、今回は見た目の好みで決める
    （タイトルなどのメニューの RE:2 風のモックの色に合わせる）

================================================================================
 3. 形（決まった物）
================================================================================
  ・左上の先で指す、細い矢印（普通の矢印より細い）
  ・中は黒（#050505）、縁は骨色の白（#e8e4dc。メニューの文字と同じ色）
  ・32×32 の絵の上での形（左上が 0,0）：
      (2,2) (2,23) (7.5,18) (11,26) (13.6,24.8) (10.2,17) (17,16.8)
      縁の太さ 1.4・指す点（ホットスポット）は (2,2)
  ・黒い背景では白い縁の線だけが見え、明るい背景では黒い矢印に見える

 4. 決めること（★はおすすめ）
================================================================================
 Q1. 作り方
     ★A：Windows のカーソルそのものを差し替える（.cur のファイルを作り、窓のクラスに登録する）
          ・Windows が描くので、フレームの遅れが無い（マウスの動きにぴったり付いてくる）
          ・出す・隠すは今の ShowCursor のまま。画面ごとの変更は要らない
      B：ゲームの UI としてカーソルの絵を描く（OS のカーソルは隠したまま）
          ・1 フレーム遅れて付いてくる。メニュー・カバン・結果の画面すべてで描く必要がある

 Q2. 大きさ
     ★A：32・48・64 画素の 3 つを 1 つの .cur に入れ、Windows の拡大率で選ばせる
          （150% の画面で小さすぎにならない）
      B：32 画素だけ

 Q3. ファイルが無い・読めないとき
     ★A：標準の矢印のまま起動する（カーソルが無くても遊べるので止めない）
      B：Debug では止める（ほかの UI の絵と同じ）

 Q4. F6 のエディタを Alt で触っている間
     ★A：今のまま ImGui に任せる（窓の端の矢印・文字入力の I など、意味のある形が出る。Debug の道具だけ）
      B：エディタの中も黒い矢印にする

 5. 変える所（★のとき）
================================================================================
  ・tools/texgen/cursor_gen.py（新しく作る）
      3 章の形を 32・48・64 画素に描き、Resource/UI/cursor.cur に書く
      縁はなめらかにする（1 画素を 4×4 に分けて数える）。ほかの texgen と同じく Blender の python.exe で動かす
      tools/README.md の一覧に 1 行足す
  ・GameLib：WindowCreator::Configuration に setCursorFile( const char* path ) を足す
      MyRegisterClass で、指定があれば LoadImage( LR_LOADFROMFILE | LR_DEFAULTSIZE ) で読む。読めなければ IDC_ARROW
      読んだカーソルは終わるときに DestroyCursor で消す
  ・Framework.cpp の WindowCreator::configure で setCursorFile( "Resource/UI/cursor.cur" ) を呼ぶ
      （題名の文字列と同じ所。ゲームごとに違う物なので GameLib には書かない）

================================================================================
 6. 懸念点
================================================================================
  ・Windows の「マウスポインターのサイズ」を大きくしている人には、LR_DEFAULTSIZE の大きさが 64 を超えることがある
    → いちばん近い 64 を Windows が拡大する（少しぼやけるが形は崩れない）
  ・ゲームの外（窓の枠やタスクバー）では、いつもの Windows の矢印に戻る（窓の中だけ変わる）

 8. 実装（2026-11-12）
================================================================================
  ・tools/texgen/cursor_gen.py を作り、Resource/UI/cursor.cur（32・48・64 画素・約 30KB）を書いた
  ・GameLib：WindowCreator::Configuration::setCursorFile を足した。Impl::loadCursor が MyRegisterClass で読み、
    ~Impl で DestroyCursor する
  ・Framework.cpp の configure で setCursorFile( "Resource/UI/cursor.cur" ) を呼ぶ
  ・確かめたこと
      Debug・Release・Profile（x64）のビルドが通った
      Windows の LoadImage で 3 つの大きさとも読め、黒い背景と灰色の背景に描いて形を見た
      Release を起動し、タイトルの上でカーソルが標準の矢印と別の物になっているのを GetCursorInfo で見た
  ・まだ確かめていないこと：一時停止・カバン・結果の画面、F6 のエディタ、150% など拡大率を変えた画面
