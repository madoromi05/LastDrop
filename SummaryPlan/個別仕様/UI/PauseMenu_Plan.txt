================================================================================
 0. 決定事項
================================================================================
 ★ ボタンは上から Resume / Retry / Title / Quit（ユーザー選択。おすすめの 3 つに Quit を足した）
   今は RESUME / OPTIONS / RETRY / TITLE / QUIT（Options は OptionsMenu_Plan.txt で足し、大文字と RE:2 風の見た目は MenuRestyle_Plan.txt）。
   RETRY は全部を新しく引き直して町へ（SimpleRun_Plan.txt C1）
 ★ ESC は一時停止に置き換える（ユーザー回答・おすすめ）。ESC で止めてメニューを出し、カーソルを外す。
   もう一度 ESC か Resume で戻ってカーソルをロックする。窓が裏に回ったときも自動で止める

--------------------------------------------------------------------------------
 決まりごと（Claude の判断。確かめてもらう）
--------------------------------------------------------------------------------
 ・止める物：世界（ゾンビ・弾・自キャラ）と音のすべて。画は止めた瞬間の物を描き続け、上に半透明の黒を重ねてメニュー
 ・見出しは「PAUSED」（白）。並べ方はタイトル・クリア画面と同じ（同じ組み立てを使う）
 ・止めずにカーソルだけ外す操作は無くなる（ESC は一時停止）。クリックでロックし直す仕組みは、止めていない間だけ残す
 ・死んで暗くなっている間も止められる
 ・Debug の F キー（F1〜F4・F9）は止めている間は効かない
 ・ゲームオーバー・クリア画面には出さない（本編の中だけ）

================================================================================
 1. 作り
================================================================================
  クラス                         変更
  -----------------------------  ----------------------------------------------------------
  Scene/Menu/MenuLayout（新規）  見出しとボタンを縦に並べる組み立て。MenuScene のコンストラクタから抜き出して、
                                 一時停止と共有する（画面を足しても並べ方が 1 か所）
  MenuCatalog                    pause( onResume )：見出しと 4 つのボタン（Resume だけ呼ぶ側の処理）
  Scene/Game/PauseMenu（新規）   止めているか・メニューの UiScreen・暗くする板。open / close / handleInput / draw
  GameScene                      beginFrame で ESC・窓が裏に回ったかを見て開く。開いている間は入力を読まず、
                                 update で世界を進めない。draw は世界を描いた後にメニュー
  AudioEngine                    setPaused（miniaudio の ma_engine_stop / ma_engine_start。鳴っている途中の音も止まり、続きから鳴る）
  FirstPersonControl             updateCursorLock から ESC でカーソルを外す処理を除く（一時停止が外す）

 ・固定ステップ（FixedStepClock）は止めている間も時間を数えるが、GameScene::update が何もしないので、戻った瞬間に
   早送りにはならない（確かめる）

================================================================================
 2. 懸念点
================================================================================
 ・窓が裏に回ったか（WindowCreator::isActive）は、ウィンドウの外をクリックしたときにも false になる。止まりすぎたら
   「最小化したときだけ」に変える
