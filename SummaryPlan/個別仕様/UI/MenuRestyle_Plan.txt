一時停止・設定・操作の一覧を RE:2 風に揃える（MenuRestyle_Plan）
2026-11-10 案。★ は決めてほしい所（おすすめを先に書いた）。承認までコードは変えない。
コードはユーザーが書く。Claude は段ごとに、どのファイルの何を変えるか（変更前 → 変更後）を渡し、書いた物を読んで確かめる。

■ 目的
タイトル（TitleScreen_Plan.txt）と同じ見た目に、一時停止・設定・操作の一覧を揃える。
見本は claude.ai のモック（https://claude.ai/artifact/RHr5y2N5hLMGD8SW4cx5jD の「一時停止」「設定」「操作の一覧」）。
揃え終えたら、中央に板のボタンを並べる今の形（MENU_LOOK_CENTER）はどこからも使わなくなるので消す。

■ 手本のゲームでは
・タルコフ：メニューのボタンの並び・見た目を書いた出典は、タイトルのときと同じく見つからなかった（分からなかった）。
  一時停止は、公式の説明は見つからなかった。オフライン版（SPT）に一時停止を足す MOD がある
  （https://hub.sp-tarkov.com/files/file/2729-pause）ので、元のゲームには無いと考えられるが、確かめられていない。
  → このゲームは一人用なので、ESC の一時停止は今のまま残す（世界を止める・音を止める）。
・見た目はユーザーが選んだ RE:2 風（ゲーム案_確定条件.md「メニュー画面の見た目」）。

■ 画面の中身
1. 一時停止
   ・止めた本編の画の上に黒を重ねる（濃さ 0.6 → 0.74。モックの濃さ）。ぼかしは入れない（★5）。
   ・左上に「PAUSE」と赤い線。タイトルと同じ大きさ・同じ並べ方（MENU_LOOK_SIDE）。ひと言と背景の絵は無し。
   ・行は RESUME / OPTIONS / RETRY / TITLE / QUIT（タイトルに合わせて大文字。押した後の動きは今のまま）。
   ・行のまとまりの「下端」をタイトルと同じ所に揃え、行が多い画面は上へ伸ばす
     （今の決まりのまま 5 行並べると、下の案内に重なるため）。
   ・下の案内：[Enter] 決定  [Esc] 戻る（タイトルと同じ）。
2. 設定
   ・左上に「設定」と赤い線（題名より小さい見出しの字。UI_TEXT_HEADING を足す）。
   ・行：全体の音量 / 効果音の音量 / マウス感度（スライダー）→ 少し空けて 操作の一覧 / 戻る（板なしの行）。
   ・スライダーも板をやめる。選んでいる行はメニューの行と同じ印（上下の細い線・薄れる帯・赤いひし形）。
     バーは細い線、溜まっている所は明るい線、今の値の所に小さなひし形。数字は右。
   ・下の案内：[← →] 値を変える  [Esc] 戻る。
   ・値の範囲・刻み・保存の仕方（ページを閉じるときに settings.xml へ）は今のまま。
3. 操作の一覧
   ・左上に「操作の一覧」と赤い線。
   ・「移動」「戦う」「そのほか」の 3 つのまとまりに分け、まとまりの名前を小さく書く。
     行は 操作の名前（左）と キー（右寄せ。1 つずつ細い枠で囲む。W A S D は 4 つの枠）。行の上に細い線。
   ・列は 2 列（★3）。左の列に 移動・戦う、右の列に そのほか。
   ・キーの名前は今と同じく割り当てから読む（Pad の bindings。パッドの割り当ては出さない ★4）。
   ・下に「戻る」の行。下の案内：[Esc] 戻る。

■ 作る物・変える物（段に分ける。1 段ずつ書いてビルドし、画面で見てから次へ）
段0 前回のコメントを規約に合わせる（CLAUDE.md「コードを書くときに出さない癖」）
   計画書の名前と ★ を、クラス（struct・enum・namespace）の説明以外から外す。
   ・UiRenderer.cpp の kMincho の行、UiScreen.cpp の左寄せの定数の頭、MenuLayout.cpp の無名の名前空間の頭、
     MenuLayout.h の MENU_LOOK_SIDE の行：「TitleScreen_Plan.txt」を消す。
   ・UiKeyHintRow.h のクラスの説明：「★3」を消す。

段1 共通の部品（見た目はまだ変わらない）
   ・SelectionMarks（新しい名前空間。GameSrc/UI/Widget/SelectionMarks.h/.cpp）
     選んでいる行の印（帯・上下の線・赤いひし形）を描く関数と、印の右で文字が始まる x を返す関数。
     UiMenuItem の drawSelectedMarks をここへ移す（UiSlider も使うので 1 か所にする）。
   ・KeyCap（新しい名前空間。GameSrc/UI/Widget/KeyCap.h/.cpp）
     キーの名前を細い枠で囲んで描き、右端の x を返す関数。UiKeyHintRow の枠を描く所をここへ移す
     （操作の一覧の行も使うので 1 か所にする）。
   ・UiMenuItem に字の間を引数で渡す（英字の大文字は広く 5、日本語は 2.4。「操作の一覧」「戻る」の行は日本語なので）。
   ・見出し（UI_TEXT_HEADING・buildSideHeading）は使い始める段3で足す（段1で足すと、段3まで使わない物が残る）。
段2 一時停止
   ・MenuCatalog::pause を MENU_LOOK_SIDE に、行の文字を大文字に。
   ・UiScreen::sideMenuItemRect に行の数を渡し、まとまりの下端を揃える（タイトルの 3 行は今と同じ位置になる）。
   ・PauseMenu の暗くする板の濃さを 0.74 に。
段3 設定
   ・UiRenderer に UI_TEXT_HEADING（游明朝・32・細字）を足す。
   ・MenuLayout に「左上の見出しと赤い線」を足す関数 MenuLayout::buildSideHeading を足す（設定・操作の一覧が使う）。
     位置は UiScreen::sideHeadingPosition・sideHeadingRuleRect を足す。
   ・UiSlider の見た目を作り直す（板なし・SelectionMarks・細いバーとひし形・游明朝）。値の動かし方は変えない。
   ・OptionsPage：buildSideHeading・左寄せの行（UiScreen::sideSettingRowRect を足す）・
     操作の一覧 / 戻る は UiMenuItem・下の案内（UiKeyHintRow）。
段4 操作の一覧
   ・UiKeyBindingRow（新しい部品）：操作の名前・キーの枠（KeyCap）を右寄せ・行の上の細い線、を描くだけ。
   ・ControlsPage：まとまりの表（名前と行の並び）に作り直す。キーの名前は 1 つずつの並び（W, A, S, D）で返す。
     位置は UiScreen::controlsGroupPosition・controlsLineRect を足す。戻るは UiMenuItem。
段5 片付け（使わなくなった物を消す）
   ・MENU_LOOK_CENTER と buildCenter、MenuDefinition::headingColor と MenuCatalog の kTitleColor・kPauseColor、
     UiScreen の headingPosition・menuButtonRect・settingRowRect・settingButtonRect・listLinePosition・listButtonRect と
     その定数。UiButton は RaidEndScene が使うので残す。UI_TEXT_LARGE も HUD などが使うので残す。

■ 影響範囲
・タイトル・一時停止・設定・操作の一覧の見た目だけが変わる。押した後の動き・ページの行き来・設定の保存は変えない。
・UiButton を使う RaidEndScene（ゲームオーバー・脱出成功）は変わらない（揃えるのは別の段）。
・修正の入口：色は MenuPalette.h、位置は UiScreen.cpp、文言は MenuCatalog.cpp・OptionsPage.cpp・ControlsPage.cpp。

■ 決めてほしいこと
★1 一時停止の右の欄（今回の条件・目的・経過・倒した数。モックにある）
   おすすめ：今回は作らない（見た目を揃えるのが先。欄はゲームの状態を読むので別の段にする）。
★2 選んでいる行の説明（モックの一時停止の左下・設定の右の「説明」）
   おすすめ：作らない（選び直すたびに文字を変える仕組みが要る。行の名前だけで分かる）。
★3 操作の一覧の列の数
   おすすめ：2 列（始めの窓 640×480 でも字を小さくせずに収まる）。
   ほか：モック通り 3 列（4:3 の窓では「銃を出す／しまう」が収まらず、字を小さくすることになる）。
★4 パッドのキーの表示
   おすすめ：今まで通り出さない（キーとマウスの割り当てだけ）。
★5 一時停止の後ろのぼかし
   おすすめ：入れない（ぼかしは後処理のシェーダーを足す作業になる。暗くするだけにする）。
