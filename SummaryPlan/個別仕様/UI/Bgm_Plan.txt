■ ゲームにつなぐ
1. 音のファイル
   ・Resource/Sound/ に bgm_title_0.wav・bgm_gameover_0.wav・bgm_escaped_0.wav を置く（録音と同じ扱い。SoundGen は上書きしない）。
   ・SoundCatalog の SoundId の最後に SOUND_BGM_TITLE・SOUND_BGM_GAMEOVER・SOUND_BGM_ESCAPED を足す。
     最後に足すのは、SoundGen の乱数の種が目録の並びの番号で決まり、途中に足すと後ろの合成音が変わるため。
   ・SoundReadme.md に「BGM」の節を足す。
2. 読み込み方（AudioEngine）
   ・曲は 1 曲 15MB 前後あるので、起動のときに全部を展開しない。鳴らすときにファイルから少しずつ読む（miniaudio のストリーム）。
     目録の行に「流して読む」印を付け、印のある音だけ起動のロードを飛ばす。
     起動のロードは今の 0.81 秒から増えない見込み（読むのは鳴らし始めた時だけ）。
   ・バスに BUS_MUSIC を足す（効果音・環境音と別に音量を変えられるように）。
3. 曲を鳴らす係（新しいクラス MusicPlayer。GameSrc/Audio）
   ・責任は「今の曲を 1 つだけループで鳴らす」こと。
   ・play( SoundId )：同じ曲が鳴っていれば何もしない（タイトルから設定のページへ行っても曲が頭に戻らない）。
     違う曲なら前の曲を止めて、新しい曲を鳴らし始める。
   ・stop()：今の曲を止める。
   ・切り替えは、鳴らし始めを 1 秒で大きく、止めるのを 0.8 秒で小さくする（★4。miniaudio のフェードを使う）。
   ・持ち主は GameResources（シーンをまたいで 1 つ。音の装置 AudioEngine の隣）。
4. どこで鳴らすか
   ・タイトル：MenuScene が作られたときに、MenuDefinition に書いた曲を鳴らす。
     曲は MenuCatalog::title() の中身に書く（画面ごとの違いは MenuCatalog の 1 か所、の決まりに合わせる）。
   ・結果の画面：RaidEndScene が、クリアなら SOUND_BGM_ESCAPED、死んだなら SOUND_BGM_GAMEOVER を鳴らす。
   ・出撃：GameScene が作られたときに stop()（★2）。ロード画面の間に曲が小さくなって消える。
   ・一時停止の画面は今のまま（曲は鳴らさない）。
5. 音量の設定（★3）
   ・設定の「音声」タブに 3 行目「音楽の音量」（0〜100・5 刻み）を足す。初めは 70。
   ・GameSettings に musicVolume を足し、settings.xml に musicVolume として保存する（無ければ 70）。
   ・applyAudio で BUS_MUSIC の音量に反映する。

■ 改訂 2：車の SE をところどころに（2026-11-18）
・依頼：「車の音みたいな SE も所々に足してほしい」
・car_interior.js に、80 秒のループの中の決まった時刻で鳴る出来事を足した。日本は左側通行なので、対向車は右、追い越しも右の車線で。
    12.0 秒  対向車がすれ違う（右。タイヤの音の帯とエンジンの音が、すれ違うときに下がる＝ドップラー）
    25.4 秒  ウインカー 12 回（カチ・コチ。約 83 回/分）
    30.0 秒  右の車線へ移る。タイヤが車線の鋲を踏む「コトッ、コトッ」（前輪・後輪）
    30.4 秒  加速（エンジンのうなりが高く大きくなり、33.6 秒でシフトアップして一度下がる。41 秒で元に戻る）
    37.5 秒  遅いトラックを追い越す（左を後ろへ。ゆっくり、低い音）
    43.4 秒  ウインカー 8 回 → 46.6 秒 左の車線へ戻る（鋲の音）
    62.5 秒  もう一度対向車（右）
  外の音（すれ違う車・トラック）は窓越しなので 2.2kHz より高い音を削る。ウインカーと鋲は車内の音なので、スピーカーの音の加工は通さない。
・大きさは、すれ違う車が曲のピークの 55%、トラック 50%、ウインカー 20%、鋲 22%。エンジンは加速の間だけ最大で約 2 倍になる。
・時刻と大きさは car_interior.js の先頭の PASSES・BLINKS・LANE_CHANGES・REV_KEYS と PASS_KINDS で変えられる。
・エンジンの高さが途中で変わっても、ループの終わりで音の波がちょうど 1 周し終わるように、元の高さを少しずらしている（継ぎ目の段差は 0.0005 のまま）。

■ 改訂 3：SE を大きく・エンジンを高い頻度で（2026-11-18）
・依頼：「全体的に SE の音量を上げてもいい、あとエンジンの音を高頻度でつけて」
・大きさ（改訂 2 → 改訂 3）
    ロードノイズ 曲の 20% → 30%（rms）／エンジン 7% → 16%（rms）
    継ぎ目 35% → 50%／鋲 22% → 35%／ウインカー 20% → 32%（曲のピークに対して）

  曲そのものは、改訂 2 より約 0.7dB 小さくなっただけ（全体の大きさを RMS 0.08 に揃えるため）。
・エンジン
  ・回転の上下を、ループのほぼ全体に入れた（REV_KEYS）。
      2〜11.5 秒   アクセルを戻して下がる → 踏み込んで上がる → 7.4 秒でシフトアップ
      14〜18.6 秒  軽く踏む

■ 改訂 4：音のフォルダを SE と BGM に分ける（2026-11-18）
・依頼：「Resource/Sound の後 SE と BGM で分けて _数字を削除して」
  番号を消すのは「揺らぎが 1 つだけの音は全部」（ユーザーが選んだ。別テイクが 2〜4 個ある音は番号で見分けるので残す）。
・Resource/Sound/SE/ に効果音 67 個、Resource/Sound/BGM/ に曲 3 つ。SoundReadme.md は Resource/Sound/ のまま。
    例：aim_in_0.wav → SE/aim_in.wav、footstep_concrete_0〜3.wav → SE/footstep_concrete_0〜3.wav、bgm_title_0.wav → BGM/bgm_title.wav
・目録（SoundCatalog）：SoundEntry の streamed（bool）を kind（SoundKind：SOUND_KIND_SE / SOUND_KIND_BGM）に替えた。
  置くフォルダと読み方（曲は流して読む）が、この 1 つの値で決まる。AudioEngine は soundStreamed( id ) で読み方を聞く。
  soundFilePath は「Resource/Sound/ + 種類のフォルダ + 名前 +（揺らぎが 2 つ以上なら _番号）+ .wav」を返す。
・SoundGen は soundFilePath で書き出し、フォルダも自分で作るので、コードは説明のコメントだけ直した。
・確かめたこと：目録から作った 70 個のパスが全部あり、余分なファイルも無い。git の上でも元の番号のまま移った（_2 は _2）。
・同日 追加：依頼「SE を敵、Player、武器で分けて」で、SE/ の下を Enemy/（5 個）・Player/（39 個）・Weapon/（23 個）に分けた。
  SoundKind の SOUND_KIND_SE を SOUND_KIND_SE_ENEMY・SE_PLAYER・SE_WEAPON の 3 つに替えた（目録の列は kEnemy・kPlayer・kWeapon）。
  分け方：敵＝ゾンビに当たった・倒れた。武器＝銃声・空撃ち・リロード・出す/しまう・覗く・装備の揺れ・懐中電灯・着弾音。
  Player＝足音・服の擦れ・漁る・給油・車のエンジン・サイレン（3 つのどれにも当たらない車とサイレンは、自キャラの周りの音として Player に入れた）。
