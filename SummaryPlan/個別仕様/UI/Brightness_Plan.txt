 0. タルコフでは
================================================================================
 ・設定の PostFX のタブに Brightness（明るさ）のスライダーがある。PostFX を入れたときだけ効く
 ・攻略記事の値は -20〜100 とばらばらで、0 のままにする人もいる。公式の範囲と初期値は見つからなかった
 ・明るさは、ゲームの設定よりも、GPU のドライバのガンマで上げる人が多い（暗い所だけ持ち上がり、明るい所が白く飛ばないため）
 ・参考：https://primagames.com/tips/lvndmarks-complete-controls-graphics-and-post-fx-settings-in-escape-from-tarkov
         https://www.esports.net/wiki/guides/best-escape-from-tarkov-settings/

 1. 決めること（Q1〜Q5）
================================================================================
 Q1. 明るさの掛け方
     ★A：ガンマ。トーンマップとグレーディングの後の 0〜1 の色を pow( 色, 指数 ) で曲げる
          ・暗い所ほど持ち上がり、白（1）と黒（0）は動かない。月明かりや懐中電灯が白く飛ばない
          ・タルコフでドライバのガンマを使う人が多いのと同じ効き方
      B：露出（exposure）。ACES の前に倍率を掛ける。全体が明るくなり、明るい所はトーンマップで頭打ちになる
          ・F6 の exposure と同じ値を遊ぶ人が触る形になり、調整値とぶつかる

 Q2. 数の範囲と見せ方
     ★A：-50〜+50、5 ずつ、初期値 0。画面には「+10」「0」「-10」の形で出す
          ・指数は 2 の（-値÷100）乗。+50 で 0.71（暗い所が明るい）、-50 で 1.41（暗い所がもっと暗い）
      B：0〜100、初期値 50（音量と同じ見た目）

 Q3. 置き場所
     ★A：設定画面に「画面」のタブを足し、そこに「明るさ」のスライダーを 1 本置く。タブは 音声・感度・画面・操作 の順
      B：感度のタブの 3 本目に置く（タブを増やさない）

 Q4. 確かめ用の絵
     ★A：置かない。出撃中の一時停止の設定画面なら、後ろのゲームの絵がその場で変わるので見ながら合わせられる
          ・タイトルの設定画面は後ろが画像（UI）なので、変えても見た目は変わらない
      B：「うっすら見える」くらいの暗い印を並べた確かめ用の絵を置く（UI はガンマの後に描くので、絵の方にも同じガンマを掛ける仕組みが要る）

 Q5. 掛かる範囲
     ★A：ゲームの 3D の絵だけ。HUD・メニュー・文字は今のまま（UI はガンマの後にバックバッファへ描くので、何もしなくてもそうなる）

 2. 今のコード
================================================================================
 ・Resource/Shader/Present.hlsl：ACES → gradeColorWithLut → ビネット → 噛まれた赤み → 暗転 → linearToSrgb の順
 ・色の定数は PresentConstants.hlsli（C++ は PostProcess.cpp の PresentConstants。16 バイトの並び）
 ・PostProcess は SceneRenderer が毎フレーム setPain・setFade で動かす
 ・GameSettings：音量 3 つと感度 2 つを settings.xml に保存。項目が無い古いファイルは既定値のまま読める
 ・OptionsPage：タブ（音声・感度・操作）ごとに UiSlider を置く。タイトルと一時停止の両方が使う

================================================================================
 3. やること
================================================================================
 a. GameSettings
    ・brightness（-50〜+50・初期値 0・5 ずつ）を足す。settings.xml の属性は brightness
    ・brightnessExponent()：画面に掛ける指数へ直す（2 の（-brightness÷100）乗）。直し方はここだけに置く
 b. PostProcess
    ・setBrightnessExponent( float ) を足し、PresentConstants の最後に gBrightnessExponent を足す（16 バイトにそろえる余りも足す）
    ・Present.hlsl：グレーディングの後・ビネットの前に color = pow( saturate( color ), gBrightnessExponent )
      （ビネット・赤み・暗転は「明るさの設定で変わらない演出」なので後に掛ける）
    ・LutBake.hlsl は同じ定数を読むが、明るさは表に焼かない（表はグレーディングだけを写すため）
 c. SceneRenderer：毎フレーム GameSettings の brightnessExponent を PostProcess へ渡す
    ・GameSettings への道は FirstPersonControl と同じく、作るときにポインタで受け取る
 d. OptionsPage：「画面」のタブと「明るさ」のスライダー。OptionsTab に OPTIONS_TAB_DISPLAY を足す
    ・表示は formatBrightness（+ を付ける）。変えたらすぐ settings に入り、後ろの絵に効く。保存は今の設定画面と同じ所で

================================================================================
 4. 確かめ方
================================================================================
 ・一時停止 → 設定 → 画面 で明るさを動かし、後ろの夜の町の暗い所が持ち上がる・沈むこと。月や懐中電灯の明るい所は白く飛ばないこと
 ・HUD・メニューの色が変わらないこと
 ・settings.xml に brightness が書かれ、次の起動でも同じ明るさになること。brightness の無い古い settings.xml でも起動できること
 ・3 構成ビルド

================================================================================
 5. 懸念点
================================================================================
 ・ガンマで暗い所を持ち上げると、夜の 8 ビットの縞（バンディング）が目立つことがある。今のディザ（±半段）はガンマの後に足すので効く
 ・FXAA は Present の a に入れた輝度で輪郭を探すので、明るさを変えると輪郭の見つけ方が少し変わる（見た目の明るさで探すので、むしろ合う）
 ・タイトルでは効き目が見えない（Q4）
