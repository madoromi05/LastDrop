 1. 決めること（★はおすすめ）
================================================================================
 Q1. ライフル（AKM）はどうするか
     ★A：始めは拳銃だけ。ライフルは町で拾う物にする（R3 の漁る場所ができるまでは、町に 1 丁だけ置いておく）
          ・「始めは弱い → 漁って強くなる → 死んだら失う」の形になり、RaidLoop の芯（失う怖さと漁る欲）に合う
          ・RaidLoop Q10（★A：ライフルは毎回タダ）を「毎回タダでもらえるのは拳銃」に書き換える
      B：拳銃とライフルの両方を始めから持つ（拳銃は予備の武器）
      C：始めはライフル、拳銃は町で拾う

 Q2. 銃をカバンに入れる形
     ★A：持っている銃もカバンの 1 マスを使う（RE:2 と同じ）。手に持っている銃のマスには「E」の印
          ・カバンの画面の項目に「Equip（持つ）」を足す。持っている銃を Drop すると素手になる
          ・ライフルも 1 マス（ユーザーの「一枠」の通り）。大きさは表の cellSize なので、後で 2 マスにするのは 1 行の変更
      B：手に持っている銃はマスを使わず、予備の銃だけがマスを使う（タルコフに近い）

 Q3. 拳銃の弾
     ★A：別の弾（9mm）にする。1 マス 24 発（弾倉 2 本ぶん）。始めは弾倉に 12 発＋カバンに 24 発（1 マス）
          ・どちらの弾をカバンに入れるかが、マス目で迷う材料になる
          ・ゾンビが落とす弾は、そのとき手に持っている銃の弾（素手なら 7.62）
      B：ライフルと同じ 7.62 の弾を使う（作るのは楽だが、2 丁を持つ意味が薄くなる）

 Q4. 拳銃の撃ち方と強さ（数は F6 で動かせるようにする）
     ★A：1 回引くと 1 発（セミオート）。間隔は最短 0.15 秒。弾倉 12 発。
          威力は 7.62 の 6 割（12。ライフルは 20）。反動は小さく、弾道の跳ね上がりも小さい。リロードは 1.5 秒（ライフルは 2 秒）
      B：威力をライフルと同じにする（違いは連射と弾倉だけ）

 Q5. 拳銃を持つ腕のアニメ
     ★A：Mixamo から拳銃のアニメを落とす（Pistol Idle・Pistol Walk・Pistol Run と、拳銃のリロード）。
          今のライフルのアニメと同じ Ch15 の骨で、player.json の extra_animations に足す
          ・落とすのはユーザーの作業（Mixamo の名前と設定は Plan を書き直すときに一覧にする）
          ・リロードのアニメが Mixamo に無ければ、腕だけ今の reloading.fbx を使う（下の B と同じ）
      B：今のライフルのアニメのまま、握りの位置だけ拳銃に合わせる（左手は今の IK で拳銃に寄せる）
          ・アニメを落とさずに済むが、ライフルを抱える腕の形のまま小さい銃を持つので、不自然に見える見込み

 Q6. 銃の持ち替え
     ★A：カバンの画面の「Equip」だけ（開くと世界が止まるので、持ち替えの時間は作らない。RE:2 と同じ）
      B：A に加えて、数字の 1・2 キー（パッドは十字キー）でも持ち替える（持ち替えに 0.5 秒かかる。タルコフ寄り）

 Q7. 銃声
     ★A：拳銃の銃声は今の SoundGen の合成で、軽く高い音を 1 つ足す（SOUND_PISTOL_SHOT）
      B：Downloads/ゾンビゲーム/weapons の録音（Weapon Gun Pistol ... Single Shot）を使う

 Q8. 画面の名前
     ★A：「Pistol」「Rifle」「9mm rounds」「7.62 rounds」（実在の商品名は出さない）
      B：銃の型の名前を出す

 2. タルコフでは（と RE:2 では）
================================================================================
 2-1 タルコフ
  ・装備の枠は「主武器 2 つ（背中と肩）」と「ホルスター（拳銃）1 つ」。装備の枠に付けた銃はカバンのマス目を使わない
    （予備の銃をカバンに入れると、銃の大きさのぶんマスを使う）
  ・拳銃のマス目の大きさ・9mm の弾が 1 マスに何発重なるかは、今回の検索では確かめられなかった（分からなかった）
  ・持ち替えは数字キーで、持ち替えに時間がかかる
  → 取り入れる：拳銃は弱いが軽い予備・弾の種類が違う
  → 取り入れない：装備の枠（RE:2 式に、持っている銃もマスを使う。ユーザーの「銃も一枠」に合わせる）

 2-2 RE:2（2019 年のリメイク）
  ・武器もアイテムと同じマス目に入る。拳銃・普通のサブマシンガンは 1 マス、大きい武器（スパークショット・火炎放射器）は 2 マス
  ・パーツを付けると大きくなる物がある（長い銃身で 1 → 2 マス）
  ・十字キーの上下左右に武器を割り当てて持ち替えられる。カバンの画面からも持ち替えられる
  ・カバンの中の銃はリロードできない
  → 取り入れる：銃もマスを使う・拳銃は 1 マス・カバンの画面から持ち替え
  → あとで考える：十字キーの割り当て（Q6 の B）

 3. 今のコードで関係するところ
================================================================================
  ・PlayerFactory：AKM 1 丁を作って HoldComponent に渡す（kWeaponFile・kMagazineFile・kWeaponName）
  ・GunComponent：FireControl（600 発/分・フルオート）・Magazine（30 発）・WeaponRecoil・WeaponReload を持つ。弾は ITEM_AMMO 固定
  ・WeaponModelComponent：握り・サイト・銃口の位置が AKM の定数
  ・Bullet：威力 kDamage = 20 の定数
  ・HoldComponent：持つ物は 1 つ（コンストラクタで受け取る）。リロードのアニメは "rifle_reload" 固定
  ・ItemCatalog：ITEM_FUEL・ITEM_AMMO。ItemGrid のマスは { ItemId, 数 } だけ（銃の弾倉の中身を持つ所が無い）
  ・InventoryScreen：項目は Drop・Move・Cancel
  ・PropFactory::spawnDroppedItem：ガソリンと弾だけ（銃を落とす形が無い）
  ・CombatResolver::dropAmmo：ゾンビが落とすのは 7.62 だけ

 4. クラスの分け方（案）
================================================================================
  WeaponCatalog（Weapon。新規。ItemCatalog と同じ形の表）
   ・WeaponId（WEAPON_PISTOL・WEAPON_RIFLE）→ WeaponSpec
     { 銃のアイテム（ItemId）, 弾のアイテム（ItemId）, 弾倉の数, 間隔, フルオートか, 威力, 反動, リロードの時間,
       モデルのファイル, 握り・サイト・銃口の位置, リロードのアニメの名前, 銃声 }
   ・今の定数（Magazine・FireControl・Bullet・WeaponModelComponent）をここへ移す。処理は表を読むだけにする
  ItemCatalog
   ・ITEM_PISTOL・ITEM_RIFLE（1 マス・重ねない）・ITEM_AMMO_9MM を足す
  GunComponent・WeaponModelComponent
   ・コンストラクタで WeaponSpec を受け取る（どの銃かは作る側 PlayerFactory が決める）
  HoldComponent
   ・持てる銃を 2 つ（拳銃・ライフル）持ち、どちらを手に持つかを切り替える入口を足す（equip）
   ・弾倉の中身は銃の GameObject（GunComponent）が持ち続ける。カバンのマスは「持っているか」だけ
  Inventory・InventoryScreen
   ・「Equip」の項目・持っている銃の「E」の印
   ・持っている銃を捨てたら素手。捨てた銃は弾倉の弾ごと足元に落ち、拾い直すと弾倉もそのまま
  PropFactory
   ・spawnDroppedItem に銃（拳銃・ライフルのモデルを置く）を足す

 5. 進め方（段階）
================================================================================
  P1 銃の決まりを表へ（WeaponCatalog）。AKM だけで今と同じに動くことを確かめる（見た目・数は変えない）
  P2 拳銃のモデルを変換（tools/configs/pistol.json）・握り・サイト・銃口を Blender で求める・始めの装備を拳銃に
  P3 銃をカバンの 1 マスに（ITEM_PISTOL・ITEM_RIFLE・Equip・捨てる・拾う）・ライフルを町に 1 丁置く
  P4 拳銃のアニメ（Q5 の A なら、ユーザーが落とした後）・銃声
  各段階でビルド（Debug・Release・Profile）

 8. 実装（2026-11-04）
================================================================================
  P1 銃の決まりを表へ
  ・WeaponCatalog（Weapon。新規）：WeaponId（WEAPON_PISTOL・WEAPON_RIFLE）→ WeaponSpec
      { 名前・銃の物・弾の物・形／弾倉／落ちた形のファイル・弾倉・発/分・フルオートか・威力・反動の大きさ・リロード秒・銃声と大きさ・持ち方 WeaponGrip }
      weaponForItem（物の種類 → 銃。銃でなければ WEAPON_NONE）
  ・定数を表へ移した：Magazine（容量）・FireControl（発/分・セミオート）・WeaponReload（秒。アニメは速めて流す）・Bullet（威力は弾ごとに持つ）・
    WeaponModelComponent（握り・サイト・銃口）。GunComponent( spec ) が組み立てる
  ・反動：FirstPersonControl::updateViewEffects( shotRecoil ) にして、ViewRecoil・AimRecoil・画面の揺れへ銃ごとの大きさを掛ける
  ・銃声：PlayerFoley は持っている銃の shotSound と shotVolume で鳴らす
  P2 拳銃のモデル
  ・tools/configs/pistol.json（弾倉と外の弾を除いた形）・pistol_mag.json（弾倉）・pistol_ground.json（地面に寝かせた形）・orm/pistol.json
      G2-Combat.fbx を 0.8 倍（長さ 16cm＝実物）。向きは AKM と同じ（銃口 +Z）なので回さない。画像は 1024・DDS（texture_to_dds.ps1 に足した）
  ・握り・サイト・銃口は頂点から求めた（握り＝引き金の囲いの後ろ・下の箱の真ん中、目＝スライド上端のすぐ上で後ろのサイトの 25cm 後ろ、銃口＝銃身の先）
  ・持ち方の向き・手の中の位置はライフルと同じ値（拳銃の握りを AKM の握りと同じ所に置く）。拳銃のアニメが入ったら合わせ直す
  ・始めの装備は拳銃：ItemSpec の startAmount（拳銃 1・9mm 24・7.62 は 0）
  P3 銃もカバンの 1 マス
  ・ItemId に ITEM_PISTOL・ITEM_RIFLE・ITEM_AMMO_9MM（ITEM_AMMO は ITEM_AMMO_762 へ名前を変えた）・ITEM_NONE
  ・PlayerFactory が銃を全部 1 丁ずつ作り HoldComponent へ渡す。HoldComponent::equip（持ち替え）・syncWithInventory（毎ティック。
    持っている銃が捨てられたら素手、素手でカバンに銃があれば表の順で持つ＝始めの拳銃もこれで持つ）
  ・銃の物は捨てても消えない（弾倉の中身は銃ごとに残る）。地面に落ちた銃は別の置物（PropFactory::spawnWeaponDrop・タグ WeaponDrop）
  ・カバンの画面：銃で、手に持っていなければ「Equip」をメニューの一番上に。手に持っている銃のマスの左上に「E」
  ・町に 1 丁だけライフルを置く（TownMap::rifle。始めの位置から 1 ブロック南の通り）。段階R3 で漁る場所へ移す
  ・ゾンビが落とす弾は手に持っている銃の弾（素手なら 7.62）。9mm の落ちた弾の形は tools/configs/ammo9_drop.json
  P4
  ・銃声（Q7 を変えた）：ライフルの銃声が合成ではなく録音（GunShot.wav）だったので、拳銃も合成ではなく録音
    「Weapon Gun Pistol 9mm Glock Single Shot Interior Shooting Range Short 01.wav」を使う（SOUND_PISTOL_SHOT・pistol_shot_0.wav）。
    合成の音を録音のライフルと並べると音の質がそろわないため。素材がライフルの約 3 倍大きいので、大きさは 0.3 で鳴らす
  ・カバンの絵：icon_pistol・icon_rifle（真横から。銃口が右）・icon_ammo_9mm（Ammo&Prop の 9MM Ammo.fbx）。item_icon_gen.py に
    mesh_names（撮る部品）と camera_elevation・camera_azimuth（物ごとのカメラ）を足した
  ・拳銃のアニメ（Q5 の A）はまだ無い。Mixamo で「Pistol」を検索して、構え・歩き・走りと、拳銃のリロードがあれば落としてもらう
    （拳銃のリロードのアニメが Mixamo にあるかは、まだ確かめていない）

  画面で確かめること
  ① 始め：拳銃を持っている。カバンは拳銃（E）と 9mm 24 発
  ② 拳銃：1 回引くと 1 発・12 発でリロード（1.5 秒）・反動はライフルの半分・銃声が拳銃の音・ADS でサイトが目に合うか
  ③ 町のライフルを拾い、カバンの Equip で持ち替え。7.62 が無ければリロードできない
  ④ 持っている銃を Drop すると、閉じた後に素手→カバンにもう 1 丁あればそれを持つ。落ちた銃を拾い直すと弾倉の弾数がそのまま
  ⑤ ゾンビが落とす弾が持っている銃の弾になる
  ⑥ カバンの絵（拳銃・ライフル・9mm）

  懸念
  ・拳銃をライフルのアニメで持つので、左手は空中の、AKM のハンドガードの所にある（Q5 の B で書いた不自然さ）
  ・リロードもライフルのアニメを速めて流すので、手の動きと拳銃の弾倉の位置がずれる
  ・地面に落ちた銃（pistol_ground・rifle_ground）は横に寝かせただけで、地面にめり込む・浮くかは画面で見る
  ・F6 の Add で同じ銃を 2 つ入れられる（銃の物は 1 丁なので、確認のときだけ気を付ける）
