 3. 分け方の方針
================================================================================
 ・判断（いつ・どれにするか）と計算（どれだけ・どこへ）が 1 つの関数に混ざっている所で、計算の方を持ち主へ移す（Move Function）。
 ・判断も、答えだけを返す関数にできる所は Split Phase で分ける（段階O）。実際に動かす（アニメを流す・状態を変える）のは Zombie のまま。
 ・修正の入口：
     F6 の値の幅・体ごとの値の選び方          → ZombieUncertaintyParams
     どの距離からどれだけ揺れるか              → ZombieSway
     首の突き出し方                            → ZombieFlinch
     這う速さ・腕で引く長さ・胸の置き場所      → ZombieCrawler（中の ZombieCrawl・ZombieCrawlBody）
     撃たれたときに倒れる・よろける等の優先順位 → ZombieDamageReaction
     いつ・どの状態でそれをするか              → Zombie

================================================================================

   ZombieCrawler( const ZombieCrawlLayout* layout, const ZombieDismemberment* dismemberment );

 9. 段階O（カ）：撃たれたときの反応を選ぶ関数（ZombieDamageReaction）
================================================================================
 状態を持たない関数だけのクラス（ZombieAttackReach と同じ形）。★4 案A。
   struct Facts{               // 撃たれた直後の体の様子（Zombie が作って渡す）
       bool canFall;           // 死亡アニメがある（無い確認用の体は倒れない）
       bool isDead;            // 体力が 0
       bool isStanding;        // Alive（Downed ではない）
       bool hasLostFooting;    // 脚を失った
       bool isAttacking;       // 攻撃の最中（ZombieAttack::isActive）
       bool canStagger;        // よろけてよい（アニメがある・間あけが済んだ、または頭）
   };
   enum class Fall{ None, Die, Down };            // 倒れる（Falling へ）・脚を失って倒れる（Downed へ）
   enum class Hit{ None, ShakeOff, Stagger };     // 手を放してよろける・よろける
   static Fall chooseFall( const Facts& facts );
   // 倒れないときだけ呼ぶ。shakenOff: ZombieAttack::takeShakeDamage の答え（振りほどかれた）。
   static Hit chooseHit( const Facts& facts, bool shakenOff );

 Zombie の applyDamage の後半は、
   Fall fall = chooseFall( facts ) → Die なら startFalling、Down なら startDowned
   → None のときだけ takeShakeDamage を数え、chooseHit → ShakeOff なら shakeOff、Stagger なら startStagger
 の形になる（今の if の並びと、呼ぶ順・呼ぶ条件が同じ）。
 ついでに、切れた部位の一覧を ZombieDismemberment へ移す：
   void clearSeveredThisHit(); const std::vector< BodyPart >& severedThisHit() const;（sever が true のときに足す）
   Zombie::severedByLastDamage は、それを返すだけになる。部位の箱を外すのは Zombie のまま（ZombieDismemberment は箱を知らない）。

 10. 分けない所と理由
================================================================================
 ・攻撃のつなぎ全体（canStartAttack・startAttack・approachDuringAttack・updateAttack・shakeOff）：攻撃の段階・アニメ・根の動き・
   向きを変えて寄る・のけぞり・メッシュ・足元と向きを全部使う。まとめて出すと「全部借りる別の Zombie」になる。今回は段階M だけ出す。
 ・立って追うときのつなぎ（chase。約 20 行）：部品を順に呼ぶだけ。段階K で角度の計算は抜ける。
 ・よろけ（canStagger・startStagger・updateStagger）：3 つとも 1〜3 行で、中身はもう ZombieStagger と ZombieAnimationSet にある。
 ・コンストラクタの「乱数を引く順」と「姿勢の書き換えを掛ける順」：組み立てそのもの。外へ出しても置き場所が移るだけ。

 15. 懸念点

 ・段階J は乱数を引く回数が 1 回でも変わると、うろつく先・揺れが全部変わる。幅が逆のときに引かない所を落とさない
