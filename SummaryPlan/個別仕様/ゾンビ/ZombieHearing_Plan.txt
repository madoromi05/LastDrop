 0. 決定事項と未決事項
================================================================================

--------------------------------------------------------------------------------
 決定事項（ユーザー回答。4 問ともおすすめどおり。2026-10-22）
--------------------------------------------------------------------------------
 ★ 銃声が届くのは撃った所から 30m（水平の距離。決めたときは 40m）。建物越しでも同じ（音は回り込むので壁では切らない）
 ★ 聞いたら、撃った瞬間の自キャラの位置へ探しに来る（今の Search と同じ。道探しで建物を回り込む）。
   着いても見えなければ、立ってからうろつく。撃った後に動けば、まける
 ★ 反応するのはうろついている体（Wander）と探している体（Search）。探している体は新しい銃声の所へ向かい直す。
   追っている体（Chase）は今のまま
 ★ 聞いてから動き出すまで、体ごとに 0.2〜1.0 秒のばらつき（一斉に振り向かない）

--------------------------------------------------------------------------------
 決まりごと（Claude の判断。確かめてもらう）
--------------------------------------------------------------------------------
 ・音が出るのは弾が出たときだけ（弾が無くてカチッと鳴るとき・リロードは数えない）
 ・フルオート（0.1 秒に 1 発）で撃ち続けても、待っている遅れは延ばさない（延ばすと撃っている間ずっと動かない）。
   待っている間に次の銃声が来たら、向かう先だけ新しい所に替える
 ・倒れた体・よろけ中・攻撃中は聞かない（よろけ・攻撃が終わってから、待っていた分は続きから数える）
 ・F6 の表示は今の「Search」のまま（見失ったのか銃声なのかは分けない）

--------------------------------------------------------------------------------
 未決事項（作りながら画面で見て決める）
--------------------------------------------------------------------------------
 ・届く距離（30m）・遅れ（0.2〜1.0 秒）は初期値

 1. 前提：今のコードで関係するところ
================================================================================
  項目                今の実装                                      関係
  ------------------  --------------------------------------------  -----------------------------
  撃った              PlayerCharacter::firedThisTick（GameWorld が   ここで近くのゾンビへ知らせる
                      弾を出し、マズルフラッシュを光らせる）
  探す                ZombieChase の Search（行き先へ歩き、着いたら    銃声もこれに乗せる
                      立ってからうろつく）
  回り込む            ZombiePath / NavMesh（ZombieNavMesh_Plan.txt）  そのまま使う
  着けない            ZombiePath::isStuck → giveUpSearch（2 秒）      そのまま使う

================================================================================
 2. 聞こえる・向かう
================================================================================
 ・弾が出たティックに、PlayerNoiseComponent が ZombieHearing::hearGunshot を呼び、30m 以内のゾンビ全員へ
   「ここで銃声がした」と知らせる。届く距離は世界の決まりなので、ZombieHearing の定数にする。
   聞くかどうか（倒れている・よろけている等）は ZombieBrainComponent が決める。
 ・脱出の車のエンジンなどの物音は ZombieHearing::hearNoise。届く距離・寄って来方は銃声と同じ。
 ・ZombieChase::hearNoise( 位置 )：
   - Chase なら何もしない。
   - 待っていなければ、遅れ（0.2〜1.0 秒。体ごとの乱数）を決めて待ち始める。待っている間なら、向かう先だけ替える。
 ・ZombieChase::update：
   - 見えたら Chase（待っていた銃声は捨てる）。
   - 待ち終えたら Search にして、行き先＝聞いた所・歩く。
 ・行き先が別の所へ飛んだら（探している途中で新しい銃声）、ZombiePath はすぐ道を調べ直し、近づけているかを数え直す
   （古い行き先で数えた分で、すぐあきらめないように）。

 3. 要りそうな部品と処理の流れ
================================================================================
  クラス           変更
  ---------------  ----------------------------------------------------------
  ZombieChase           hearNoise・待っている銃声（位置・残りティック・待っているか）
  ZombieBrainComponent  hearNoise（立っていて追ってくる体だけ ZombieChase へ渡す）
  ZombiePath            行き先が 1 ティックで大きく飛んだら、すぐ調べ直して数え直す
  ZombieHearing         hearGunshot・hearNoise。30m 以内のゾンビへ hearNoise（kGunshotHearingRange）

  値（初期値）
  ----------------------------------------  --------
  届く距離                                  30m（ZombieHearing.cpp）
  動き出すまでの遅れ                        0.2〜1.0 秒（ZombieChase.cpp）
  「行き先が飛んだ」とみなす 1 ティックの動き  1m（ZombiePath.cpp。走る自キャラは 1 ティックに 0.05m）

 6. 足音（2026-11-06）
================================================================================
 決定事項（ユーザー回答。2026-11-06）
  Q1 ＝ ★ 歩き 5m・走り 18m・止まっている 0m（自キャラの足元から水平。建物越しでも同じ。銃声と同じく壁では切らない）
        （目は 前 15m／横・後ろ 10m。走ると後ろからでも 18m 先で気付かれる。歩きは後ろの目 10m より短くして、
          そっと歩けば後ろを抜けられるようにする）
  Q2 ＝ 別案「見つけたことにする」（撃たれたときと同じ alert。向き・壁に関係なく Chase になる）
  Q3 ＝ Q2 が alert なので要らない（遅れなしで気付く）

 タルコフでは
  ・人の耳（ヘッドセットなし）で、歩きは約 47m・走りは約 52m 先まで聞こえるという有志の計測がある。
    AI（SPT の Mod の SAIN・QuestingBots）では、ヘッドセットの無い bot は歩きを聞かないことが多く、走りは全員が聞く。
  ・持ち込む所：「歩きは聞かれにくく、走りは必ず聞かれる」「銃声 ＞ 走り ＞ 歩き」の順。
    距離はタルコフの値をそのまま使わない（銃声 30m・目 15m の町に合わせて縮める）。
    確率で聞き漏らす・荷物の重さで変わるは入れない（重さは RaidLoop Q11 で「なし」に決定済み）。
  ・出典：https://eft-ammo.com/headsets-table
          https://newreleases.io/project/github/Solarint/SAIN/release/2.3.0
          https://newreleases.io/project/github/dwesterwick/SPTQuestingBots/release/0.4.1

 今の形
  ・PlayerNoiseComponent が 0.3 秒ごとに自キャラの歩き方（PlayerLocomotionComponent::gait）を読み、
    届く距離（歩き 5m・走り 18m）を ZombieHearing::hearFootsteps( 足元, 距離 ) へ渡す。
  ・ZombieHearing は渡された距離をそのまま使い、その内のゾンビの ZombieBrainComponent::hearFootsteps を呼ぶ。
    距離が 0 以下（止まっている・つかまれている）なら誰も聞かない。日の条件で距離を変える倍率は無い（2026-11-17 に消した）。
  ・聞くかどうかの条件は銃声と同じ（ZombieBrainComponent::canHear。倒れている・よろけ中・攻撃中は聞かない）。
    聞いたら alert（撃たれたときと同じ）。
  ・足音の音（FootstepEmitter）からは知らせない。音を消したり変えたりしたときに、ゾンビの動きまで変わらないため。
  ・alert の後、次に目の線を引いて見えなければ、その時の自キャラの所を探しに行く（Search）。走り続けると 0.3 秒ごとに
    また alert されるので、壁越しでも実質ずっと追ってくる。止まる・歩きで 5m の外に出ると、最後の所で見失う。

  値
  ----------------------------------  --------
  歩きの足音が届く距離                5m（PlayerNoiseComponent.cpp の kWalkFootstepHearingRange）
  走りの足音が届く距離                18m（同 kRunFootstepHearingRange）
  足音を知らせる間隔                  0.3 秒（同 kFootstepNoiseIntervalSeconds）

 懸念点
  ・走ると 18m 内の全員が気付くので、ゾンビが多い所では走るとすぐ囲まれる。
  ・建物の中で走ると、壁の向こうの通りのゾンビまで寄ってくる（壁で切らないため）。

 後回しにする物
  ・壁越しは届く距離を縮める・床の材質で大きさを変える（草は静か、金属はうるさい）・しゃがみ歩き
