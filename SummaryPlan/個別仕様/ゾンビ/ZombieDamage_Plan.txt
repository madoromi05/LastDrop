 仕様（2026-10-18 承認。★ はおすすめどおりで決定）
--------------------------------------------------------------------------------
 ・全体の体力 120。部位の体力は 3 章の表
 ・弾 1 発の基本ダメージは 40（7.62 NATO。弾の速さ 830m/秒 と同じ所に置く）
 ・当たった部位の倍率を掛けた値を、その部位の体力と全体の体力の両方から引く
 ★ 倒れるのは「全体が 0」か「頭が 0」のとき。頭は 2 発で倒れる（3 章）
 ★ 頭以外の部位が 0 になったら「壊れた」印を付けるだけ（今は表示が変わるだけ。部位欠損の入口）
   壊れた部位に当たっても、全体の体力は減り続ける
 ・距離による減衰・貫通は無し（今の弾は最初に当たった物で止まる。そのまま）
 ・体力が 0 以下になったら、死亡アニメ（death1 / death2）へ 6 ティックで繋いで倒す
   最後のフレームで止める（今のアニメは必ずループするので「1回だけ再生」を足す）
 ★ death1 / death2 は体ごとにランダムで選ぶ
 ・倒れ始めた時点で移動の名簿（CollisionWorld）から外す（死体の上を歩ける）
 ★ 命中の名簿（HitWorld）には死体のあいだ残す（弾は死体で止まる。ダメージは入らない）
 ・倒れ終わってから 10 秒置き、1.5 秒かけて 0.5m 地面へ沈めて消す（ActorList::destroyLater）
 ・倒れている途中・死体に当たってもダメージ・反応は無し
 ★ T ポーズのゾンビ（当たり判定の確認用）は体力は減るが倒れない（0 で止まる。部位の減り方を止まった的で確かめられる）
 ・ラグドールは使わない（物理エンジンが無い。アニメで倒す）

 2. 体力とダメージ（全体の体力と部位の体力）
================================================================================
  ・全体の体力：生きているかどうかを決める。0 以下で倒れる
  ・部位の体力：その部位がどれだけ傷んだか。頭が 0 なら倒れる。ほかの部位は 0 で「壊れた」
    （後で部位欠損・脚を失って這う・腕を失って掴めない、をここから決める）
  ・1 発の流れ
      ダメージ ＝ 弾の基本ダメージ（40）× 当たった部位の倍率
      当たった部位の体力 −＝ ダメージ（0 で止める）
      全体の体力         −＝ ダメージ
      全体が 0 以下、または頭が 0 → 倒れる
  ・弾の値（40）は弾の性能として Weapon 側に置く（Bullet.cpp の弾速と同じ所）
    部位の体力と倍率はゾンビ側（受ける側）に置く。弾を増やしても、ゾンビを増やしても、
    直すのは片方だけで済む
  ・端数は float のまま持つ（表示は四捨五入した整数）

  倒れるまでの発数と時間（600発/分。同じ部位だけを撃った場合）
    部位                ダメージ         部位が 0 まで   倒れるまで
    ------------------  ---------------  --------------  ------------------------
    頭                  40 ×1.5  = 60    2 発            2 発（頭が 0）約 0.1 秒
    胴                  40 ×1.0  = 40    3 発            3 発（全体が 0）約 0.2 秒
    太もも              40 ×0.75 = 30    2 発（壊れる）  4 発（全体が 0）約 0.3 秒
    上腕・前腕・すね    40 ×0.5  = 20    2 発（壊れる）  6 発（全体が 0）約 0.5 秒

 3. 部位ごとの体力と倍率
================================================================================
  部位            体力   倍率    0 になったら   理由
  --------------  -----  ------  -------------  ----------------------------------------
  Head            80     1.5     倒れる         一番効くが 1 発では倒れない（ユーザー指定）
  Torso           120    1.0     （全体と同時） 基準。全体と同じ値なので、胴だけ撃てば同時に 0
  LeftThigh       60     0.75    壊れる         脚は胴より弱いが、腕よりは効く
  RightThigh      60     0.75    壊れる
  LeftUpperArm    40     0.5     壊れる         腕・すねは「外した」に近い扱い
  RightUpperArm   40     0.5     壊れる
  LeftForeArm     40     0.5     壊れる
  RightForeArm    40     0.5     壊れる
  LeftLowerLeg    40     0.5     壊れる
  RightLowerLeg   40     0.5     壊れる

  ・表は BodyPart の番号で引く配列にし、static_assert で数が BodyPart::Count と合うか見る
    （BodyPart.h の「並びを変えると表も直す」の約束を、ビルドで守らせる）
  ・「0 で倒れる部位か」は表の列（印）で持つ。頭を特別扱いする if は書かない
    （後で胴も 0 で倒れる、などに変えるときは表だけ直す）

 4. 倒れる処理（死亡から消えるまで）
================================================================================
  状態            入る時                     していること
  --------------  -------------------------  ----------------------------------------
  Alive           出したとき                 歩く（今は置いた場所でアニメだけ）
  Falling         倒れる条件を満たした       death1 / death2 を1回だけ再生。
                  （2 章）                   移動の名簿から外す
  Corpse          死亡アニメが最後まで来た   最後の姿勢で止まる。10 秒数える
  Sinking         10 秒たった                1.5 秒かけて 0.5m 沈む
  （消える）      沈み終わった               GameWorld が destroyLater → flush で消える

  ・状態は Zombie の中の enum で持つ（今は 4 つだけなので、状態ごとのクラスにはしない）
  ・Falling 以降もアニメと部位の箱は毎ティック更新する（死体にも弾が当たるため）
    Corpse 以降は姿勢が変わらないので、部位の箱の更新を止めてもよい（最適化。後で）
  ・名簿から外すのは GameWorld が、全員の update が済んだティックの最後に行う
    （ActorList と同じ考え。名簿をたどっている最中に中身を変えない）

 5. 要りそうな部品と処理の流れ
================================================================================
  新しく作る
    Hit/DamageInfo.h          受けたダメージ（部位・量・当たった位置・弾の向き）
    Hit/IDamageable.h         ダメージを受けられるもの（設計思想.md の IDamageable）
    Zombie/ZombieHealth       全体の体力と部位の体力・倍率の表。ダメージを引き、
                              「倒れたか」「この部位は壊れたか」「残りいくつか」を答えるだけ
    DebugMode/ZombieHealthBars  頭の上のバーと部位の数字を描く（9 章）。Debug ビルドだけ

  直す
    Zombie                    IDamageable を実装。状態（4 章）と死亡アニメ・沈む処理。
                              ZombieHealth を持ち、読む入口（health()）を出す
    SkinnedMeshInstance       1回だけ再生して最後で止める入口を足す
    Bullet                    1 発のダメージ（40）を持つ
    GameWorld                 hit.target のとき Zombie を探してダメージを渡す。
                              消えてよいゾンビを destroyLater、倒れたゾンビを移動の名簿から外す
    GameDebugOverlay          F3 で ZombieHealthBars の表示を切り替え、描かせる
    Pad                       F3 のキー（WorkId の末尾に足す。文字列は Pad.cpp に書かない）

  1 ティックの流れ（GameWorld::update）
    1. 弾を進める → 当たった所（hits）
    2. hit.blocker → 弾痕・砂ぼこり（今のまま）
       hit.target  → 撃った本人でなければ Zombie を探して applyDamage
    3. ゾンビの update（アニメ・状態・沈む）
    4. 倒れ始めたゾンビを移動の名簿から外す／消えてよいゾンビを destroyLater
    5. flush

 7. 懸念点
================================================================================
  ・死亡アニメで体が地面に沈む・浮くかもしれない（モデルの原点と地面の高さ次第）
  ・死体の部位の箱が地面の下へ入ると、弾が地面より先に箱へ当たる所が出るかもしれない
  ・頭の箱は首を含まないので、首元を狙った弾は胴になる（今の箱のまま）
  ・倒れる途中で弾が当たっても反応しないので、手応えが薄く見えるかもしれない
    （ヒット音・血の演出が入れば補える。8 章）
  ・部位の数字は、歩いて腕が胴に重なると数字同士も重なる（9 章。近いときだけ出して減らす）

 9. 体力の表示（Debug ビルドだけ・頭の上のバー）
================================================================================
  ・F3 で表示の入り／切り（F1・F2 と同じく Debug ビルドだけ。Release にはキーも描画も残さない）
    F1（当たり判定）と一緒に出すと、部位の箱と数字を並べて見られる

  出す物
    全体のバー    頭の箱の少し上（頭の箱の上端 ＋ 0.25m）に、画面の向きで横長に出す
                  幅 120 ピクセル・高さ 8 ピクセルで固定（遠くても読める。距離で縮めない）
                  中身は残りの割合だけ伸びる。上に「HP 80/120」の数字
    部位の数字    各部位の箱の中心に、残りの体力（例「40」）。壊れた部位は「0 BROKEN」
                  近いとき（10m 以内）だけ出す（遠いと 10 個が重なって読めない）
    状態          Falling / Corpse（消えるまでの残り秒）/ Sinking をバーの下に出す

  色（初期値。当たり判定の表示は白い線だけ、の方針に合わせて色は最小限）
    バーの枠・背景  黒（半透明）    中身  白
    壊れた部位      赤い文字        死んだゾンビのバー  灰色

  出さない条件
    ・カメラの後ろ（画面の外）
    ・30m より遠い
    ・目からバーの位置までの間に壁・建物がある（HitWorld に線を聞く。キャラは無視）
      （F1 の「物に隠れる線は描かない」と同じ考え）

  作り方
    ・世界の位置を projectionView で画面の位置へ直し、UiRenderer の addRect・addText で描く
      （3D の板にしないのは、文字を出すため。UiRenderer は ASCII を先に作っているので数字は出せる）
    ・ゾンビは体力を「読む入口」を出すだけで、表示のことは知らない（表示は ZombieHealthBars だけ）
    ・T ポーズのゾンビにも出す（止まっているので、部位ごとの減り方を確かめやすい）
