 Q1. 進める順番
     ★A：段階9 月・星／LUT → 段階10 血の跡 → 段階11 材質テクスチャ → 段階12 Hi-Z／ぼけた映り込み → 段階13 ボリュームフォグ
          ・小さくて他と関係が無い物（空のシェーダ・最後の色）から始める
          ・ぼけた映り込み（段階12）は「粗さ 0.4〜0.7 の面」が無いと画面で確かめられない。今は車・道路・ガソリン缶しか
            画素ごとの粗さが無いので、先に建物・銃・キャラの材質（段階11）を入れる（段階 7 の Q1 と同じ考え方）
          ・ボリュームフォグは一番重く、霧・影・TAA の全部に乗るので最後。ほかの段階の重さを測り終えてから足す
      B：見た目の効き目が大きい順：ボリュームフォグ → 月・星 → 材質テクスチャ → ぼけた映り込み／Hi-Z → 血の跡 → LUT

 Q2. ボリュームフォグを付ける光
     ★A：懐中電灯（影のマップあり）と街灯（影なし。光の届く球の中だけ）。月には付けない
          ・夜の町で光の筋が見えるのは、暗い所に強い光がある所（懐中電灯・街灯）。月の光は弱く、筋はほとんど見えない
          ・月の CSM は 3 枚あり、歩くたびに読むと重い
          ・タルコフでは懐中電灯の霧の濃さを下げる修正があり、「自分がまぶしいだけ」という声もある（1 章）
            → 自分の懐中電灯は、目から近い所（初期値 1.5m）の濃さを下げる。強さは F6 で決める
      B：懐中電灯だけ（街灯は今の霧の色だけ）
      C：懐中電灯・街灯・月の全部

 Q3. ボリュームフォグの作り方
     ★A：画素ごとに視線の向きへ進む（ray march）。4 分の 1 の大きさ（480×270）の描画先へ、16 歩。
          歩き始めは IGN でずらしてフレームで動かし（段階 8 と同じ）、奥行きを見た拡大（SsaoUpsample.hlsli と同じ）で戻す。TAA が均す
          ・霧の濃さの式は今の距離の霧・高さの霧（Fog.hlsli）と同じ物を使う（霧の濃い所ほど筋も濃い。見た目が揃う）
          ・GameLib を変えずに作れる（今ある全画面のパスの形）
      B：3D の格子（froxel。画面を奥行きで切った箱に光を貯める。Wronski 2014）。光の数が増えても重さが変わりにくいが、
         GameLib に 3D テクスチャと compute shader が要る

 Q4. LUT の画像の形
     ★A：2D の帯（1024×32。32×32 の色の表を 32 枚、横に並べる）。GameLib に 3D テクスチャを足さない
          ・Unity・UE と同じ形で、Photoshop などで開いて直せる
          ・青の向き（32 枚のどれか）は 2 枚を読んで混ぜる（3D テクスチャの補間の代わり）
      B：GameLib に Texture3D（32³）を足す（読み込みは 1 回で済むが、DDS の 3D の読み込みも足す）

 Q5. LUT と今の色の調整（gradeColor の値）の関係
     ★A：F6 に「今の色の調整を LUT に書き出す」を作る（gradeColor を表に焼いて TGA で保存）。それを外の道具で直して読み込む。
          LUT を読み込んだ後は、gradeColor の代わりに LUT を引く。混ぜる強さ（0〜1）を F6 で動かす（タルコフの色の欄も強さを持つ。1 章）
          ・今の調整を捨てずに、LUT で仕上げを足せる
      B：LUT だけにする（gradeColor の値は消す）
      C：両方を順に掛ける（gradeColor → LUT。調整が二重になり、どちらで直すか迷う）

 Q6. 血の跡の作り
     ★A：ZombieHitFeedback_Plan.txt 4 章の案のまま、描き方だけ板からデカール（DecalBatch。段階 7）に変える
          ・当たった所から弾の進む向きへ 2m 聞き、壁・地面に当たったらその面に血の跡。ゾンビの後ろのゾンビには付けない
          ・真下（1.5m）も聞き、足元に小さな滴の跡（血だまりは作らないので要る）
          ・大きさ 25cm（頭 35cm）・32 個・30 秒（20 秒から薄く）・4 種類を 1 枚に並べる。絵は tools の python で作る（blood_gen.py に足す）
          ・デカールなので、壁の角・窓枠をまたいでも浮かない。ゾンビ・自キャラには乗らない（段階 7 の Q7 の描く順番）
      B：壁だけ（滴の跡は作らない）

 Q7. 血の跡を遊びに使うか（段階 7 の Q9 で「追跡にも関わるので見た目だけ先に作らない」とした所）
     ★A：見た目だけにする。ゾンビは逃げないので「血をたどって追う」遊びが無い。自キャラは出血しない（体力はバイオ式）
          ・タルコフの血の跡は、出血した人が残す追跡の手がかり（1 章）。このゲームは「撃った手応え・戦った跡」として使う
      B：先に「自キャラが出血して、ゾンビが血の跡をたどる」を決めてから作る（体力の仕様から変わる）

 Q8. 材質テクスチャ（ORM）の作り方
     元の画像で分かっていること（2026-10-31 に元のフォルダを確認）：
       ゾンビ：Albedo・Normal・gloss・Metallic・Occlusion・Height・Emission がある → そのまま使える（粗さ = 1 − gloss）
       建物（Red Brick Building/Baked）：Albedo・Normal だけ
       銃（AKM_01）：色・法線だけ
       自キャラ（Mixamo Ch15）：FBX に埋め込まれた画像を確かめていない（段階11 を始めるときに確かめる）
     ★A：元に無い物は tools の python で albedo から作る。
          ・色の範囲ごとに粗さ・金属を決める表（建物：赤れんが 0.85・目地 0.95・窓の枠 0.5・ガラス 0.1 など。銃：黒い鉄 金属 1・粗さ 0.45、木 0.6）
          ・明るさの細かい揺れを粗さに少し混ぜる（同じ材質でも画素ごとに違うつやにする）
          ・表の値は画像を出して F6 の Roughness / Metallic の表示で確かめ、直す
      B：Blender で手で塗る（正確だが、ユーザーの作業が大きい）
      C：元の画像がある物（ゾンビ）だけ。建物・銃・自キャラは今の数値（材質ごとに一様）のまま

 Q9. Hi-Z の深度の縮小の段の作り
     ★A：GameLib の RenderTarget に「段の数（mip）」を足し、段ごとの描画先を作る（GameLib は変えてよいと決定済み。2026-10-26）。
          半分の大きさの深度（SSR と同じ大きさ）から、2×2 の一番手前を取って 1 段ずつ縮める
          ・シェーダは 1 枚のテクスチャを段を指定して読むだけ（SampleLevel）
          ・段階12 のぼけた映り込みで B（色の縮小の段）を選んだときも、同じ作りを使える
      B：段ごとに別の RenderTarget を作る（GameLib を変えないが、シェーダが段の数だけテクスチャを持ち、読む所が分かれ道になる）

 Q10. 粗い面のぼけた映り込み
     ★A：粗さに合わせて、反射の向きを画素ごとにばらす（GGX の分布から 1 本選ぶ。確率的 SSR。Stachowiak 2015）。
          ばらし方は IGN でフレームで動かし、TAA と今のぼかし（粗さで広げる）が均す。SSR を計算する粗さの上限を 0.4 → 0.7 にする
          ・物の形が正しくにじむ（近い所ははっきり、遠い所ほどぼける）
          ・Hi-Z（Q9）で 1 本が軽くなった分を、粗い面に回す
      B：シーンの色の縮小の段（ぼかした絵）を作り、粗さで読む段を選ぶ（cone tracing。ノイズは出ないが、
         手前と奥の物の色が混ざってにじむ・段の境目が見える）

 Q11. 月・星の作り
     ★A：空のシェーダ（LightList.hlsli の skyColor）で描く
          ・月：月の光の向き（CSM と同じ向き）に円板。模様は tools の python で作る画像 1 枚（クレーター）。周りに薄いにじみ。
            明るさは HDR で高めにして、ブルームが少し拾う程度
          ・星：作ったが、ユーザーの指示で削除した（2026-10-31。MoonStarsLut_Plan.txt 13 章）
          ・月の光の強さ（地面の明るさ）は今のまま。絵を足すだけ
      B：板を空に貼る（Graphics_Spec.txt 8 章の元の案。板の向き・遠さ・霧との重なりを別に扱う必要がある）

 1. タルコフでは
================================================================================
 （2026-10-31 に Web で調べた。見つからなかった物は「見つからなかった」と書く）
 ボリュームフォグ（光の筋）
  ・グラフィックの設定に「Volumetric lighting」の ON/OFF があり、初期値は ON。低い性能の PC 向けに切れるようにした
    （Escape from Tarkov Wiki の Changelog・Survival-Sandbox の記事）
  ・懐中電灯の霧（volumetric fog）の濃さを下げる修正・探照灯の光の筋の濃さを半分にする修正がある（同じ出典。版の番号までは確かめていない）
  ・2024 年の技術的なアップデートで、全マップの霧・もやを減らした（天気の霧は残る。Forbes）
  ・遊ぶ人の声：「懐中電灯は相手を照らすより自分がまぶしいだけ」（devtrackers.gg に載った投稿。開発者の発言ではない）
  → 光の筋は入れるが、濃すぎると嫌われる。自分の懐中電灯の目の近くは薄くし、F6 で切れるようにする（Q2・共通）
 月・星
  ・月が出ている夜は、月の当たる所と陰の差が大きい。雲が月を隠すと暗くなる。暗視ゴーグルは月の無い夜に弱い
    （Tarkov Ballistics の 2019 年の夜の攻略。古い記事なので今と違うかもしれない）
  ・月・星の見た目（模様・星の数・月の満ち欠け）を書いた資料は見つからなかった
  → このゲームは雲・天気が無いので、月は出しっぱなし・形は満月 1 つ（Q11）
 色・LUT
  ・PostFX の設定に「Colour Grading」があり、色のフィルタを選んで強さを動かせる。色覚の補助も同じ欄（攻略記事。公式の資料ではない）
  ・LUT 画像を読み込む機能の資料は見つからなかった
  → フィルタの強さと同じく、LUT にも「混ぜる強さ」を持たせる（Q5）
 血
  ・0.12.8 で「重い出血は、ほかの人にも見える血の跡を残す」（段階 7 の 1 章。GameSpot・Dexerto）
  ・撃った相手の後ろの壁に血が付くかを書いた資料は見つからなかった（Garry's Mod の「タルコフ風の血」の改造の話は見つかったが、タルコフ本体の話ではない）
  → 追跡の遊びは作らず、撃った手応えとして壁・地面に付ける（Q6・Q7）
 SSR・材質（段階 7 の 1 章のまま）
  ・SSR は Off・Low・Medium。攻略はどれも Off を勧める（重いだけで遊びに効かない）
  ・ぼけた映り込み・Hi-Z の資料は見つからなかった
  → Hi-Z で軽くしてから、ぼけた映り込みを足す（Q1 の順番・Q9・Q10）

 2. 今のコードで関係するところ
================================================================================
  ・空：LightList.hlsli の skyColor（地平線 → 天頂のグラデーションだけ）。DeferredLighting.hlsl が何も描かれていない画素に描く
  ・霧：Fog.hlsli（距離の霧＋高さの霧）。Fog.hlsl が全画面で掛ける。TAA の前
  ・色：Present.hlsl の gradeColor（「色 → 色」の関数 1 つ。NightFinish_Plan.txt 6-3 で LUT へ置き換えられる形にしてある）
  ・SSR：Ssr.hlsl（直線で 24 歩 ＋ 二分探索 4 回。半分の大きさ）・SsrBlur.hlsl（奥行きを見たぼかし）・SsrComposite.hlsl。
    粗さ 0.4（maxRoughness）より上は計算しない（SsrParams）
  ・デカール：DecalBatch（Decal.hlsl。G-Buffer の色と法線に書く）。今は弾痕だけ。G-Buffer は動かない物 → デカール → 動く物の順
  ・材質：StaticMeshGBuffer.hlsl が ORM（r AO・g 粗さ・b 金属）を読む。キャラの SkinnedMeshGBuffer.hlsl は材質の数値のまま（ORM を読まない）
    ORM がある物：uaz_orm・road_orm・fuelcan_orm
  ・影：懐中電灯の ShadowMap（1024²・透視）・月の CascadedShadowMap（3 枚）
  ・GameLib：RenderTarget・DepthTarget は段（mip）が 1 つだけ。3D テクスチャと compute shader は無い（Q3・Q4・Q9 に関わる）
  ・TAA：TemporalJitter::frameIndex で IGN を動かす。SSAO・SSR のノイズはもう毎フレーム動いている

 4. 段階9：月・星の絵、LUT 画像

 9-a 月・星（Q11）
  ・月の向きは月の CSM と同じ光の向き（影と月の位置がずれない）。見かけの大きさは初期値 1.5°（本物 0.5° は画面で小さすぎるため、少し大きく）

  ・確かめる絵：月が影の向きの空にある・ブルームで少しにじむ
  ・F6：月の大きさ・明るさ

 9-b LUT（Q4・Q5）
  ・Present.hlsl：gradeColor の後に「LUT を引く」を足し、混ぜる強さで混ぜる（強さ 0 なら今と同じ）
  ・F6 → Render → Grading に「LUT に書き出す」（Profiling と同じ所に TGA）と「LUT を読む」（Resource/lut_*.tga）
  ・LUT は数のまま読む（_SRGB にしない）。トーンマップ後・ガンマの前の色（0〜1）を引く
  ・確かめる絵：書き出した LUT を読んだとき、混ぜる強さ 1 でも絵が変わらない（表に焼いた誤差だけ）

 5. 段階10：血の跡のデカール（Q6・Q7）
================================================================================
  ・弾痕と別の DecalBatch（数・残る時間・絵が違う）。描くのは弾痕の後（血が穴の上に乗る）

  ・絵：飛び散った血（中心が濃く、外へ筋と点）4 種類・法線も作る（段階 7 の Q8 の弾痕と同じ。濡れたつやを粗さで出す）
  ・確かめる絵：撃ったゾンビの後ろの壁に血・足元に滴・角をまたいで浮かない・ゾンビには乗らない

 6. 段階11：材質テクスチャ（Q8）
================================================================================
  ・ゾンビ：元の gloss・Metallic・Occlusion を 1 枚の ORM にする（fbx_to_gamelib.py の mesh_orm。粗さ = 1 − gloss）
  ・建物・銃：albedo から作る（tools/orm_from_albedo.py を足す。色の範囲 → 粗さ・金属の表は configs の json に書く）
  ・自キャラ：FBX の埋め込みの画像を見て、あればゾンビと同じ・無ければ建物と同じ
  ・SkinnedMeshGBuffer.hlsl：StaticMeshGBuffer.hlsl と同じく ORM を読む（無い材質は白 1 画素の画像。今と同じ値）
  ・AO：建物の albedo には陰が焼き込まれている（Baked）。ORM の r へ移すかは画像を見て決める（SSAO と二重にならないように）
  ・確かめる絵：F6 の Roughness / Metallic の表示で、建物の窓・銃の鉄と木・ゾンビの服と肌が分かれて見える。懐中電灯で銃の鉄が光る

 7. 段階12：Hi-Z と、粗い面のぼけた映り込み
================================================================================
 12-a Hi-Z（Q9）
  ・半分の大きさの深度を作り、2×2 の一番手前を取って段を縮める（960×540 から 1 画素まで 10 段ほど）
  ・Ssr.hlsl：直線で進む代わりに、空いている所は粗い段で大きく飛ばし、当たりそうな所で細かい段へ下りる（Uludag 2014）
  ・二分探索は残すか実装で決める（Hi-Z だけで当たりが出るなら消す）
  ・確かめる絵：映り込みの見た目が直線のときと同じ・遠くの映り込みが途切れにくくなる。重さは同じ距離で比べる
 12-b ぼけた映り込み（Q10）
  ・粗さの上限 0.4 → 0.7。0.7 より上は今と同じ空の色
  ・反射の向き：粗さから GGX の分布で 1 本選ぶ（IGN をフレームで動かす）。確からしさは粗さで少し下げる
  ・SsrBlur.hlsl：ぼかしの幅を粗さで広げる（なめらかな面は今のまま）
  ・確かめる絵：濡れていない路面・建物の窓の枠に街灯がぼんやり映る・TAA を切るとざらつく（TAA の役目の確認）

 8. 段階13：ボリュームフォグ（Q2・Q3）【保留。コードに残っていない。作り直すなら街灯の筋は外す（VolumetricFog_Plan.txt の状態）】

  ・4 分の 1 の大きさの描画先（RGBA16F。rgb 光の筋の色・a は使わない）へ、視線の向きに 16 歩（最大 30m。霧の濃さの式で減衰）
  ・1 歩ごとに：懐中電灯（円すいの中か・影のマップで遮られていないか）・街灯（届く球の中か）の光 × 霧の濃さ × 向きで変わる散らばり方

 10. 懸念点
================================================================================
  ・ボリュームフォグは夜の暗さと反対向き（霧が光ると全体が明るく見える）。段階 3 の Q2「明かりが無くても 15m 先の輪郭が分かる」と、
    暗さの怖さの両方を保つように、濃さは低めから始める
  ・確率的 SSR と TAA：ゾンビ・手元に映り込みが乗ると残像が出やすい（動く物は TAA が強めに抑えるので、ぼけた映り込みは消えやすい）。
    段階12 の画面確認で見る
  ・albedo から作る粗さは「それらしい」だけで正しくはない。気になる所（窓・銃）だけ手で直す道は残す（Q8 の B）
  ・GameLib の RenderTarget に段を足すと、今の作り（段 1 つ）の呼び出しすべてに影響しないようにする（初期値は段 1 つ）
  ・月の位置は影の向きと同じなので、影の向きを F6 で変えると月も動く（それで正しい）
  ・血の跡が 32 個 × 30 秒あると、戦った場所が赤くなりすぎるかもしれない。数と時間は段階10 の画面確認で直す
