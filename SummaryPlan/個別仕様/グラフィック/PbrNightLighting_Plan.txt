 1. タルコフでは
================================================================================
  ・エンジンは Unity。外は球面調和（SH）の環境光で空の光を当て、屋内はステンシルの範囲で
    環境光を弱め、窓や扉の「ポータル」から外の環境光を入れる（80.lv の技術紹介。自前の照明の仕組み）
  ・動く光と影は Unity の標準の物。影の届く距離を短くし、影を落とすのは形を簡単にした別メッシュ
  ・夜の暗さはマップで違う。プレイヤーの声では「本当に暗いのは Factory だけ、ほかはぼんやり見える」
    暗い所はナイトビジョンで見るのが普通
  ・懐中電灯は銃のレールに付ける「タクティカルデバイス」。可視光・赤外線・レーザーの組み合わせがあり、
    T（等）で ON / OFF、Ctrl + T 等でモード（ライトだけ・レーザーだけ等）を切り替える。
    キーの割り当ては資料ごとに違う（版によって変わっている）
  ・ヘルメットのライトは別のキー（H）
  ・PBR の材質の作り方・ライトの減衰の式は、資料が見つからなかった
  このゲームへの当てはめ
  ・環境光は SH ではなく、まず半球（上は空の色・下は地面の色）。屋内の暗さは段階6 の SSAO と
    段階4 の影に任せ、ステンシルの範囲は作らない（GameLib にステンシルが無い）
  ・懐中電灯は銃に付け、T で ON / OFF だけ（モード・レーザー・赤外線は作らない）
  ・ナイトビジョンは作らない。Q2 で「明かりが無くても輪郭は見える」を基準にする

 2. 今のコードで関係するところ
================================================================================
  ・ライト：GameScene::setupLights（GameScene.cpp 26〜33 行・319〜335 行）。GameLib の 4 灯に
      0 太陽（遠くの点光源）・1 補助光・2 マズルフラッシュ・3 空き。明るさは「強さ / 距離」
      環境光 0.4。舞台は昼の絵（空は消去色の黒）
  ・式：Resource/Shader/Lighting.hlsli の lightSurface（4 灯の Phong 風＋環境光）。
      ディファード（DeferredLighting.hlsl）とフォワード（shadePixel）が共有
  ・G-Buffer：RT2 は今「スペキュラの色」、RT1.a は「鋭さ」（GBuffer_Plan.txt 2 章）
  ・材質：メッシュの txt の <StaticMesh diffuse specular sharpness normalstrength>（20 ファイル）
      specular は 0.02〜0.6、sharpness は 8〜48。emission はどのファイルにも無い
  ・半透明の板：LitQuadBatch は GameLib の固定パイプライン（4 灯）で照らす（10 章）
  ・町：TownMap::junctions()（交差点の位置）。街灯の置き場所に使える

 3. ゴールと、段階3 でやらないこと
================================================================================
  ゴール：夜の町になる。月がうっすら照らし、交差点の街灯の下が明るく、懐中電灯で前を照らせる。

  ・画面をタイルに分けてライトを振り分ける方式（16 個で足りなくなったら考える）

 4. PBR の式（3-a）
================================================================================
  ・拡散反射：Lambert（albedo / π）。金属は拡散反射が無い（albedo × (1 − 金属)）
  ・鏡面反射：Cook-Torrance
      D：GGX（Trowbridge-Reitz）  α = 粗さ²
      G：Smith の Schlick-GGX 近似（k = (粗さ + 1)² / 8。UE4 の点光源用）
      F：Schlick  F0 = lerp( 0.04, albedo, 金属 )
  ・1 つのライトの寄与：(拡散 + 鏡面) × ライトの色 × 強さ × 減衰 × max(0, N・L)
  ・粗さは 0.045 より下にしない（点光源の光が 1 画素に縮んでちらつくのを防ぐ）
  ・関数は Lighting.hlsli に置き、ライトの種類ごとの「向きと減衰」と、面の「BRDF」を分ける
      surfaceBrdf( 面, L, V ) … 式は 1 か所
      evaluateLight( ライト, 位置 ) … 向き L と、届く光の量（6 章）
  ・光の単位（ルクス等）は使わない。強さは F6 で見た目で決める（Graphics_Spec.txt 5-1）

 5. 材質のデータと G-Buffer の RT2（3-a）
================================================================================
  ・メッシュの txt に roughness・metallic・emission を足す（材質ごとに一様。Graphics_Spec.txt 5-2 の段階1）
      <StaticMesh ... roughness="0.8" metallic="0" emission="0">
      書いていないファイルは roughness 0.8・metallic 0・emission 0（コードの定数 1 か所）
      specular・sharpness は読み込みを残して使わない（20 ファイルを一度に書き換えなくてよい）
  ・最初に入れる値（Graphics_Spec.txt 5-2 の目安から）
      建物・コンクリート 0.8 / 道路・アスファルト 0.9 / 車の塗装 0.4 / 銃 粗さ 0.5・金属 1 /
      弾頭・薬莢 粗さ 0.35・金属 1 / ゾンビの肌・服 0.8 / 自キャラの腕・手袋 0.7 / ガソリン缶 0.5・金属 1
  ・G-Buffer の RT2 を入れ替える（GBuffer_Plan.txt の予告どおり）
      RT2（RGBA8 UNORM）：r AO（今は 1）・g 粗さ・b 金属・a 発光の強さ（0〜1 を 0〜kEmissionMax へ広げる）
      RT1.a（鋭さ）は使わなくなる → 予備
      RT2 は色ではないので sRGB をやめて UNORM にする（GBuffer.cpp の kFormats）
  ・発光の色は「albedo × 発光の強さ」。窓・街灯の電球に使う（今はどの材質も 0）
  ・F6 → Render → G-Buffer の表示に Roughness・Metallic・Emission を足し、Specular・Sharpness は消す

================================================================================
 6. ライトの種類と減衰（3-b）
================================================================================
  ・GameLib の 4 灯（b0）は使わなくなる。ライトの一覧を自分の定数バッファ（b2）で渡す
      struct LightData { 位置 or 向き・届く距離・色×強さ・種類・スポットの向きと角度 }
      最大 16 個（kMaxLights）。ディファードのライティングのパスと、半透明の板（10 章）が同じ b2 を読む
  ・種類
      平行光（月）      向きだけ。減衰なし
      点光源            距離の 2 乗に反比例 × 届く距離でなめらかに 0
                         窓 = saturate( 1 − (d / range)⁴ )²（UE4 / Frostbite と同じ形）
      スポット          点光源の減衰 × 内側の角度と外側の角度の間でなめらかに暗く
  ・GameSrc に LightList（今のフレームのライトを集める）を置く
      GameScene が月・マズルフラッシュ・懐中電灯・街灯を積む → 16 個を超えたら、
      カメラに近い順（月は必ず残す）に選んで定数バッファへ
  ・マズルフラッシュの光（今は GameLib の 2 番）は LightList の点光源へ移す（MuzzleFlash は位置・色・強さを渡すだけで、中身は同じ）
  ・3-b の終わりの絵：今の太陽・補助光を「平行光 2 つ」に置き換えた昼の絵（まだ夜にはしない）。
    式の変更（3-a）とライトの変更（3-b）を別々に確かめるため

================================================================================
 7. 空と環境光・夜にする（3-c）
================================================================================
  ・空：何も描かれていない画素（深度 1）に、地平線の色 → 天頂の色のグラデーションを描く
      今の discard をやめ、ライティングのパスで描く（向きはカメラの逆行列から出す）
  ・拡散の環境光：半球ライト。lerp( 地面の色, 空の色, N.y × 0.5 + 0.5 ) × albedo × AO
  ・鏡面の環境光：反射の向き R で空のグラデーションを引き、粗さでぼかす（近似）× F（Schlick の粗さ版）
      金属が真っ黒にならないための物。キューブマップは作らない（Graphics_Spec.txt 8 章）
  ・夜の値（最初の値。F6 で調整してプリセットに入れる）
      月：向き 斜め上 35°・青白い色・弱い
      空：天頂 濃い紺 → 地平線 少し明るい青灰（後で霧の色と揃える）
      環境光の下限：Q2 の基準（15m 先の輪郭）で決める
  ・昼の値もプリセットとして残す（F6 で切り替え。見比べと不具合探しに使う。遊びの中では夜だけ）

 8. 街灯（3-d）
================================================================================
  ・TownMap::junctions() の位置に、点光源（下向きのスポットの方が光が地面に溜まって見える。最初は点光源）
      高さ 5m・届く距離 14m・暖かい色（ナトリウム灯風のオレンジ）
  ・配置は TownMap が知る（道路の部品と同じ。「街灯の位置の一覧」を TownMap に足す）
  ・柱の模型は無い（Q4）。光の芯に発光の小さな板も置かない（段階5 のブルームで光らせたくなったら足す）
  ・数：交差点の数だけ。今の町は 4×4 で 16 個。月・マズルフラッシュ・懐中電灯を足すと 19 個になり 16 を超えるので、
    6 章の「カメラに近い順」で選ぶ処理は 3-d で必ず使う（遠い街灯が消えるのが見えないかを確かめる）

 9. 懐中電灯（3-e）
================================================================================
  ・スポット 1 つ。位置は銃口の少し後ろ、向きは銃の向き（AimSway でぶれた銃の向きと揃える）
      届く距離 25m・内側 12°・外側 22°・白に少し暖かみ
  ・入力：T で ON / OFF（Q3）。入力の名前は GameLib の入力の一覧に足し、Pad.cpp には文字列を書かない
      キーコンフィグ（Controls 画面）にも出す。ON / OFF でカチッという音（SoundGen で作る。短い物）
  ・ADS・しまう・リロード中も付いたまま（銃に付いているので銃と一緒に動く）
  ・銃を「しまう」状態では、銃の向きが下を向くので光も下を向く（そのまま。特別な処理はしない）
  ・ゾンビの視野（ZombieChase）には影響させない（光に寄ってくる等は作らない。後で決める）
  ・影は段階4。懐中電灯の光は壁を通り抜ける（3 章）

 10. 半透明の板（弾痕・砂ぼこり・血）の照らし方
================================================================================
  ・今は LitQuadBatch が GameLib の 4 灯で照らしている。3-b で 4 灯を使わなくなると、
    板だけ昼のライトで照らされて浮く
  ・LitQuadBatch に自作のシェーダを持たせ、ライトの一覧（b2）を読んで、粗さ 1・金属 0 の面として照らす
    （光る物＝マズルフラッシュの板は今のまま照らさない）
  ・3-b と同時に入れる（ライトを切り替えた瞬間に浮かないように）

 11. 調整（F6）と表示
================================================================================
  ・F6 → Tuning に「Lighting」の構造体（LightingParams）
      月の向き・色・強さ／空の天頂と地平線の色／環境光の空と地面の色・強さ／街灯の高さ・距離・色・強さ／
      懐中電灯の距離・角度・色・強さ／露出（今の ToneMap の値）
      プリセット：Night（遊びの値）・Day（見比べ用）
  ・F6 → Render → G-Buffer の表示に Roughness・Metallic・Emission（5 章）
  ・F3 のデバッグ表示：ライトの位置に小さな印と、届く距離の円（街灯の置き場所を見る）
  ・2-d の計測の「Lighting」の印はそのまま使う

 12. 進め方（3-a〜3-e）
================================================================================
  前提：段階2 の画面の見比べ（2-b）と 2-c の確認が済んでいること。Q1 が A ならその後にフォワードを消す

  3-a  式を PBR にし、材質に粗さ・金属・発光を足す。RT2 を入れ替える。ライトは今の 4 灯のまま（昼の絵）
       確かめること：昼の絵で、銃・弾・ガソリン缶に金属らしい光り方、道路と壁はつやが無い
  3-b  LightList と b2 のライトの一覧。平行光・点光源・スポット。マズルフラッシュを移す。
       半透明の板を同じライトで照らす（10 章）。太陽・補助光は平行光 2 つにする（昼の絵のまま）
       確かめること：3-a と見た目がほぼ同じ（減衰の式だけが違う）・撃つと周りが光る
  3-c  空と環境光。夜のプリセットにする
       確かめること：夜の町になる・Q2 の基準で輪郭が見える・金属に空が映る・空が描かれる
  3-d  街灯
       確かめること：交差点の下が明るく、道の途中が暗い。F3 で置き場所と距離が見える
  3-e  懐中電灯（Q3 が C なら無し）
       確かめること：T で付く・銃と一緒に動く・ADS で照らす先がぶれない
  各段の終わりに Debug・Release の x64 ビルドと、シェーダを fxc で全部コンパイルして確かめる
  夜にした後、ゾンビの湧く条件（見えない所）とゾンビの見つけやすさを遊んで確かめる（ZombieSpawn_Plan.txt）

 13. 計測
================================================================================
  ・3-e の後、2-d と同じ測り方（Profile・VSync なし・F7）で、ライト 16 個の夜の絵を測る
    見る所：gpu.Lighting（今 0.056ms）がライトの数でどれだけ増えるか
  ・技術まとめ 8 章に足す（2-d の⑥の続き）
  ・結果（2026-10-29。Profile・VSync なし・2560×1369・91,538 フレーム。Profiling/20261029_011038/perf_20261029_011706.csv）
      GPU 全体の中央値 0.345ms（段階2）→ 0.679ms、ライティングのパスの中央値 0.053ms → 0.442ms（99% 1.20ms）
      ライト 1 個あたり約 0.03ms。建物・地面・ポストプロセスは段階2 とほぼ同じ。1 万フレームずつ分けても 0.42〜0.53ms で安定
      VSync を入れたままの記録（perf_20261029_011329.csv）は、GPU 全体に画面の更新待ちが入るので使わない
      技術まとめ 8 章⑦に書いた

 16. 実装で仕様から変えた所（3-b）
================================================================================
  ・LightList（GameSrc/Render/LightList.h / .cpp）と Resource/Shader/LightList.hlsli（b2）を足した
      ライト 1 つは float4 × 4（位置と届く距離・向きと種類・色と強さ・スポットの角度の倍率とずらし）
      作るときは directionalLight / pointLight / spotLight（種類ごとに要る値だけ渡す）
      選び方：平行光は必ず先、残りは「目から届く範囲のふちまでの距離」が近い順に 16 個（同じなら足した順）
  ・色は sRGB のまま渡し、シェーダでリニアへ直してから強さを掛ける（GameLib の setLightColor と同じ順番。
    GameLib の色の変換は外から呼べないので、シェーダの srgbToLinear を使った）
  ・点光源の距離の下限を 10cm にした（Pbr.hlsli の kMinLightDistanceSquared）。距離の 2 乗で弱まるので、
    銃口の 5cm 前にあるマズルフラッシュの光が銃そのものを何百倍にも照らすのを抑える
  ・マズルフラッシュ：強さ 1.5 はそのまま（1m 先で 3-a までと同じ明るさ）、届く距離 8m。
    MuzzleFlash::Light をやめて LightSource を返す（GameWorld::muzzleLight も同じ）
  ・太陽・補助光は平行光 2 つ。向きは 3-a までの遠い点光源の位置から町の真ん中へ向かう向き、強さ 1
    （遠い点光源の「強さ＝距離」と、町の真ん中で同じ明るさ）
  ・環境光は 3-c まで GameLib の値（setAmbientColor → b0 の gAmbient）のまま。GameLib の 4 灯はゲーム本編では使わない
    （SkinTestScene は今までどおり GameLib の 4 灯で照らす）
  ・ライトの一覧は setupLights で付け、半透明の板を描き終えた所で外す（GameScene::draw）
  ・半透明の板：LitQuadBatch の MODE_LIT に Resource/Shader/LitQuad.hlsl を持たせた（粗さ 1・金属 0。Pbr.hlsli の shadeSurface）。
    MODE_GLOW（マズルフラッシュの板）は固定パイプラインのまま。シェーダは板の入れ物ごとに作る（弾痕・砂ぼこり・血の 3 つ）
  ・Pbr.hlsli の evaluateLight は return を 1 か所にした（途中で返すと fxc の最適化ありで「初期化していないかもしれない」警告が出た）
  ・画面で確かめること（3-b）
     昼の絵が 3-a とほぼ同じか（太陽と補助光は同じ向き・同じ明るさのはず）
     撃つと、周りの壁・地面・ゾンビ・自分の腕と銃がオレンジに照らされ、8m より先は照らされないか。
       銃が真っ白に飛んでいないか（3-a までより近くは明るく、遠くは暗くなる）
     弾痕・砂ぼこり・血しぶきが、周りの壁と同じ明るさで、浮いて（明るすぎ・暗すぎ）見えないか。撃った瞬間に一緒に照らされるか

 17. 実装で仕様から変えた所（3-c）
================================================================================
  ・調整値は LightingParams（GameSrc/Render/LightingParams.h。F6 → Tuning の LightingParams）。初期値は夜

  ・環境光（LightList.hlsli の environmentLight）

      鏡面：反射の向きに見える空（上）・地面（下）の色を、粗さで半球ライトの色へ寄せる（粗いほどぼける近似）
            映り込みの強さは 3-a の EnvBRDFApprox のまま
  ・半透明の板（LitQuad.hlsl）も同じ shadeSurface を通るので、夜の環境光で照らされる
  ・夜の値は撮った絵で「15m 先の輪郭」がおおよそ見える所まで。細かい合わせはユーザーが F6 で行う（Q2）
  ・ゾンビの湧く条件（ZombieSpawn の「見えない所」）は、まだ夜に合わせて確かめていない（12 章の最後）
  ・画面で確かめること（3-c）
     夜の町になっているか。明かりの無い所でも 15m 先のゾンビの輪郭が分かるか（暗すぎ・明るすぎは F6 → Tuning で）
     空が黒ではなく、地平線が少し明るい紺のグラデーションか。建物の輪郭が空に対して見えるか
     弾頭・落ちた弾（金属）に空の色が映り、真っ黒になっていないか
     F6 → Render の Day で昼の絵（3-b とほぼ同じ明るさ・空が青）、Night で夜に戻るか
     撃ったときの照り返しが、夜だと昼よりはっきり見えるか

  ・覗く（ADS）と銃口が視線に揃うので、光は照準の先に当たる（照準のぶれで銃が揺れると光も揺れる）
  ・音：SOUND_FLASHLIGHT_CLICK（flashlight_click_0.wav）を SoundCatalog の末尾に足し、SoundGen（FoleySynth.cpp の makeFlashlightClick）で合成。

    SoundGen はサイレン（siren_0.wav）も書き換えるので、git で戻した
  ・F3：スポットは照らす向きへ 3m の線も描く（LightDebugDrawer。向きを確かめるのに足した）
  ・画面で確かめること（3-e）
     T で付く・消える、「カチッ」が鳴るか。Controls 画面に Flashlight（T）が出るか
     覗いたとき照準の先が照らされるか。歩く・撃つと光が銃と一緒に揺れるか
     近くの壁が白く飛びすぎないか（強すぎるなら F6 → Tuning の flashlightIntensity）
     銃をしまうと消え、出すとまた付くか
     夜のライトの数：月＋懐中電灯＋マズルフラッシュ＋街灯 16 ＝ 19。16 を超えた 3 つは遠い街灯から外れる
