 Q1. 進める順番
     ★A：12-a Hi-Z（見た目は今と同じ）→ 画面確認・計測 → 12-b ぼけた映り込み → 画面確認・計測
          ・12-a は「速くなったか・映り込みが同じか」だけを見る。12-b と一緒に入れると、見た目の違いがどちらから来たか分からない
      B：12-a と 12-b を一緒に入れて、まとめて確かめる

 Q2. GameLib の描画先に段（mip）を足す形
     ★A：RenderTarget::create / createScreenSized に「段の数」（初期値 1。今の呼び出しは変わらない）。
          Manager に「1 段だけに描く」setRenderTargets( target, mip ) と「1 段だけを読む」setShaderResource( slot, target, mip ) を足す。
          今の setShaderResource( slot, target ) は全部の段を読む（シェーダが Load / SampleLevel で段を選ぶ）
          ・D3D11 は同じ画像の「段 i に描きながら段 i−1 を読む」ができる（段ごとの view を作る）。縮小のパスは段の数だけ回す
      B：段ごとに別の RenderTarget を作る（GameLib を変えないが、Ssr.hlsl が 10 枚の画像を持ち、段の選び方が分かれ道になる）

 Q3. Hi-Z に入れる値
     ★A：深度の値そのまま（0 が手前・1 が奥。目からの距離に比べて形が歪む値）の、2×2 の一番手前（最小）
          ・深度の値は画面の上で直線に変わるので、光線を画面の上で進めたまま、段の値と比べられる（Uludag 2014 と同じ）
      B：目からの距離（m）。厚さの判定が段の値でできるが、画面の上で進むたびに距離へ直す計算が要る

 Q4. 薄い物の裏（Hi-Z は一番手前の面しか知らない）
     ★A：Hi-Z で当たった所で、今と同じ厚さの判定（0.5m）をする。厚さを超えていたら「当たらなかった」（確からしさ 0。空と地面の色のまま）
          ・電柱・ゾンビの裏に、その奥の物が映らずに抜ける所が出るが、今の直線の SSR も同じ扱い（当たらなければ空）
      B：厚さを超えたら、当たった所の少し先から進み直す（裏を通り抜けて奥の物を探す。正しいが歩数が読めない）

 Q5. 今の直線の進み方
     ★A：12-b の計測が終わるまで F6 で切り替えられるように残し（見比べ・前後の計測のため）、段階12 の終わりに消す
          ・段階3 でフォワードを消したのと同じ（比べ終わったら片方にする）
      B：12-a で消す（シェーダが短くなるが、同じ場面で見比べられない）

 Q6. ぼけた映り込みで、反射の向きをばらす方法（12-b）
     ★A：GGX の「目から見える法線」の分布（VNDF。Heitz 2018）から、画素ごとに 1 本選ぶ。乱数 2 つは IGN を 2 つ（ずらした画素）で、フレームで動かす
          ・裏向き（面の中へ入る）の向きがほとんど出ないので、捨てる画素が少ない。式は 20 行ほど
      B：GGX の分布（D）そのものから選ぶ（式は短いが、斜めから見ると面の中へ入る向きが多く出て、捨てる分だけざらつく）

 Q7. ぼかし（12-b）
     ★A：SsrBlur.hlsl の読む間隔を粗さで広げる（粗さ 0.4 以下は今のまま 1 画素おき、0.7 で 3 画素おき）。粗さが大きく違う画素は混ぜない
          ・なめらかな面（水たまり・車）は今のくっきりした映り込みのまま。粗い面だけ広くならす
          ・ざらつきの残りは TAA が均す（TAA を切るとざらつくのは正しい。確かめる絵に入れる）
      B：ぼかしは変えず、TAA だけで均す（粗い面がざらついて見える）

 Q8. GPU の計測の印
     ★A：Hi-Z を作るパスに印「Hi-Z」を足し、GameLib の印の上限（GpuTimer::kMaxMarks）を 20 → 24 にする
          ・今 19 個使っている。Hi-Z で 20、段階13 のボリュームフォグで 21 になり、上限を超えた印は捨てられて CSV の列から消える（10-30 に起きた）
      B：Hi-Z を「SSR」の印に入れる（上限は変えないが、Hi-Z だけの重さが分からない）

 2. 今のコードで関係するところ
================================================================================
  ・ScreenSpaceReflection（Render/）：半分の大きさ（RGBA16F）の描画先 2 枚（作る・ぼかしの行き来）。Ssr.hlsl → SsrBlur.hlsl（横・縦）
  ・Ssr.hlsl：元の大きさの深度（t5）を、半分の画素 i なら元の画素 2i で読む。直線 24 歩（先ほど歩幅を広げる）＋二分探索 4 回。
    当たりは「点が深度より奥・差が厚さ 0.5m より小さい」。粗さ 0.4（SsrParams::maxRoughness）より上は計算しない
  ・SsrComposite.hlsl：環境光の鏡面（空と地面の色）を、確からしさの分だけ SSR の色へ入れ替える。重みは EnvBRDFApprox（粗さで変わる）
    → 粗い面は「映り込みの光の平均」を SSR が出せば、強さの計算はそのまま使える（12-b で混ぜる側は変えない）
  ・SsrBlur.hlsl：ガウス（半径 4・σ 2）× 奥行きの近さ。粗さは見ていない
  ・GameLib：RenderTarget は段が 1 つ（MipLevels = 1）。Manager::setRenderTargets は描画先の大きさに描画範囲を合わせ、
    付けていた読み込み（t2 以降）を外す（読み込みは描画先を付けた後に付ける）
  ・GPU の印：19 個（Shadow・Buildings・Props・Ground・Decals・Player・Zombies・SSAO・Lighting・SSR・SSR composite・Fog・TAA・
    Effects・PostProcess・FXAA・GBufferView・UI・ImGui）。上限 20
  ・粗さ 0.4〜0.7 の面（段階11 の後）：銃の鉄 0.45・木 0.6・自キャラの装備・ゾンビの傷の所（0.5 前後）・建物の一部（揺れで 0.8 を下回る所は無い）

 4. 12-a：GameLib の描画先に段を足す（Q2 の A）
================================================================================
  ・RenderTarget::create( w, h, format, mipLevels = 1 )・createScreenSized( scale, format, mipLevels = 1 )。mipLevels() を読める
    mipLevels に 0 を渡すと「1 画素まで全部」（960×540 なら 10 段）
  ・Impl：段ごとの RTV と SRV（1 段だけ）を持つ。今の mRTV・mSRV は段 0 の RTV と全部の段の SRV（今の呼び出しは何も変わらない）
  ・Manager::setRenderTargets( const RenderTarget& target, int mip )：段 mip だけに描く。描画範囲はその段の大きさ
  ・Manager::setShaderResource( int slot, const RenderTarget& target, int mip )：段 mip だけを読む（縮小のパスが 1 つ上の段を読む）
  ・画面の大きさが変わったときの作り直し（fitToScreen）は段の view も作り直す
  ・ASSERT：段の番号が範囲の外・段の数 1 の物に mip > 0

 5. 12-a：Hi-Z を作る（GameSrc/Render/HiZBuffer・Resource/Shader/HiZBuild.hlsl）
================================================================================
  ・描画先：画面の半分の大きさ・R32F・段は 1 画素まで全部（960×540 → 480×270 → … → 1×1。10 段）
  ・段 0：元の大きさの深度の 2×2 の一番手前（最小）。段 i：段 i−1 の 2×2 の一番手前
  ・元の段の大きさが奇数のとき（135 → 67 など）は、端の 1 列・1 行も足して 3 つ目まで見る（取りこぼすと、細い物の手前を見落として抜ける）
  ・パスの数：段の数だけ全画面を描く（10 回。後ろの段ほど小さいので、ほとんど段 0 の重さ）
  ・HiZBuffer：draw( depth ) で作る・result()（全部の段）・mipLevels()。ScreenSpaceReflection が持つ

================================================================================
 6. 12-a：Hi-Z で進む（Ssr.hlsl。Uludag 2014）
================================================================================
  ・光線を画面の上で表す：始まり（画素の uv と深度）・終わり（位置 + 反射の向き × 最大の長さ。目の前の面より手前へ出るなら、そこで切る）を
    画面へ写し、(x, y, 深度) が直線に変わるとして進む（深度の値は画面の上で直線に変わる。Q3 の A）
  ・段 0 から始める。今の段の「升目の境目」まで進み、
      光線の深度 < 升目の一番手前 … 升目の中に当たる物は無い → 境目の先へ進み、1 段上へ（大きく飛ばす）
      光線の深度 ≥ 升目の一番手前 … 当たるかもしれない → 境目の手前で止まり、1 段下へ（細かく見る）
    段 0 で「当たるかもしれない」になったら当たり。決まった回数（初期値 48。F6）で見つからなければ当たらなかった
  ・当たった所で厚さの判定（今の 0.5m。目からの距離で比べる。Q4 の A）
  ・二分探索は使わない（段 0 の升目の境目で止まるので、半分の画素の細かさで当たりが決まる）。映り込みの縁が今より粗く見えたら、
    当たった升目の中だけ今の二分探索を 2 回足す（画面確認で決める）
  ・確からしさ（画面の端・粗さ・遠さ）は今のまま。「遠さ」は進んだ長さ（m）で、今と同じ
  ・今の直線の進み方は F6 で切り替えられるように残す（Q5 の A）。同じシェーダの中で、定数で分ける

  確かめる絵：Hi-Z の ON/OFF で、水たまりに映る街灯・車・建物が同じ形・同じ明るさ。遠くの映り込みが途切れにくくなる。
              F6 の G-Buffer 表示に「Hi-Z」（段を選んで見る。8 章）で、段ごとに手前の物が太って見える

 7. 12-b：粗い面のぼけた映り込み（Stachowiak 2015 を小さくした物）
================================================================================
  ・粗さの上限 0.4 → 0.7（SsrParams::maxRoughness の初期値）。0.7 より上は今と同じ空の色。境目で薄くする幅は今の 0.1
  ・反射の向き：画素ごとに、GGX の見える法線の分布（Q6 の A）から半ベクトル h を 1 本選び、r = reflect( 目からの向き, h )。
    r が面の中へ入る（n・r ≤ 0）ときは、選び直さずに鏡の向きを使う（ざらつきを増やさない）。粗さ 0.05 未満は鏡の向きのまま
  ・乱数：IGN( 画素, フレーム ) と IGN( 画素 + ずらし, フレーム )（Noise.hlsli。TAA と同じくフレームで動く）
  ・持ってくる色：当たった画素のシーンの色（今と同じ。段の付いた色の縮小は作らない＝GraphicsExtra_Spec.txt Q10 の B は使わない）
  ・確からしさ：今の式に「粗さで少し下げる」を掛ける（粗さ 0.4 → 0.7 で 1 → 0.6）。ばらした 1 本が外れる分を空の色で埋める
  ・ぼかし（Q7 の A）：SsrBlur.hlsl に G-Buffer の材質（t4）を読ませ、真ん中の粗さで読む間隔を広げる
      間隔 = 1 + 2 × saturate( (粗さ − 0.4) / 0.3 )（0.4 以下は 1・0.7 で 3）。粗さの差が 0.2 より大きい画素は混ぜない
  ・混ぜるパス（SsrComposite.hlsl）は変えない（2 章）

  確かめる絵：濡れていない路面・建物には映らない（0.8 より粗い）。銃の鉄・木・自キャラの装備・ゾンビの傷に、街灯・懐中電灯の光がぼんやり映る。
              近い物ははっきり、遠い物ほどぼける。TAA を切るとざらつく（TAA が均している）。水たまり・車の映り込みは今のまま
              ゾンビ・手元が動いたときに、ぼけた映り込みの残像が出ないか（10 章）

 10. 懸念点
================================================================================
  ・Hi-Z は一番手前の面しか知らないので、物の裏を通る光線が手前で止まる（Q4）。今の直線より抜ける所が増えたら、Q4 の B に変える
  ・確率的 SSR と TAA：ゾンビ・手元に乗ったぼけた映り込みは、TAA が動く物を強めに抑えるので残像は出にくいが、ちらつきは出やすい
    （GraphicsExtra_Spec.txt 10 章）。気になれば、手元（動きの種類 = 手元）だけ粗さの上限を 0.4 のままにする
  ・粗い面の映り込みは、夜の暗い所ではほとんど見えない（街灯・懐中電灯の光しか映らない）。効き目が小さければ、上限を 0.6 に下げて軽くする
  ・GameLib の RenderTarget を変えるので、今の描画先（影・G-Buffer・SSAO・TAA の履歴など）が全部同じに動くことをビルド後に見る（段 1 は今と同じ view）
  ・GPU の印の上限を 24 にすると、計測の CSV の列が増える（集計は列の名前で合わせるので、古い CSV とも比べられる）

 12. 実装で決めた細かい所（12-a。2026-11-02）
================================================================================
  ・GameLib：RenderTarget::create / createScreenSized に mipLevels（初期値 1・RenderTarget::FULL_MIP_CHAIN で 1 画素まで）と mipLevels()。
    Manager::setRenderTargetMip( target, mip )（深度なし・描画範囲はその段）と setShaderResource( slot, target, mip )（1 段だけ）。
    段が 1 つの描画先は view の作り方も今と同じ（段ごとの view は段が 2 つ以上のときだけ作る）。GpuTimer::kMaxMarks 20 → 24
  ・HiZBuffer（Render/。ScreenSpaceReflection が持つ）・HiZBuild.hlsl：描く先の 1 画素に重なる元の画素の範囲を「始まり切り捨て・終わり切り上げ」で出し、
    3×3 まで見る（奇数の段・画面の大きさが奇数でも取りこぼさない）。段 0 は元の深度から、段 i は段 i−1 から。全画面を段の数だけ描く
  ・Ssr.hlsl：marchHiZ（6 章のとおり）と marchLinear（今までの直線＋二分探索）に分け、gSsrHiZ.z で選ぶ。
    光線は (uv, 深度の値) の直線。目の方へ向かう光線は、目の前 0.1m に届く所で長さを切る。画面の外へ出る所で t を切る。
    升目の境目は段 0 の 1 画素の 1% だけ越える。始まりは自分の段 0 の升目を出た所。二分探索は使っていない（画面確認で縁が粗ければ足す）
  ・ScreenSpaceReflection::buildHiZ（印「Hi-Z」を draw と分けるため別にした）。SSR を切っている間も印は打つ（列を揃える）
