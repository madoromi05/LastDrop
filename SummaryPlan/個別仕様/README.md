# 個別仕様（機能ごとの計画書）

機能ごとに「計画書を書く → Q を★で承認 → 実装 → 画面確認 → 計測」の順で進める。その計画書の置き場所。
進み具合の全体は `../main.txt`、計測した数字は `../技術まとめ_ポートフォリオ.md` の 8 章を見る。

計画書を足したら、下の種類のフォルダのどれかに入れて、この一覧にも足す。
コードのコメントから計画書を指すときは `SummaryPlan/個別仕様/<フォルダ>/<名前>.txt` と書く（2026-11-09 にフォルダへ分けた）。

| フォルダ | 中身 | 全体の計画 |
|---|---|---|
| `グラフィック/` | 描き方の段階1〜13（リニア化・ディファード・PBR・影・霧・SSAO・SSR・TAA・月と LUT・血の跡・材質・Hi-Z・ボリュームフォグ）、ブルーム・街灯の模型と光（StreetLamp） | `Graphics_Spec.txt`（段階1〜8）・`GraphicsExtra_Spec.txt`（段階9〜13） |
| `最適化と計測/` | 最適化【S】【A】【B】【C】、計測の仕組み（Profile 構成・F6・F7）、計測の道具（AutoPlay・PerfCompare） | `Optimization_Plan.txt` |
| `射撃と手応え/` | マズルフラッシュ・弾痕・煙のコマ送り・カメラシェイクと反動・照準のぶれ・手応えの強弱・着弾音・息遣い（作らない）・拳銃 | — |
| `ゾンビ/` | 追う・道探し（NavMesh）・聞く・湧く・攻撃・体力と欠損・よろけ・這う・ルートモーション・不確かさ | — |

| `UI/` | 一時停止・設定画面・キーの割り当て（作らない）・日本語化・物の絵・使える物のマーク・弾数・タイトル画面（RE:2 風）・メニューを RE:2 風に揃える | — |
| `設計と分割/` | ComponentSystem、GameWorld・Zombie・大きいクラスの分割、小さな計算の置き場所、音の基盤のまとめ、メニューの部品のまとまり（MenuKit） | — |
