--------------------------------------------------------------------------------
 決定事項（ユーザー回答。2026-10-22〜23）
--------------------------------------------------------------------------------
 ★ 這うアニメは使わない。倒れ終わった姿勢のまま、腕の骨をコードで動かし、体を少しずつ前へ引きずる（2026-10-23 変更）
 ★ 足をつかんだら、立っているゾンビの攻撃と同じ流れ（つかむ → 1.2 秒で噛む・撃って振りほどく）。噛まれるのは脚
 ★ 引きずるゾンビの追い方は立っている時と同じ（見えたら追う・見失ったら探す・銃声で寄る・建物は回り込む）。速さだけ遅い

--------------------------------------------------------------------------------
 決まりごと（Claude の判断。確かめてもらう）
--------------------------------------------------------------------------------
 ・脚を失ったら、体ごとに選んだ死亡アニメではなく、いつも前へ倒れる death1 で倒す（2 章。仰向けだと引きずれない）
 ・倒れ終わってから引きずり始める（death1 の 160 フレーム目＝脚を失ってから約 2.7 秒）。腕は 0.4 秒かけて動き始める
 ・引きずる速さは平均 0.4m/秒（歩きは 1.0m/秒）。左右の腕で交互に引き、1 回引くごとに 0.25m 進む（1 往復 1.25 秒）。
   引いている間だけ進むので、ぐっ・ぐっと波打って進む
 ・向きを変える速さは 60°/秒（立っている時は 180°/秒）。向きを変える中心は胸（足元を中心に回すと頭が大きく振れるため）
 ・気付く前（うろつき）と、追いついて待っている間は、その場で腕を遅く（0.3 倍）動かしてもがくだけ
 ・腕を片方失ったら半分の速さ（失った腕のぶんは進まない）。両腕を失ったら進まず、つかみもしない
 ・目の高さは胸から 0.4m（伏せている）。見通しの線もここから引く
 ・2026-10-23 ユーザー指定（4 章の後半）
     1 回目「手が地面に埋まる・足も動かしてほしい・頭も上げてほしい」
     2 回目「足や手は浮かせるのではなく地面に対して這うように」「顔を上げる＝角度を変えて Player を見るように」
     → 手は地面に突いたまま体を引き寄せる（IK で手首を地面の点へ置く）。脚は地面に沿って開いて蹴る（高さを変えない）。
       頭は自キャラの方へ顔を向ける（見えていないときは前の少し上を見る）
 ・引きずるゾンビは今の Downed と同じく他のキャラの移動を止めない（上をまたげる）。自分は胸の位置で壁・車に沿って滑る
 ・一度に攻撃に行けるのは今どおり 1 体（立っている体と引きずる体を合わせて）
 ・F3 の表示は「Downed」の後ろに Wander / Chase / Search を付ける

 2. 倒れ方（うつ伏せの死亡アニメ）
================================================================================
 ・Resource/character.txt の腰の骨（Zombie_Hips）の最後のキーを調べた（2026-10-23）
     death1：腰が前へ約 0.85m・下へ約 0.87m 動き、前へ 86° 傾く → 前へ倒れる（うつ伏せ）。160 フレーム目から後は動かない
     death2：腰が後ろへ約 1.2m・下へ約 1.0m 動き、後ろへ 77° 傾く → 後ろへ倒れる（仰向け）
   （前後は、攻撃のアニメ atack3 で手を伸ばすときに腰が前へ出る向きと同じ向きを「前」とした）
 ・脚を失ったら death1 で倒す（Zombie::Animations::downed）。体力が 0 で倒れるときは今どおり体ごとに選んだ方
 ・倒れ終わった体は、足元から前へ 1.5m ほど伸びて寝ている。体の向き（腰 → 首）は足元の向きから少しずれている（約 20°）ので、
   引きずり始めるときに、体の向きを「進む向き」とする（見た目は動かさず、向きの数字だけ合わせる）

================================================================================
 3. 引きずって追う
================================================================================
 ・ZombieChase・ZombiePath はそのまま使う（見えたら追う・探す・銃声・回り込む）。渡す「自分の位置」は足元ではなく胸
   （止まる距離 1.2m は胸から測る。頭は胸の 0.5m ほど先なので、頭は自キャラの足元の手前 0.7m 辺りまで来る）
 ・腕を引いている間だけ前へ進む（壁・車に当たったら沿って滑る）。腕を戻している間は止まる
 ・向きの差が 60° より大きい間は、その場で向きを変えるだけ（立っている時と同じ）
 ・地面の段差（歩道）には胸の位置で合わせる
 ・撃たれても、よろけない（今どおり。のけぞりだけ）

 4. 腕の動き（骨をコードで曲げる）
================================================================================
 ・のけぞり（ZombieFlinch）と同じく、描く直前に骨を曲げる（BonePoseModifier）。曲げる順は 腕 → のけぞり → 部位欠損
 ・腕ごとに「伸ばす ⇔ 引く」の 2 つの形を決め、その間を行き来する。形は体の向き（腰 → 首）・上・外側の 3 つの向きで書く
     伸ばす：上腕も前腕も、頭より前へまっすぐ伸ばす（手は地面の少し上）
     引く  ：肘を胸の横へ下ろし、前腕は前へ向けて地面に置く
 ・1 往復の前半で腕を少し持ち上げながら前へ伸ばし、後半で地面を押さえて引く（このとき体が前へ進む）。左右は半周ずらす
 ・上腕は肩で、前腕は肘で、それぞれ「今の向き」から「決めた形の向き」へ回す（アニメの姿勢に関係なく、決めた形になる）
 ・つかみに行く間（Reach・Hold）は両腕とも前へ伸ばし、手を少し上げる
 ・死んだら、そのときの腕の形のまま止める（腕が急に元の姿勢へ戻らないように）
 ・2026-10-23 作り直し（ユーザー指定「手足は地面に対して這う」「Player を見る」。上の「伸ばす ⇔ 引く の形」の決め方は捨てた）
     胸：Spine1 で 10° 反らせる（前腕で上体を支えた形。反らせすぎると手が地面に届かない）
     手：手首を置く地面の点を決め、肩 → 肘 → 手首を 2 本の骨の IK（余弦定理）で合わせる。地面は骨格の根の空間の高さ 0
       ・置く点は、肩の真下の地面から外側へ 0.12m、前へ 0.45m（伸ばし切り）〜 0.20m（引き終わり）。手首の高さは 4.5cm
       ・前半：引き終わりの点から伸ばし切りの点へ、地面をこするように運ぶ（真ん中で 4cm だけ浮く）
       ・後半：地面に付けたまま、体が進む分（0.25m）だけ後ろへずらす → 地面の同じ所に手を突いて体を引き寄せて見える
         （体が壁で止まっている・向きを変えているだけのときは、手が地面を掻く動きになる）
       ・肘は外側の下へ張り出す（地面から 5cm より下へは行かせない）。手のひらは前腕を水平にした向きで、指の付け根を 3cm の高さへ
       ・つかみに行くときは、前へ 0.6m 伸ばして手首を 12cm（足首の高さ）で止める
     脚：反対の側の腕を伸ばしていくのに合わせて、太ももを 25° 外へ開き、膝で足先を 45° 内へ曲げる。どちらも真上の軸のまわりに
       回すので高さは変わらず、地面に付いた脚は地面に沿って動く（蛙のように地面を蹴る）。その腕で引く間に伸ばす。
       つかみに行っている間は伸ばして止める
     頭：顔の向き（頭 → あごの先から首 → 頭の成分を除いた向き）を、自キャラの目の方へ首で回す。
       ・自キャラを見ている（Chase）・つかみに行っている間だけ自キャラを見る。それ以外は、体の前から 20° 上を見る
       ・向けられるのは体の前から左右 70°・上 60°・下 10° まで（首が回りすぎないように）
       ・向きは 1 秒に 240° までで少しずつ回す（見えた瞬間に首が跳ねないように）
 ・引きずり始めた後は、部位の当たり判定（HitboxSet）を見えている姿勢に付ける（POSE_SHOWN。死んだ後も）。
   頭を 0.2m ほど持ち上げるので、アニメどおりの姿勢のままだと見えている頭を撃っても当たらないため

================================================================================
 5. 足をつかんで噛む
================================================================================
 ・始める：Chase で、頭から自キャラの足元まで 0.9m 以内・向きの差 30° 以内・ほかの体が攻撃に行っていない・腕が残っている
 ・ZombieAttack を「時計」で進める（1 ティックで 1 フレーム。つかんでいる間は今どおり遅く）。時間割は立っている攻撃と同じ
   （手を伸ばし切るまで 0.75 秒 → つかんで 1.2 秒で噛む → 戻る）
 ・手を伸ばし切ったとき、頭から 1.0m 以内・向きの差 45° 以内に相手が居ればつかむ。居なければ空振り
 ・つかんだら今どおり自キャラは動けず、視点はゾンビの頭（足元）へ向く。噛むとき頭を持ち上げる（のけぞりで首を上へ押す）
 ・噛むのは左脚か右脚（半々）。ダメージは今どおり 20。撃って 60 与えると振りほどける（今どおり。引きずる体はよろけない）
 ・噛んだ・空振りした・振りほどかれた後は、待ち時間（2 秒）を置いてまた引きずる

 7. 懸念点
================================================================================
 ・アニメ無しなので、体が地面を滑って見えるかもしれない（腕の引きと進む量を合わせて、ごまかす）
 ・腕・頭の形は向きだけで決めているので、ねじれ（手首の返し・顔の横向き）は倒れた姿勢のまま
 ・地面は骨格の根の空間の高さ 0 とみなしている。歩道の段差の境目では、手が段差に埋まる・浮くことがある
 ・壁との当たりは胸の位置の長方形だけ。頭・足が壁にめり込むことがある
 ・自キャラは引きずる体をまたげるので、真上に立たれると向きが定まらない

================================================================================
 8. 後回しにする物
================================================================================
 ・這うアニメ（Mixamo の Zombie Crawl）への置き換え。来たら、腕を曲げる処理の代わりにアニメを流すだけにする
 ・引きずる体の当たり判定を体の形にする・倒れた体が起き上がる
