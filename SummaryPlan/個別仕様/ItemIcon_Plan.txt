 1. 決めること（★はおすすめ）
================================================================================
 Q1. 絵の作り方
     ★A：Blender で、物の 3D モデルを撮って絵にする（tools/item_icon_gen.py を新しく作る）
          ・どの物も、同じ向き（斜め上から）・同じライト・背景は透明で撮るので、並べたときに揃う
          ・モデルはもうある：ガソリン（Oil tank_atlas.fbx）・7.62 の弾（Ammo&Prop の 7.62NATO Ammo.fbx。弾の箱）・
            AKM（FP_AKM_binary.fbx）・拳銃（G2-Combat.fbx）・9mm の弾（9MM Ammo.fbx）
          ・物を足したら、設定ファイルに 1 行足してスクリプトを回すだけ（今の弾痕・血の絵と同じ「絵はツールで作る」考え方）
          ・タルコフも RE:2 も、物の絵は 3D モデルを撮った物
      B：Python で平らな絵を描く（今の bullet_hole_gen.py と同じ作り方）。手描きの記号のような絵になる
      C：ユーザーが絵を用意する

 Q2. マスの形
     ★A：正方形にする（1 マス 64×64。2 マスの物は 132×64 の横長）。今は横長の 130×40 で、絵を入れると潰れる
          ・座標の高さ 480 の中に、見出し・マス目 4 行・下の欄が入る（4 行で約 270）
          ・6 行（強化 2 回）までは入る。それより増えたら並べ方を変える（R5 の強化のときに決める。5 章）
      B：今の 130×40 のまま、左に小さい絵・右に名前

 Q3. マスに出す文字
     ★A：数だけ（右下。重ねられる物だけ。例：30）。名前は選んだときに下の欄に出す（今の下の欄と同じ）
          ・手に持っている銃の「E」（Pistol_Plan Q2）も文字で左上に出す
      B：短い名前も絵の上に出す（タルコフの短い名前のように）

 Q4. マスの色
     ★A：物のマスの色はやめて、どの物も同じ暗い灰の背景に絵を置く。今の物ごとの色（ItemSpec の red・green・blue）は、
          絵が読めなかったときの代わり（今と同じ色の長方形＋名前）にだけ使う
      B：今の物ごとの色の上に絵を置く

 2. タルコフでは（と RE:2 では）
================================================================================
  ・タルコフ：物ごとに絵（アイコン）と短い名前を持ち、絵はマス目の大きさに合わせてある
    （tarkov.dev・Tarkov Market の API が、物ごとに shortName と icon の画像・使うマスの数を返す）
  ・短い名前と数がマスのどの角に出るかは、今回の検索では確かめられなかった（分からなかった）
  ・RE:2：武器もアイテムも同じマス目に絵で入る（拳銃は 1 マス、大きい武器は 2 マス）。
    数や名前を絵のどこに出すかは、今回の検索では確かめられなかった（分からなかった）
  → 取り入れる：3D モデルを撮った絵・マスの大きさに合わせた絵・数は右下・名前は選んだときだけ
  → 取り入れない：短い名前を絵の上に出す（2 列の小さいカバンなので、名前は下の欄で足りる。Q3 の B で入れられる）

 3. 今のコードで関係するところ
================================================================================
  ・UiRenderer：addRect（色の長方形）と addText（文字）だけ。PrimitiveRenderer は 1 つ
      draw の中で、文字をにじませないためにテクスチャの読み方を「点」にしている → 絵は「線形」で読みたいので、
      長方形（絵）を描く間は線形、文字の間は点にする
  ・画面（バックバッファ）は R8G8B8A8_UNORM（sRGB ではない）で、UI は ToneMap の後に直接描く
      → 絵は sRGB の変換をせずに読む（TEXTURE_COLOR_SPACE_LINEAR）。3D の色の画像のように SRGB で読むと暗くなる
  ・InventoryScreen：マス 130×40（kCellWidth・kCellHeight）。物のマスは ItemSpec の色で塗り、名前と数を文字で出す
  ・ItemSpec：{ name, cellSize, stackSize, startAmount, red, green, blue } → 絵のファイル名（icon）を足す
  ・PrimitiveRenderer の描き方の設定（テクスチャも）は「設定した後に積んだ物」にだけ効く
      （PrimitiveRenderer の設定は積む前に、の約束。2026-10-21）

 4. やること
================================================================================
  I1 絵を作るツール
   ・tools/item_icon_gen.py（Blender で動かす）と tools/configs/item_icons.json（物ごとに FBX・画像・向き・大きさ）
   ・出力：Resource/icon_<名前>.tga（1 マスは 256×256、2 マスは 512×256。2 の累乗。背景は透明）
   ・物を枠いっぱいに収める（モデルの外側の箱から写す範囲を決める）
  I2 UiRenderer::addImage( rect, texture )
   ・積む順は「マスの背景 → 絵 → 枠・選んだ枠」。絵をまとめて積み、絵ごとに描く回数が増えないようにする
     （PrimitiveRenderer のまとまりは 64 まで。マスごとに背景・絵・枠を交互に積むと、マスが増えたときに足りなくなる）
   ・積み終えたらテクスチャを外す（次に積む色の長方形に絵が付かないように）
  I3 ItemSpec に icon（ファイル名）。絵は InventoryScreen が始めに 1 回読む（読めなかった物は今の色と名前で出す）
  I4 InventoryScreen：マスを Q2 の大きさへ・絵・数（右下）・選んだ物の名前（下の欄）
  確かめ方：ビルド（Debug・Release・Profile）・画面で ① 絵の明るさが Blender の絵と同じか ② 2 マスの物の絵が潰れないか
          ③ 動かしている物（薄くする）が分かるか ④ 絵のファイルを消すと今の色と名前に戻るか

 5. 懸念点
================================================================================
  ・強化でカバンが 7 行以上になると、座標の高さ 480 に入らない（64×64 で 6 行まで）。R5 で並べ方（列を増やす・スクロール）を決める
  ・今の texture_to_dds.ps1 は色の画像を BC7_SRGB にする。UI の絵を DDS にすると、SRGB の印の付いた形式を「変換しない」で読めるか
    まだ確かめていない → I3 では、まず TGA のまま読む（8 マスぶんなら大きさは困らない）
  ・7.62NATO Ammo.fbx などの Ammo&Prop のモデルは、まだゲームに変換したことがない（画像の付け方を Blender で見る必要がある）
  ・Pistol_Plan の回答しだいで、拳銃・ライフル・9mm の絵も作る

 7. 実装（2026-11-04）
================================================================================
  ・tools/item_icon_gen.py（新規。Blender の Cycles・CPU で撮る）と tools/configs/item_icons.json
      カメラは正投影・斜め上 25 度・左 35 度。物の外側の箱から写す範囲を決める（端に 8% 空ける）。ライトは 3 つ＋まわりの灰。
      色の見え方は Standard（AgX にすると画像の色と変わる）。FBX は画像を持っていないので、設定の画像でマテリアルを作り直す
      （albedo・normal・orm〈ゲームの並び〉・metallic_smoothness〈Unity の並び〉）。
      作り直し：blender -b --factory-startup --python tools/item_icon_gen.py -- tools/configs/item_icons.json [名前]
  ・Resource/icon_fuel.tga（512×256。缶を横に寝かせた）・icon_ammo_762.tga（256×256。弾の箱）。DDS にはしない（5 章）
  ・UiRenderer::addImage（絵を貼った長方形）。addRect は絵を外してから積む（絵が変わったときだけ描くまとまりが分かれる）。
      draw は長方形と絵を線形、文字を点で読む（今までは全部を点で読んでいた）
  ・ItemSpec に icon（ファイル名）。ItemIcons（Scene/Game。新規）が種類ごとに 1 枚ずつ LINEAR で読む。読めなければ nullptr
  ・InventoryScreen：マス 64×64。① 背景（物のマスは同じ灰。絵が無い物だけ物の色）→ ② 絵（縦横の比を保って収める）→ ③ 数（右下の暗い板の上）
      名前は今まで通り下の欄（選んだ物だけ）
  ・決めた所（計画と少し違う所）：絵が読めなかった物は、物の色だけで塗り、名前はマスに出さない（64 の幅に「7.62 rounds」が入らないため。
    名前は選べば下の欄に出る）
  ・画面で確かめること：4 章の ①〜④（明るさが Blender の絵と同じか・2 マスの物・持ち上げた物が薄くなるか・絵を消すと色に戻るか）と、
    数の板が絵の大事な所を隠していないか
