 芯の一言（全部の Q をここに照らして決める）
================================================================================
 「持ち込んだ物を失うかもしれない町で、もう一つ漁るか、もう逃げるかを迷う」

 ・迷う材料は 3 つ：残り時間・カバンの空き・体力と弾（重さは使わない。Q11）
 ・失う怖さ：死ぬか時間切れで、持ち込んだ物も拾った物も無くなる
 ・漁る欲：持ち帰った物で次の出撃が楽になる（カバンが広がる・良い物を持ち込める）

================================================================================
 0. 決めること（★はおすすめ）
================================================================================
 Q1. 全体のゴール（何をしたら終わりか）
     【2026-11-05 変更】5 日間生き残る（1 日 = 1 回の出撃。5 日続けて脱出できたらクリア）。最後にスコアを出す。下の A は取り下げ
      A：車を直して町から逃げる（取り下げ）
          ・ガソリン 3 缶と車の部品（バッテリー・タイヤなど 2〜3 種）を、何回かの出撃で拠点へ持ち帰って貯める
          ・全部そろったら「最後の出撃」：車へ積み込んで乗れたらエンディング
          ・今のガソリン・車・給油の仕組みと絵をそのまま使える。「何のために漁るか」がはっきりする
      B：終わりは無し（拠点を強くし続ける。タルコフと同じ）
      C：日数の制限（○回の出撃までに車を直す。失敗したら最初から）

 Q2. 拠点（出撃の合間にいる所）の作り
     ★A：メニュー画面（UI だけ）。「倉庫」「準備（持ち込む物を選ぶ）」「強化」「出撃」の 4 つ
          ・今の MenuScene・UiCanvas・UiButton の形で作れる。3D の部屋を作る手間が要らない
      B：歩ける 3D の隠れ家（倉庫の箱・作業台を置く）

 Q3. 死んだとき・時間切れのときに失う物
     【2026-11-05 変更】その場でゲームオーバー（5 日間の日数・倉庫を全部失い、次は 1 日目から）。安全ポーチは作らない。
                      途中でやめたら、その日をやり直すだけ。下の A は取り下げ
      A（取り下げ）：持ち込んだ物も拾った物も全部失う。「安全ポーチ」（2 マス。拠点で広げられる）の中だけ残る
          ・タルコフと同じ形。失う怖さが一番強い。安全ポーチで「これだけは守る」を選ばせる
      B：拾った物だけ失い、持ち込んだ物は戻る（ZERO Sievert の形。やさしい）
      C：保険（持ち込む前に払うと、一部が戻る）

 Q4. 1 回の出撃の長さと、時間が減ると何が起きるか
     ★A：10 分。残り 3 分でサイレンが鳴り、走るゾンビが町の外から増え始める。0 分で「行方不明」（死んだのと同じ扱い）
          ・町は約 110m 四方なので、タルコフの 35〜45 分では長すぎる。端から端まで走って約 40 秒
          ・サイレンの音は今ある環境音を使える。「音が鳴る → 危なくなる」が原因の見える因果になる
          ・残り時間は画面の隅に出す（タルコフは時計を見て確かめる。ここは迷わせたいのは時間の使い方なので、そのまま見せる）
      B：15 分（増え方は同じ）
      C：時間は見せない（腕時計のキーで見る。タルコフ寄り）

 Q5. 脱出の仕方
     ★A：町の外周に脱出点が 4 つ。毎回そのうち 2 つだけが開く（どれが開くかは出撃の始めに分かる）。そこで 5 秒立っていたら脱出
          ・開く所が毎回変わるので、漁る道順を毎回考える
          ・5 秒の間に寄ってこられるので、最後まで気が抜けない
      B：1 つは条件付き（ガソリン 1 缶を置くと開く など。タルコフの払って出る脱出点）を足す
      C：脱出点は 1 つだけ（車の所）

 Q6. インベントリの形（RE:2 のマス目）
     ★A：マス目のカバン。始めは 8 マス（RE:2 と同じ）、拠点の強化で 2 マスずつ広がる
          ・物の大きさは 1 マスか 2 マス（横長）だけ。ガソリンの缶と車の部品は 2 マス
          ・同じ物は 1 マスに重ねられる（弾は 1 マス 30 発まで。RE:2 の弾と同じ）
          ・タルコフのような形の違う物（2×3 など）は作らない。回して詰めるパズルは芯（迷う）とずれ、作るのも重い
      B：タルコフの形（大きさがいろいろ・回せる）
      C：重さ（重いと遅い）だけで、マス目は作らない

 Q7. カバンの画面を開いている間　→ 決定：B（2026-11-04 ユーザー）
      A：世界は止まらない（Tab で開く。開いている間も撃たれる・ゾンビが来る）
          ・タルコフと同じ。「安全な所で整理するか、ここで急ぐか」も迷う材料になる
     【決定】B：止まる（RE:2 と同じ）
          ・残り時間も止まる。迷うのは「何を持って何を捨てるか」で、急ぐ迷いは町の中（漁る・開ける 1〜2 秒・脱出の 5 秒）に任せる
          ・漁れる場所を開けて中身を見る画面（Q8）も止まるか → 段階R3 の Plan で決める（★止まる。カバンの画面と同じ扱いに揃える）

 Q8. 漁る場所と、拾える物
     ★A：町に「漁れる場所」を置く。今は建物に入れないので、外に置ける物にする
          ・場所：車のトランク・ゴミ箱・店先の箱・ゾンビの死体（今の弾が落ちる仕組みを広げる）
          ・物は 5 種類から始める：弾・包帯（体力を戻す）・ガソリン・車の部品・売れる物（拠点で強化に使う）
          ・場所ごとに出やすい物を変える（車のトランク → ガソリンと部品、ゴミ箱 → 売れる物 など）
          ・開けるのに 1〜2 秒かかる（その間は撃てない）。「ここで開けるか」を迷わせる
      B：建物に入れるようにする（中で漁る）。町の作りから直すので大きい。後から足せる

 Q9. 走るゾンビ
     ★A：ゾンビの 2 割が走る（約 3.0m/秒。自キャラの走り 3.1m/秒より少しだけ遅い）。残り 3 分からは走る割合を上げる
          ・振り切れるが、まっすぐ逃げ続けないと追いつかれる（漁る・開ける・撃つで止まると追いつかれる）
          ・今のゾンビに走るアニメと速さを足す。体力・部位欠損・道探しはそのまま
     【不採用】2026-11-07 ユーザー：残り 3 分のサイレンから走る割合を上げるのはやめる（走る割合はずっと同じ）
     【不採用】2026-11-07 ユーザー：走って逃げ切れる対策にスタミナは入れない（前の「作らない」決定のまま）
      B：全体の 1 割（少しだけ）
      C：残り 3 分からだけ出る

 Q10. 持ち込む銃　→ 2026-11-04 変更：毎回タダでもらえるのは拳銃。ライフルは町で拾う（Pistol_Plan.txt Q1。ユーザー承認）
     ★A：基本のライフル（今の銃・弾倉 1 本）は毎回タダでもらえる。失っても次の出撃はできる
          ・全部失っても詰まない（ローグライクの「もう 1 回」）。失う怖さは、それ以外に持ち込んだ物（弾・包帯・広いカバン）が受け持つ
          ・銃の種類を増やすのはプロトタイプβ（複数の武器とカスタム）で
      B：銃も失う。倉庫に銃が無ければ素手（タルコフと同じ。厳しい）

 Q11. カバンが重いと遅くなるか　→ 決定：B（2026-11-04 ユーザー）
      A：ガソリンの缶・車の部品（2 マスの物）を持つ数だけ、走る速さが少し落ちる（1 つで 5%）
     【決定】B：遅くならない（マス目の空きだけで迷わせる）
          ・自キャラはいつも走るゾンビ（3.0m/秒）より少し速い。振り切るには走り続ける必要がある、の形になる
          ・走るゾンビが「速すぎて怖い／遅すぎて怖くない」は段階R4 で遊んで決める（速さは F6 で動かす）

 Q12. 拠点の強化（持ち帰った「売れる物」の使い道）
     ★A：3 つだけ。カバンを広げる（+2 マス）・安全ポーチを広げる（+1 マス）・持ち込める包帯を増やす
          ・強くなる方向を少なくして、作る量を抑える。遊んでから足す
      B：お店（売る・買う）を作る
     【決定】強化は死んでも残る（2026-11-04 ユーザー）
          ・死ぬ・行方不明で失うのは「物」だけ。カバンの広さなどの強化は拠点に残る
          ・ローグライクの「失っても少しずつ前へ進む」になる。失う怖さは物が受け持つ

 1. タルコフでは（と、似たゲーム）
================================================================================
 1-1 タルコフ（Escape from Tarkov）
  ・出撃（レイド）ごとに時間の制限がある。時間内に脱出点へ行けないと「行方不明（MIA）」で、死んだのと同じく持ち物を失う
  ・死ぬと持ち込んだ装備と拾った物を失う。残るのは「安全ポーチ（セキュアコンテナ）」の中身と、ナイフなど決まった枠の物だけ
  ・保険を掛けると、他の人に拾われなかった物が後で戻る（戻るとは限らない）
  ・脱出点は、いつでも使える所・毎回開くかどうか分からない所・お金を払う所・鍵が要る所などに分かれる
  ・拠点（隠れ家）と倉庫があり、持ち帰った物で強くなる
  → 取り入れる：時間の制限と MIA・安全ポーチ・毎回変わる脱出点・倉庫
  → 取り入れない：保険（失う怖さを弱める。作る物が増える）・人の敵（PvE だけ）

 1-2 バイオハザード RE:2
  ・持ち物はマス目。始めは 8 マスで、ヒップポーチを拾うたびに 2 マス増える
  ・アイテムボックスは、どこのボックスからでも同じ中身を取り出せる（倉庫）
  ・使い終わった鍵や余った物はボックスへ預け、カバンを空けて先へ進む
  → 取り入れる：マス目・始め 8 マス・2 マスずつ広がる・倉庫

 1-3 ZERO Sievert（タルコフに影響を受けた 2D の脱出ゲーム。一人用）
  ・拠点（バンカー）で準備し、出撃して漁り、脱出点から帰る。脱出しないと持ち帰れない
  ・死んだときの罰は、資料によって違う（持ち込んだ物は戻り、拾った物だけ失う、という説明がある）
  ・強くなるのはほぼ装備から。拠点に倉庫の部屋を作って広げていく
  → 一人用でも脱出の形が成り立つ例。Q3 の B（やさしい方）はこの形

 1-4 Left 4 Dead 2（Dead Center の最後）
  ・ガソリン缶を集めて車へ入れる。缶を持つと銃が撃てない（置けば撃てる）
  → 今回は芯をタルコフ寄りにしたので取り入れない。重さも使わない（Q11 は B）。運ぶ重みは 2 マスの大きさ（カバンの空き）で出す

 2. 今のコードで関係するところ
================================================================================
  ・Inventory（canAdd / add / remove / count の 4 つだけを外へ見せている）
      → 中身をマス目にしても、この 4 つは残す。Pickup・車・HUD は変えずに済むように作ってある
  ・ItemCatalog（ItemSpec に name・maxCarry・startCarry）
      → 大きさ（マス数）・重ねられる数・重さを足す。maxCarry はマス目に置き換わる
  ・PickupComponent / ItemSourceComponent / Interactor（E で拾う。視線のレイ）
      → 漁れる場所（開けるのに時間がかかる）を足す
  ・CombatResolver::dropAmmo（ゾンビが 50% で弾 10 発を落とす）
      → 死体を漁る形に広げる
  ・FuelTankComponent・WorldBuilder（kRequiredFuel = 3）
      → Q1 の A なら、最後の出撃でだけ使う
  ・ZombieSpawner（30 体・給油ごと +5・上限 50・10 秒ごとに補う）
      → 「給油ごと」を「残り時間」で増える形に変える。走るゾンビの割合もここで決める
  ・SceneManager（SCENE_TITLE / SCENE_GAME / SCENE_CLEAR / SCENE_GAME_OVER）・MenuScene・MenuCatalog
      → 拠点の画面（SCENE_BASE）と、脱出・行方不明の結果の画面を足す
  ・settings.xml と PseudoXml（設定の保存）
      → 倉庫と拠点の強化を保存する（save.xml。設定とは別のファイル）
  ・PauseMenu（ESC で世界と音を止める）
      → カバンの画面も同じ止め方にする（Q7 は B）
  ・SoundCatalog のサイレン（環境音）
      → 残り 3 分の合図

 3. 1 回の出撃の流れ（★の案で）
================================================================================
  拠点（メニュー）
   ├ 倉庫：持ち帰った物が並ぶ（マス目）
   ├ 準備：倉庫からカバンへ入れる。基本のライフルはタダ
   ├ 強化：売れる物でカバン・安全ポーチ・包帯を強くする
   └ 出撃
  町（10 分）
   ├ 始め：開いている脱出点 2 つが分かる。ゾンビは歩くのが中心
   ├ 漁る：車のトランク・ゴミ箱・店先の箱・死体。開けるのに 1〜2 秒
   ├ 迷う：カバンの空き・残り時間・弾と体力（カバンの画面を開くと世界は止まる）
   ├ 残り 3 分：サイレン。走るゾンビが外から増える
   └ 脱出点で 5 秒 → 持ち帰り ／ 死ぬか 0 分 → 安全ポーチ以外の物を失う（強化は残る）
  拠点へ戻る（くり返し）
  車の部品とガソリンがそろったら → 最後の出撃 → 車で逃げてエンディング

 4. 段階の分け方（上から順に。各段階で遊べる形にする）
================================================================================
  段階R1 マス目のインベントリ（カバンの画面・Tab・大きさ 1〜2 マス・重ねる）
         ・ここだけで今のゲームに入れて試せる（今のガソリン・弾をマス目へ）
  段階R2 出撃と帰還（拠点の画面・時間の制限・脱出点・失う／持ち帰る・倉庫の保存）
         ・ここで「失う怖さ」が初めて出る。一番大事な段階
  段階R3 漁れる場所と拾える物（5 種類・場所ごとの出やすさ・開ける時間）
  段階R4 走るゾンビと残り時間の山場（サイレン・増え方）
  段階R5 拠点の強化（2026-11-05 変更：車を直すゴールはやめた。5 日間とスコアは R2 で作る。R2_Plan.txt）
  段階R6 遊んで調整（数値は全部 F6 で動かせるようにしておく）

  ・各段階の終わりに、実際に遊んで「迷う場面があったか」を書き残す（画面確認だけで終わらせない）

 5. やらないこと（今回は）
================================================================================
  ・建物の中に入れるようにする（町の作りから直すため。Q8 の B）
  ・人の敵・保険・お店の売り買い
  ・形がいろいろな物を回して詰めるインベントリ（Q6 の B）
  ・銃の種類とカスタム（プロトタイプβで）
  ・グラフィック・最適化の新しい段階（この作り直しが遊べる形になるまで止める）

 6. 懸念点
================================================================================
  ・作る量が大きい。段階R1・R2 だけでも、画面（UI）と保存と流れの作り直しが要る
    → R2 まで作ったら必ず遊んで、芯が成り立つか（迷うか・怖いか）を確かめてから R3 へ進む
  ・走るゾンビのアニメが要る（Mixamo の zombie run などを変換する）
  ・町が小さい（約 110m 四方）ので、何回も出撃すると飽きやすい
    → 漁る場所の中身と開く脱出点を毎回変えて補う。足りなければ、町を広げるか建物に入れる形を後で考える
  ・今の「画面確認待ち」の機能が多い。作り直しの前に、まず今の物を一度遊んで確かめた方がよい
