 芯の一言（RaidLoop_Spec.txt と同じ）
================================================================================
 「持ち込んだ物を失うかもしれない町で、もう一つ漁るか、もう逃げるかを迷う」
  R4 で足す迷い：
   ① 止まるか（漁る・開ける・リロードで止まった数秒で、走るゾンビが追いつく）
   ② 撃つか逃げるか（逃げ切れるのは「まっすぐ走り続けたとき」だけ。撃てば止まり、銃声で次が来る）
   ③ どこを撃つか（脚を撃てば走れなくなる → Q7）

 0. 決めること（★はおすすめ）
================================================================================
 ── 何体が・どれだけ速く ──
 Q1. 走る体の決め方
     ★A：湧いたときに 2 割の確率で「走る体」に決める（一生変わらない）。条件の「群れ」のときも割合は同じ
          ・割合は F6 で動かせる（変えたら次に湧く体から効く。丈夫さと同じ扱い）
          ・時間で割合は上げない（2026-11-07 不採用。時間制限も今は無い）
      B：湧いたときではなく、気付いた瞬間に 2 割で決める（同じ体が走ったり歩いたりして見分けられない）

 Q2. 走る速さの出し方（決まっている速さは約 3.0m/秒）
     ★A：走りのアニメ（zombie@run）を 1.45 倍で流し、足の動きの表（ZombieStride）で進む。足は地面を滑らない
          ・走りのアニメは等倍で約 2.0m/秒（4 章）。1.45 倍で約 3.0m/秒
          ・倍率は F6 で動かす（例：2.6m/秒にしたいなら 1.3 倍）
      B：アニメは等倍のまま、進む長さだけ 1.5 倍（足が地面を滑って見える）

 Q3. いつ走るか
     ★A：自キャラを見つけて追う間（Chase）と、音を聞いて寄る間（Search）に走る。うろつく間（Wander）は歩く
          ・銃声・足音で寄ってくるときも走るので、「撃って止まる」と早く追いつかれる（芯の②）
          ・見失って探し終えたら、また歩く
      B：見つけて追う間だけ走る（音で寄るときは歩く。やさしい）

 ── 見分け方と避け方 ──
 Q4. 走る体を前もって見分けられるか
     ★A：見た目・声は同じ。走り出して初めて分かる（タルコフの「感染者」も見た目は同じで、走る体と歩く体が混ざる）
          ・遊んで「急すぎて理不尽」なら B を足す
      B：気付いた瞬間に吠えるアニメ（zombie@roar）を約 1 秒だけ流してから走る（Dying Light の「叫んでから来る」。撃つ間ができる）
          ・roar は全部で約 3.3 秒（ゲームの 60 フレーム/秒で 200 フレーム）あるので、どこを使うかは変換してから見る
      C：走る体だけ色の画像を変える（見分けやすいが、怖さが減る）

 Q5. 曲がる速さ
     ★A：歩く体と同じ 1 秒に 180°のまま。速く走るぶん大きく回るので、横へよけると曲がり切れずに通り過ぎる
          ・角を曲がる・車を回り込むと少し引き離せる（「まっすぐ逃げるだけ」でない逃げ方ができる）
      B：走る体は 1 秒に 360°（よけにくい。怖い）

 Q6. 走る体もフラつくか（今は追う間、近いと胴が左右に揺れて狙いにくい）
     ★A：走る間は揺らさない（走りのアニメ自体が大きく動くので、揺れを足すと狙えなくなる）。歩きに落ちたら揺れる
      B：揺らす

 ── 撃たれたら ──
 Q7. 脚を撃たれたら
     ★A：左右どちらかの脚の体力が半分を切ったら、走れなくなって歩きに落ちる（その体はもう走らない）
          ・「脚を撃って止める」という撃ち方ができる（RE2 の「脚を撃って足止め」）。脚を失うと今までどおり這う（Downed）
          ・半分の線は F6 で動かす
      B：脚を撃っても走るまま（脚を失って這うまでは同じ速さ）

 Q8. よろけ・攻撃
     ★A：今と同じ。撃たれたらよろけて止まり、終わったらまた走る。追いついたら歩く体と同じ攻撃
          （決めたときは噛みつき atack3。今は ZombieDirector の kZombieAttackStyle が Swing＝腕振り）
          ・走りから噛みつきへのつなぎは今の 6 ティックのまま（遊んで変なら直す）
      B：走る体だけ飛びかかる（アニメが無いので作る量が大きい）

 ── そのほか ──
 Q9. 残り時間の山場（RaidLoop の段階R4 の名前は「走るゾンビと残り時間の山場」）
     ★A：作らない。走るゾンビだけにする（割合を上げるのは不採用）
          ・時間制限そのものが 11-09 に無くなった。環境音のサイレンを鳴らす係（AmbienceSystem）も 11-09 に消したので、今はサイレンも鳴らない
      B：残り 3 分でサイレンを鳴らすだけ（ゾンビは変えない。合図だけ）

 Q10. 確かめやすさ
     ★A：F3 の頭上のバーの横に、走る体には「R」の印を出す。F6 に ZombieRun の欄（割合・アニメの倍率・脚の線）
      B：印は出さない（F6 だけ）

 1. タルコフでは（と、似たゲーム）
================================================================================
 1-1 タルコフ（Escape from Tarkov）
  ・本編にゾンビはいない。2024 年のハロウィンから「感染者（Infected）」のイベントがあり、2026 年も 1.3.0.0
    （10 月 29 日）で Infected Factory・Infected Lab として出ている
  ・感染者は「走る体・よろよろ歩く体・まだ銃を使える体」が混ざっている。見た目で種類ははっきり分からない
  ・攻略では「入口が 1〜2 つの所で待つ。向こうから走って来る」と言われる（走って来るので、探す必要が無い）
  ・保険が効かない（失う怖さはそのまま）
  → このゲームでは：走る体と歩く体を混ぜる（Q1）・見た目は同じ（Q4 ★A）。止まって構えれば撃てるが、
    止まれば追いつかれる、の形にする

 1-2 Project Zomboid
  ・ゾンビの速さを「よろよろ・速いよろよろ・全力で走る（Sprinter）」から選べ、Random にすると混ざる。
    走る体の割合は Random Sprinter Amount で決める（Build 42.19）
  ・「夜だけ走る」設定もある（昼はよろよろ、夜は走る）
  ・遊ぶ人の間では、走る体を 1% ほどだけ混ぜる遊び方もある（全部が走るときつすぎる）
  → 割合で混ぜる（Q1）のは同じ。割合は F6 で動かして遊んで決める

 1-3 Dying Light（Viral）
  ・走るゾンビ（Viral）は、追いかける前に止まって叫ぶことが多い。叫んでいる間はよけないので、倒す隙になる（ファンの wiki）
  ・追いかけながら叫び続けて、近くの Viral も呼ぶ
  → Q4 の B（吠えてから走る）の元。まずは見た目で分からない ★A で作り、急すぎたら B を足す

 1-4 RE2（バイオハザード RE:2）
  ・脚を撃つとゾンビの脚が壊れて這う。足止めの撃ち方として使われる（このゲームの部位欠損と同じ考え）
  → Q7 ★A（脚の体力が半分で走れなくなる）の元

 2. 今のコードで関係するところ（2026-11-07 に読んだ所）
================================================================================
  ・ゾンビの形とアニメ：Resource/character.txt。中のアニメは walk・idle1・atack1・atack3・death1・death2・gethit だけ
    変換の設定は tools/configs/zombie.json（fbx_to_gamelib.py）。元の FBX のフォルダ
    （Downloads/ゾンビゲーム/ゲームモデル/ゾンビ/Zombie+animation/animation fbx/）に zombie@run.fbx と zombie@roar.fbx がある
  ・アニメの名前：GameWorld.cpp の kZombieAnimation ほか → ZombieAnimationNames に詰めて ZombieFactory::spawn へ
  ・進む長さ：ZombieChaseComponent::walk が ZombieAnimationSet::walkDistanceThisTick（ZombieStride の表）だけ進める
  ・足の動きの表：ZombieModel が walk から 1 つだけ作る（ZombieStride。左右の足先 LeftToeBase・RightToeBase）
  ・歩く・立つの切り替え：ZombieAnimationSet::setWalking（アニメを繋ぐだけ）
  ・アニメの速さ：SkinnedMeshInstance::setPlaybackRate（今はつかんでいる間だけ使う。アニメを替えると 1 に戻る）
  ・追う・探す・うろつく：ZombieChase::Mode（Chase・Search・Wander）
  ・曲がる速さ：ZombieLocomotion.cpp の kTurnPerTick（1 秒 180°）・その場で回る角度 kTurnInPlaceDegree 60°
  ・フラつき：ZombieChaseComponent::swayStrength（Chase で近いときだけ）
  ・体ごとの値：ZombieFactory::spawn が乱数から丈夫さ・揺れの長さを選ぶ（ZombieUncertaintyParams。F6）
  ・部位の体力：ZombieHealth::part / maxPart / isBroken（BodyPart ごと）
  ・湧く：ZombieSpawner（25m 以上・見えない所）。目標の数は出撃の条件で決まる（DayConditionEffect::zombieCount）

 3. R4 でやること・やらないこと
================================================================================
  やる
   ・走りのアニメ（zombie@run）を character.txt に足す
   ・走る体（湧いたときに 2 割）・走る速さ（アニメの倍率）・走りの足の動きの表
   ・追う・寄る間に走る（Q3）
   ・脚の体力が半分で歩きに落ちる（Q7 ★A なら）
   ・F6 の欄・F3 の印（Q10）
  やらない
   ・時間で割合を上げる・スタミナ（不採用）
   ・飛びかかり・新しい攻撃のアニメ（Q8 B）
   ・走るゾンビの足音・声の音（今のゾンビにも足音は無い。足すなら別の段階で）
   ・壁を登る・跳ぶ（町に入れる建物が無いので要らない）

 4. 走りのアニメと速さ（2026-11-07 に Blender 4.5 で測った値）
================================================================================
  ・walk・run とも 2〜61 フレーム（Blender の 24fps）。ゲームは 60 フレーム/秒で流すので、1 周 約 1 秒
  ・地面についた足が 1 周で後ろへ動く長さ（測り方は scratchpad の measure_run.py。左右の低い方の足先を足し合わせた）
      walk：0.82m　→ 今のコードのコメント（約 1.0m）と比べると、この測り方は約 0.82 倍に出る
      run ：1.67m　→ 歩きの約 2.0 倍。直すと 1 周 約 2.0m ＝ 等倍で約 2.0m/秒
  ・3.0m/秒にするには 1.45〜1.5 倍で流す（Q2 ★A。最後の値は ZombieStride の cycleLength を F3 で見て合わせる）
  ・腰は動かない（その場で走る）ので、今の歩きと同じく表で進められる。腰の高さは walk 0.96 → run 0.87（前かがみ）
  ・roar：2〜201 フレーム、足は動かない（その場で吠える）。ゲームでは約 3.3 秒

 5. クラスの分け方
================================================================================
  ・ZombieRunParams（新規・GameSrc/Zombie/）：F6 で動かす値。runnerRatio 0.2・runPlaybackRate 1.45・legSlowRatio 0.5
    ZombieUncertaintyParams と同じ visit の形
  ・ZombieModel：走りの足の動きの表をもう 1 つ持つ（runStride）。名前は作るときに受け取る（walk と同じ）
  ・ZombieAnimationNames：run を足す（nullptr なら走らない。今の確認用の体はそのまま）
  ・ZombieAnimationSet：setWalking を「立つ・歩く・走る」の 3 つに広げる（Gait のような enum。今の bool をやめる）
    走るときは run を流して倍率を掛け、walkDistanceThisTick は run の表 × 倍率で進む
  ・走るか決める所：ZombieChaseComponent（湧いたときに受け取った「走る体か」と、Mode と、脚が壊れかけか、で決める）
    「走る体か」は体ごとの値なので、丈夫さと同じく ZombieFactory::spawn で選んで渡す
  ・脚の線：ZombieHealthComponent に「脚が走れないほど傷んだか」を聞く関数を足す（体力の決まりは体力の部品が持つ）

 9. 懸念点
================================================================================
  ・3.0m/秒と自キャラ 3.1〜3.2m/秒の差が 0.1〜0.2m/秒しか無い。25m 先で気付かれたら、離れるのに何分もかかる
    → 逃げ切るのは「角を曲がる・よける（Q5）・脚を撃つ（Q7）」が主になる。きつすぎたら倍率を下げて 2.6m/秒くらいへ
  ・走る体が道探し（NavMesh）の角でうまく曲がれず、壁に沿って滑り続けるかもしれない（曲がる速さが同じなので）
  ・走りから噛みつきへのつなぎが速さの割に急に止まって見えるかもしれない（Q8）
  ・zombie@run の変換で、ほかのアニメ（atack3 の時刻など）がずれないか（同じ骨なので大丈夫なはず。変換後に見る）

 11. 実装の記録（2026-11-07。R4-a〜R4-c をまとめて実装）
================================================================================
  ・変換：tools/configs/zombie.json に zombie@run を足し、Blender 4.5 で character.txt を変換し直した（run の 1 つが足されただけで、
    ほかのアニメ・形は前と同じ行のまま）。roar は Q4 ★A なので入れていない
  ・ZombieRunParams（新規）：runnerRatio 0.2・runPlaybackRate 1.45・legSlowRatio 0.5。F6 の Tuning「ZombieRun」
  ・ZombieModel：走りの足の動きの表 runStride（コンストラクタに runAnimation。nullptr なら作らない）
  ・ZombieAnimationNames に run。ZombieAnimationSet の setWalking( bool ) を setGait( Gait ) へ（Stand・Walk・Run）。
    アニメを繋ぐと速さが 1 に戻るので、繋いだ後と、走っている間は毎ティック倍率を掛け直す（F6 がすぐ効く）。
    walkDistanceThisTick は走る間「run の表 × 倍率」
  ・ZombieLocomotion：runner を持つ。Intent に running（走る体 かつ 歩きたい かつ うろついていない）。stopRunning・isRunner
  ・ZombieChaseComponent：Intent から Gait を決めて流す。走る体（isRunner）は揺らさない
  ・ZombieFactory：湧いたときに pickRunner（乱数はいつも 1 回引く）。run の名前が無ければ走らない
  ・脚の線：ZombieHealth::weakestLegRatio（脚の 4 部位のうち一番傷んだ部位の残りの割合）が legSlowRatio 以下で stopRunning
    （最初は「太もも＋すねを 1 本」で考えたが、太もも 60・1 発 15 なので半分を切る前に太ももが 0 で切れる → 部位ごとにした）
  ・F3：頭上の HP の行の最後に「R」
