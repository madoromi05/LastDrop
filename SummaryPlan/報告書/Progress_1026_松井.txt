10/26-----------------------------------------------------------------------------------------------
進捗(10/19 ～ 10/26)

まとめ
・ゾンビと戦う中身がそろった(ゾンビの攻撃と自キャラの体力、ゾンビが湧く仕組み、ゲームオーバー)
・前回の優先順位①「撃ち心地の残り」をほぼ実装(カメラシェイク、反動、着弾音、照準のぶれ、エフェクト)
・ゾンビのAIを強化(建物を回り込む道探し、銃声で寄ってくる、うろつく・視野、押し合いの対策)
	-前回の課題「建物を回り込まない」「ゾンビどうしが押し合って詰まる」に対応
・脚を失ったゾンビが体を引きずって追ってくるようにした(這うアニメ無し)
・リロード、一時停止メニュー、設定画面(音量・感度)
・開発の道具(処理時間の計測、ImGui のエディタ、調整値をゲーム中に動かす仕組み)と ComponentSystem

①ゾンビの攻撃と自キャラの体力
・自キャラの体力をタルコフと同じ7部位に分けた
	-左上に薄く体の図を出す。脚が壊れると走れない・歩きが遅くなる
・ゾンビの攻撃：1.6m まで近づいたらつかむ → 1.2秒で噛む。撃てば振りほどける
	-つかまれている間は動けない(撃つ・視点は動かせる)
・死んだら膝から崩れて暗転 → ゲームオーバー画面(YOU DIED。Retry / Title)
・半透明の体の図が半透明にならない不具合を修正(描く部品の設定は、積む前にしないと効かなかった)

②ゾンビが湧く仕組み(ZombieSpawner)
・自キャラから見えない所(25m 以上離れていて、画面の外か物の陰)に湧かせる
・始めは8体。ガソリンを入れるたびに +4(上限20)。減ったら10秒ごとに補う

③撃ち心地(前回の優先順位①)
・カメラシェイク：射撃・つかまれた・噛まれたときに揺らす
	-揺らすのは見える絵だけ。弾の飛ぶ向きは揺らさない(揺れで弾が外れない)
・弾道の反動：連射するとだんだん上へずれる(6発で頭打ち) + 左右ランダム。撃ちやめると戻る
・噛まれたときの怯み(照準が跳ねる)と、痛みの画面効果(赤み・周りのぼかし・暗さ)
・ヒットストップは作らないと決定(代わりに、反動で弾道が変わることで手応えを出す)
・着弾音：当たった物の材質(コンクリート・土・金属)で音を変え、当たった所から鳴らす
	-材質は当たった物が答える。足音の床の材質と同じ種類なので、同じ地面で音が食い違わない
	-音は自作の合成ツール(SoundGen)で作成。跳弾の音は作らない
	-タルコフを調べた(物への着弾と体への命中で、聞こえる距離を別々に調整している → 値を分けた)
・照準のぶれ(タルコフ風)：構えていると少し動くだけで照準がぶれる
	-息(止まっていても小さく8の字)・歩き(止まっても0.6秒残る)・振り向きの遅れ の3つを足す
	-カメラは動かさず、銃と弾の向きだけぶれる(覗くとサイトが画面の中で動き、弾はサイトの先へ飛ぶ)
	-腰だめは2倍。腕が壊れると大きくなる
	-A・D の連打でぶれがカクつく不具合を修正(歩きの揺れの進み具合をアニメから借りず、自分で進めるようにした)
・エフェクト
	-フリップブック：砂ぼこりを「広がって薄れていく煙」の16コマに。マズルフラッシュの芯は4つの形から撃つたびに選ぶ
	-Zソート：砂ぼこり・血しぶきの板を目から遠い順に描く(半透明の重なりが正しくなる)
	-コマの絵もツールで作成(Blender + Python)

④ゾンビのAI
・うろつく：今の向きを基準に ±90°・3～8m 先へ歩き、着いたら2～5秒立つ(一斉に歩き出さない)
・視野：前 ±60° は 60m、それ以外は 20m まで見える
・建物を回り込む道探し
	-NavMesh ではなく、交差点をつないだ図(交差点16個・道24本) + A* にした
	-まっすぐ通れないときだけ道を探す
	-車・ガソリンの置き場の四隅も図に足した(車の前で引っかからない)
	https://www.redblobgames.com/pathfinding/a-star/introduction.html
・銃声で寄ってくる：40m 以内で撃つと、撃った場所へ探しに来る(動き出しは体ごとに0.2～1.0秒ずらす)
・押し合いの対策
	-近くの仲間(1.5m 以内)から離れる向きを、歩く向きに混ぜる(分離)
	-1.5秒近づけなければ左右の通れる方へよけてから道を探し直す
	https://www.red3d.com/cwr/steer/
・ルートモーション：攻撃(0.47m 踏み込む)・よろけ・死亡(0.9～1.2m 倒れる)の体の動きを置き場所へ移した
	-壁や車に当たると体が手前で止まる。落とす弾・頭上のバーが体の所に出る(今までは元の場所に残っていた)

⑤脚を失ったゾンビ(前回の今後の予定)
・うつ伏せに倒れたまま、体を引きずって寄ってきて足をつかみ、脚を噛む
・這うアニメは使わず、腕の骨をコードで動かす(伸ばす ⇔ 引く を左右交互。引いた分だけ進む)
	-手は地面に突いたまま体を引き寄せる(IK)。脚は地面に沿わせる。顔は自キャラの方へ向ける
・追い方は立っているときと同じ(見えたら追う・探す・銃声・回り込む)。腕を失うと遅く、両腕を失うと動けない

⑥弾数とリロード
・弾倉30発。R で2秒のリロード(弾倉を抜く・挿す・槓桿を引く音とアニメ、手に持つ弾倉の見た目)
・弾が無いときは撃つと「カチッ」と鳴る。弾数の表示は一旦出さない(バイオハザード風)
・倒したゾンビが 40% で弾(10発)を落とす。歩いて拾う

⑦メニュー
・一時停止(ESC)：Resume / Retry / Title / Quit。世界と音を止める。ウィンドウが裏に回っても止める
・設定画面(Options)：音量(Master・Effects)と感度。閉じたときにファイルへ保存し、起動時に読む
	-タルコフの設定画面を調べてから決めた(感度は1つ。覗いたときは視野角の比で自動で遅くする)
・操作の一覧(Controls)：今のキーの割り当てから作る(キーを変えても一覧が合う)
・保存したキー設定が読めずに既定値へ戻っていた不具合を修正(キーの割り当てを変える機能は作らないと決定)

⑧開発効率
・処理時間の計測
	-Profile 構成を追加(Release と同じ速さのまま、確認用の機能が使える)
	-1フレームを「CPU・画面の表示待ち・待ち時間」に分けて右上に表示。F7 で記録して CSV に出す
	-重かったフレームの内訳と、ロード時間の内訳をファイルに出す
	-どのボタン・出来事(撃つ・リロード・湧く など)のときに重いか、印を残す
	-GPU の時間も測り、CPU と GPU のどちらが重いかを出す
・計測で見つけた問題：ロード直後の1フレームが 243ms 止まる
	-原因は大きいテクスチャ4枚の展開が最初の描画に集まっていたこと → 展開が終わるまでロード中にした(243ms → 30ms)
・ImGui のエディタ(F6)：一時停止・コマ送り・時間の倍率・VSync の切り替え、計測のグラフ
	-開いたまま遊べる。Alt を押している間だけマウスをエディタへ渡す(射撃・視点とクリックを取り合わない)
・調整値をゲーム中に動かす仕組み：銃の構え・覗く時間・感度と視野角・照準のぶれ・ゾンビの分離の値
	-動かすとすぐ効く。試した値は名前を付けて保存・読み込み。決まった値は C++ のコードの形でコピーして戻す
・場面の保存：自キャラ・ゾンビの位置と乱数の種を保存し、同じ場面を何度でも作れる(負荷を同じ条件で測るため)
・確認用：F4 自由カメラ(町とゾンビを見て回る)、F3 でゾンビの通り道を線で表示、F5 無敵
・ComponentSystem：Unity と同じ GameObject + Component の形にし、ゾンビ・ガソリン・落ちた弾を載せ替えた
	-ガソリンと弾で2回書いていた「拾う・探す・描く」を1回にまとめた
・小さな計算の集約：角度の折り返し・水平の距離・lerp などが各 .cpp にコピーされ、範囲が食い違っていたので1か所へまとめた
	-秒 → ティックは四捨五入にした(切り捨てだと 2.1秒 が 125 になる)
・グラフィック段階1の前半(リニア化 + ToneMap)：色の画像を sRGB として読み、光の計算をリニアで行う
	-最後に ブルーム → 露出 → ACES → sRGB へ戻す。露出・ブルームの値は F6 で調整
	-グラフィックは最適化より先にやると決定(一部の最適化は、後から入れると描く経路を作り直すので一緒にやる)
・機能ごとの仕様書を作り、先にタルコフの仕様を調べてから決める進め方にした
・息遣いは仕様書まで作ったが、とりあえず作らないと決定(案は残してある)

課題
・今週入れた物(体力・攻撃・湧き・AI・這うゾンビ・照準のぶれ・エフェクト・設定画面・ルートモーション・リニア化など)の多くは、画面での確認がまだ
・地面の当たり判定は部品を全部調べているため、部品の数に比例して重くなる(空間分割が必要)
	-弾・AIの見通しの線・段差の高さ調べも同じ判定を使うので、ゾンビが増えるほど重くなる
・ロード直後のひっかかりを直した代わりに、ロードが 0.75秒 → 1.12秒 に伸びた
	-縮めたくなったら、テクスチャの展開を別のスレッドへ移す / DDS に変換する
・照準のぶれは1ティックごとに計算していて、描画で補間していない(60Hz より速い画面で段が見えるかもしれない)
・ダメージ・反動・照準のぶれ・ブルームなどの値は初期値。F6 で画面を見ながら調整中
