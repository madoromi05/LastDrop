## 使い方

- 分からない言葉に出会ったら、`Ctrl + F` で探す。英語の名前でも探せるよう、かっこの中に書いてある
- 「意味」は、まず 1 文で言える形にしてある。正確さより「何の話か分かること」を優先した。詳しくは節の頭に書いた章へ
- 「このゲームでは」は、自分のゲームのどこにあるか・どう使っているか。「―」は、特に決まった場所が無い物。「使っていない」は、知っておくべきだがこのゲームには無い物
- 読むだけで終わらせず、**言葉を見て、意味を自分の言葉で言えるか**を試す（表の「意味」の列を手で隠す）。言えなかった言葉に印を付けて、3 日後にもう一度

## <a id="s1-1"></a>1-1. ビルドとファイル

| 用語 | 意味 | このゲームでは |
|---|---|---|
| コンパイル | `.cpp` を 1 つずつ、機械語（`.obj`）に変えること | ― |
| リンク | コンパイルした `.obj` とライブラリをつないで、1 つの `.exe` にすること | `d3d11.lib`・`d3dcompiler.lib` などをつなぐ |
| ビルド | コンパイルとリンクを合わせた全体 | Debug・Release・Profile の 3 つの構成がある |
| 宣言 | 「こういう名前と型の物がある」と知らせるだけの書き方。中身は無い | ヘッダ（`.h`）に書く |
| 定義 | 中身そのもの（関数の `{ }`・変数の実体）。プログラム全体で 1 つだけ | `.cpp` に書く |
| ヘッダ | 宣言を集めたファイル。ほかのファイルから `#include` で読む | `GameSrc/include/GameSrc/…` |
| インクルードガード | 同じヘッダが 2 回読まれても、中身が 2 回入らないようにする仕組み | `#ifndef INCLUDED_…` |
| 前方宣言 | `class Foo;` と名前だけ先に知らせること。ポインタを持つだけなら中身は要らない | `Component.h` の `class GameObject;` |
| 名前空間（namespace） | 名前がぶつからないよう、名前に「苗字」を付ける仕組み | `GameLib::Graphics::Manager` |
| 無名名前空間 | `namespace{ }`。中の名前は、その `.cpp` の中だけで使える | どの `.cpp` も先頭に定数 `kXxx` を置いている |
| プリプロセッサ | コンパイルの前に、`#include`・`#define`・`#ifdef` を処理する段 | `#ifdef _DEBUG`・`#ifdef ZF_EDITOR` |
| マクロ | `#define` で作る、文字の置き換え。型を確かめないので使いすぎない | `ASSERT`・`PROFILE_SCOPE`・`SAFE_DELETE` |
| インライン（inline） | 関数の定義をヘッダに書いても、リンクでぶつからないようにする指定 | `ComponentTypeId.h` の `nextComponentTypeId` |
| 未解決の外部シンボル | 宣言はあるが定義が見つからない、というリンクのエラー（LNK2019） | ― |

## <a id="s1-2"></a>1-2. メモリ

| 用語 | 意味 | このゲームでは |
|---|---|---|
| スタック | 関数の中の普通の変数が置かれる場所。`{ }` を抜けると自動で消える | ― |

## <a id="s1-3"></a>1-3. 持ち主と寿命

| 用語 | 意味 | このゲームでは |
|---|---|---|
| 寿命 | 物が作られてから消えるまで | 持ち主が決める |
| 所有権 | その物を消す責任。持ち主は 1 人にする | `unique_ptr` で持つ人が持ち主 |
| RAII | 確保をコンストラクタ、解放をデストラクタでして、変数の寿命に結び付ける書き方 | `unique_ptr`・`PROFILE_SCOPE`・GameLib のハンドル |
| スマートポインタ | 消えるとき、自動で先の物も片付けるポインタ | `std::unique_ptr` が 66 回 |
| `std::unique_ptr` | 持ち主が 1 人だけのスマートポインタ。コピーできず、ムーブだけできる | 部品（`Component`）・シーン（`IScene`） |
| `std::shared_ptr` | 何人かで持てるスマートポインタ。最後の 1 人が消えたとき片付く | 使っていない（0 回） |
| ムーブ（`std::move`） | 中身を写さず、持ち主を移すこと。移した元は空になる | `addComponent`・`SceneManager::change` |
| コピーコンストラクタ | 同じ型の別の物から、写して作るコンストラクタ | ほとんどのクラスで `= delete` |
| `= delete` | その関数を「使えない」と宣言する。コピー禁止に使う | 128 回 |
| 参照カウント | 「自分を使っている人の数」を数え、0 になったら消える仕組み | COM のオブジェクト・GameLib のハンドル |
| ハンドル | 本体へのポインタを 1 つ持つだけの小さなクラス。写しても本体は増えない | `Graphics::Texture`・`Shader`・`RenderTarget` |

## <a id="s1-5"></a>1-5. テンプレートと新しめの書き方

| 用語 | 意味 | このゲームでは |
|---|---|---|
| テンプレート | 型を後から決められる関数・クラス。`template< class T >` | `addComponent< T >`・`getComponent< T >` |

## <a id="s1-6"></a>1-6. 標準ライブラリ

| 用語 | 意味 | このゲームでは |
|---|---|---|
| `std::vector` | 数を増やせる配列。要素は連続して並ぶ | 515 回 |

# <a id="s5"></a>5. 似ていて間違えやすい言葉

| 比べる言葉 | 違い |
|---|---|
| 宣言 ／ 定義 | 宣言は「ある」と知らせるだけ。定義は中身。宣言は何回でも、定義は 1 つ |
| コンパイルエラー ／ リンクエラー | 文法や型の間違い ／ 中身が見つからない・2 つある |
| スタック ／ ヒープ | `{ }` を抜けると自動で消える ／ 消すまで残る |
| ポインタ ／ 参照 | nullptr にでき、付け替えられる ／ 必ず何かに付き、付け替えられない |
| `const int* p` ／ `int* const p` | 指す先を書き換えられない ／ ポインタを付け替えられない |
| コピー ／ ムーブ | 写して 2 つにする ／ 持ち主を移して元は空にする |
| オーバーライド ／ オーバーロード | 基底の仮想関数を上書きする ／ 同じ名前で引数の違う関数を作る |
| 継承 ／ 委譲 | 「〜の一種である」 ／ 「〜を持っていて、任せる」 |
| `struct` ／ `class` | 既定が public ／ private。ほかは同じ |
| デバイス ／ デバイスコンテキスト | 作る係 ／ 使う係 |
| バックバッファ ／ 描画先 ／ テクスチャ | 画面に出す絵 ／ 描く先にできるテクスチャ全般 ／ GPU の画像全般。バックバッファも描画先の 1 つ |
| RTV ／ SRV | 描く先として使う札 ／ 読むために使う札。同じテクスチャに両方作れるが、同時には使えない |
| 深度バッファ ／ シャドウマップ | カメラから見た深度（隠れを決める） ／ 光から見た深度（影を決める）。どちらも深度の画像 |
| 頂点シェーダ ／ ピクセルシェーダ | 頂点ごと（位置を決める） ／ 画素ごと（色を決める） |
| 定数バッファ ／ 頂点バッファ | 描画 1 回の間ずっと同じ値 ／ 頂点ごとに違う値 |
| セマンティクス ／ スロット | 頂点の要素の意味の札（`POSITION`） ／ 定数・テクスチャを付ける番号（b0・t0） |
| ワールド ／ ビュー ／ 射影 | 物を置く ／ カメラから見る ／ 遠近を付ける |
| クリップ空間 ／ NDC | w で割る前 ／ 割った後 |
| lerp ／ slerp | 直線で混ぜる（位置・色） ／ 球の上で混ぜる（回転） |
| 法線 ／ 接線 | 面に垂直 ／ 面に沿う |
| sRGB ／ リニア | 画像と画面の数 ／ 光の計算の数 |
| HDR ／ トーンマップ | 明るさを切らずに持つこと ／ それを 0〜1 に収める処理 |
| 拡散 ／ 鏡面 | どこから見ても同じ明るさ ／ 見る向きで変わるハイライト |
| 粗さ ／ 金属 | ハイライトの広がり ／ 拡散があるか・反射に色が付くか |
| AO ／ SSAO | 隙間が暗くなる現象 ／ それを画面の情報から作る方法 |
| フォワード ／ ディファード | 描きながら照らす ／ 面の情報を先に描いて後で照らす |
| MSAA ／ FXAA ／ TAA | 1 画素を何点も調べる ／ できた絵をぼかす ／ 何フレームかを混ぜる |
| バイアス ／ PCF | にきびを防ぐ ／ 影の縁をぼかす |
| 背面カリング ／ 視錐台カリング ／ オクルージョンカリング | 裏向きの面 ／ 画面の外の物 ／ 陰に隠れた物、を描かない |
| バッチング ／ インスタンシング | 違う形もまとめて 1 つのメッシュにする ／ 同じ形を、置き場所だけ変えて何個も描く |
| FPS ／ フレーム時間 | 1 秒に何回 ／ 1 回に何ミリ秒。「10fps 下がった」は元の数で重さが違うので、ミリ秒で話す |
| CPU バウンド ／ GPU バウンド | CPU が遅い ／ GPU が遅い。直す所が違うので、先に見分ける |
| デルタタイム ／ 固定ステップ | 経過時間を掛けて動かす ／ 決まった時間ずつ何回か動かす |
| AABB ／ OBB | 軸に沿った箱（速い） ／ 回転した箱（ぴったり） |
| 掃引 ／ レイキャスト | 大きさのある物を動かして調べる ／ 線を飛ばして調べる |
| スキン行列 ／ ボーンの行列 | 頂点を変形する（bindInverse を掛けてある） ／ 骨が今どこにあるか |
