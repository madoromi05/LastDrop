# 参考資料

各章の「先に読む」に出した物を、種類ごとにまとめた。全部を読む必要は無い。**◎ を先に**。

URL は 2026-11-12 の時点の物。この教材を書いた AI が検索で開けることを確かめられたのは一部だけなので、
開けなければ題名で検索する（★ は検索で確かめられた物）。

## まず 3 つだけ選ぶなら

1. ◎ Microsoft の [Direct3D11Tutorials](https://github.com/walbourn/directx-sdk-samples/tree/main/Direct3D11Tutorials)：1 段ずつ増えていく短いサンプル。ミニレンダラの M1〜M6 とほぼ同じ順
2. ◎ [LearnOpenGL](https://learnopengl.com/)（英語）：API は OpenGL だが、**考え方の説明**はこれが一番分かりやすい。ライティング・影・ディファード・PBR・ブルーム・SSAO は、D3D11 で書くときもまずここを読む
3. ◎ Frank D. Luna『Introduction to 3D Game Programming with DirectX 11』（本・英語）：D3D11 を 1 冊で通す定番。数学 → 初期化 → パイプライン → ライティング → … → 影 → スキニングの順

OpenGL と D3D11 の主な読み替え：

| OpenGL（LearnOpenGL） | D3D11 |
|---|---|
| Framebuffer | 描画先（RTV）＋深度（DSV）の組 |
| Uniform・Uniform Buffer | 定数バッファ |
| VAO | 入力レイアウト |
| GLSL の `vec3`・`mat4`・`mix`・`fract`・`texture()` | HLSL の `float3`・`float4x4`・`lerp`・`frac`・`Sample()` |
| クリップ空間の z は −1〜1 | z は 0〜1 |
| テクスチャの原点は左下 | 左上 |
| 右手系・列ベクトル | 決まりは無い（DirectXMath は左手系・行ベクトルが多い。自分の GameLib は右手系・列ベクトル） |
